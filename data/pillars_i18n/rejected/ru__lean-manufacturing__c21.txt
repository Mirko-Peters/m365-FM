## Глоссарий бережливого производства: ключевые термины от A до Z

| Термин | Краткое определение |
|---|---|
| Отчёт A3 | решение проблемы, анализ и план действий на одном листе формата A3 (около 279 × 432 мм) |
| Андон | сигнал (световой, шнур, кнопка), который мгновенно делает отклонение видимым |
| CONWIP | управление с постоянным количеством незавершённого производства в системе; подходит для производства высокой номенклатурной сложности |
| Время цикла | фактическое время, которое процесс затрачивает на выпуск одной детали |
| DOWNTIME | мнемоническое сокращение из США для восьми видов потерь: дефекты, перепроизводство, ожидание, нереализованный потенциал сотрудников, транспортировка, запасы, лишние движения, избыточная обработка |
| Буфер FIFO | буфер ограниченной ёмкости, который передаёт детали в порядке их поступления |
| Коэффициент потока | доля времени обработки в общем времени выполнения (также называемая эффективностью цикла процесса) |
| Гемба | место, где создаётся ценность; на производственной площадке — линия или ячейка |
| Генчи генбуцу | пойти и увидеть самому, а не полагаться на отчёты |
| Хансей | структурированное осмысление после проекта или ошибки |
| Хейдзюнка | выравнивание производства по объёму и номенклатуре |
| Хосин канри | развёртывание стратегии (политики) от высшего руководства до производственной площадки |
| Дзидока | остановка при отклонениях, качество, встроенное в процесс; второй столп ТПС |
| Just-in-time | производить только необходимое, тогда, когда это нужно, в необходимом количестве |
| Кайдзен | непрерывное улучшение малыми шагами силами всех сотрудников (непрерывное совершенствование, CI) |
| Стандартная работа руководителя | стандартная работа для руководителей, например фиксированное время обходов гемба и многоуровневых совещаний |
| Время выполнения заказа (lead time) | время от поступления детали или заказа до выхода из потока создания ценности |
| Муда, мура, мури | потери, неравномерность, перегрузка |
| OEE | общая эффективность оборудования: доступность × производительность × качество |
| Поточное производство штучными деталями | изготовление и передача деталей по одной, а не партиями |
| Процесс-задающий (pacemaker) | единственный процесс, который получает производственный график; все предшествующие процессы работают по вытягиванию |
| Такт ячейки (pitch) | такт-тайм × количество в контейнере; временной интервал ящика хейдзюнки |
| Пока-ёкэ | простое устройство, которое предотвращает ошибку или немедленно её сигнализирует |
| SMED | переналадка за время в одну минуту (менее 10 минут) за счёт разделения и преобразования подготовительных операций |
| Супермаркет | контролируемый запас с минимальным и максимальным количеством, из которого забирает последующий процесс |
| Такт-тайм | доступное время производства / потребительский спрос |
| TIMWOODS | европейское мнемоническое сокращение для тех же восьми потерь |
| TPM | общее производительное обслуживание: уход за оборудованием с участием всех сотрудников |
| TWI | Training Within Industry: программа из США с 1940 года по обучению работе, методам работы и взаимоотношениям на производстве |
| Ямадзуми | накопительная столбчатая диаграмма объёма работы каждого оператора в сравнении с тактом |
