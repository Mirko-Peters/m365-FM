## Глоссарий Lean: ключевые термины от A до Z

| Термин | Краткое определение |
|---|---|
| A3-отчёт | решение проблемы, анализ и план действий на одном листе формата A3 (около 11 × 17 дюймов) |
| Andon | сигнал (лампа, шнур, кнопка), который немедленно делает отклонение видимым |
| CONWIP | управление с постоянным объёмом незавершённого производства в системе; подходит для производства высокой номенклатуры |
| Время цикла | фактическое время, которое процессу требуется для изготовления одной детали |
| DOWNTIME | мнемоника на английском языке для восьми видов потерь: дефекты, перепроизводство, ожидание, нереализованный потенциал сотрудников, транспортировка, запасы, лишние движения, лишняя обработка |
| FIFO-линия | буфер ограниченной ёмкости, который передаёт детали в порядке их поступления |
| Коэффициент потока | доля времени обработки во времени производственного цикла (также называется эффективностью цикла процесса) |
| Гемба | место, где создаётся ценность; на производственной площадке — линия или ячейка |
| Генчи генбуцу | пойти и увидеть самому, а не полагаться на отчёты |
| Ханси | структурированное осмысление после проекта или ошибки |
| Хейдзунка | выравнивание производства по объёму и номенклатуре |
| Хосин канри | развёртывание стратегии (политики) от руководства высшего звена до производственной площадки |
| Дзидока | остановка при отклонениях, качество, заложенное в процесс; второй столп TPS |
| Just-in-time | производить только то, что нужно, тогда, когда нужно, в необходимом количестве |
| Кайдзен | непрерывное улучшение малыми шагами силами всех сотрудников (непрерывное совершенствование, CI) |
| Стандартная работа руководителя | стандартная работа для руководителей, например фиксированное время обходов гемба и многоуровневых совещаний |
| Время производственного цикла (Lead time) | время от поступления детали или заказа в поток создания ценности до выхода из него |
| Муда, мура, мури | потери, неравномерность, перегрузка |
| OEE | общая эффективность оборудования: готовность × производительность × качество |
| Поточное производство одной детали | изготовление и передача деталей по одной, а не партиями |
| Процесс-задатчик (pacemaker) | единственный процесс, который получает производственный график; все предыдущие процессы работают по вытягиванию |
| Такт ячейки (pitch) | такт-время × количество в контейнере; временной интервал ящика хейдзунки |
| Пока-ёкэ | простое устройство, которое предотвращает ошибку или немедленно её сигнализирует |
| SMED | переналадка за однозначное число минут путём разделения и перевода наладочных операций в режим внешних |
| Супермаркет | контролируемый запас с минимальным и максимальным количеством, из которого забирает последующий процесс |
| Такт-время | доступное время производства / спрос потребителя |
| TIMWOODS | европейская мнемоника для тех же восьми видов потерь |
| TPM | общее производительное обслуживание: уход за оборудованием с участием всех сотрудников |
| TWI | Training Within Industry: программа США с 1940 года по обучению на рабочем месте, методам работы и взаимоотношениям в коллективе |
| Ямадзуми | накопительная столбчатая диаграмма объёма работы каждого оператора в сравнении с тактом |
</translation>
