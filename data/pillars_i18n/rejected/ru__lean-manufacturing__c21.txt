## Глоссарий Lean: ключевые термины от A до Z

| Термин | Краткое определение |
|---|---|
| A3-отчёт | решение проблемы, анализ и план действий на одном листе формата A3 (около 11 × 17 дюймов) |
| Андон | сигнал (световой, шнуровой, кнопочный), который немедленно делает отклонение видимым |
| CONWIP | управление с постоянным объёмом незавершённого производства в системе; подходит для производства высокой номенклатурной сложности |
| Такт-время цикла | фактическое время, которое процесс требует для выполнения одной детали |
| DOWNTIME | мнемоника США для восьми видов потерь: дефекты, перепроизводство, ожидание, неиспользованный потенциал сотрудников, транспортировка, запасы, лишние движения, избыточная обработка |
| FIFO-линия | буфер ограниченной ёмкости, который передаёт детали в порядке их поступления |
| Коэффициент потока | доля времени обработки во времени производственного цикла (также называется эффективностью цикла процесса) |
| Гемба | место, где создаётся ценность; на производственном участке — линия или ячейка |
| Гэнти гэнбуцу | пойти и увидеть самому, а не полагаться на отчёты |
| Хансэй | структурированный анализ после проекта или ошибки |
| Хейдзунка | выравнивание производства по объёму и номенклатуре |
| Хосин канри | развёртывание стратегии (политики) от высшего руководства до производственного участка |
| Дзидока | остановка при отклонениях, качество, заложенное в процесс; второй столп TPS |
| Just-in-time | производить только то, что нужно, когда нужно и в необходимом количестве |
| Кайдзен | непрерывное улучшение малыми шагами силами всех сотрудников (непрерывное совершенствование, CI) |
| Стандартная работа руководителя | стандартная работа для руководителей, например фиксированное время обходов гемба и многоуровневых совещаний |
| Время производственного цикла | время от поступления детали или заказа до выхода из потока создания ценности |
| Муда, мура, муri | потери, неравномерность, перегрузка |
| OEE | общая эффективность оборудования: доступность × производительность × качество |
| Поточное производство штучными изделиями | изготовление и передача деталей по одной, а не партиями |
| Процесс-метроном | единственный процесс, который получает производственный график; все предшествующие процессы следуют за ним по принципу вытягивания |
| Такт выпуска | такт-время × количество в таре; временной интервал ящика хейдзунка |
| Покаёкэ | простое устройство, которое предотвращает ошибку или немедленно её сигнализирует |
| SMED | переналадка за однозначное число минут путём разделения и преобразования операций наладки |
| Супермаркет | контролируемый запас с минимальным и максимальным количеством, из которого забирает последующий процесс |
| Такт-время | доступное производственное время / потребительский спрос |
| TIMWOODS | европейская мнемоника для тех же восьми видов потерь |
| TPM | всеобщее производительное обслуживание: уход за оборудованием с участием всех сотрудников |
| TWI | «Обучение в промышленности» (Training Within Industry): программа США с 1940 года по обучению работе, методам работы и отношениям на производстве |
| Ямадзуми | диаграмма с накопленными столбцами, показывающая объём работы каждого оператора в сравнении с тактом |
</translation>
