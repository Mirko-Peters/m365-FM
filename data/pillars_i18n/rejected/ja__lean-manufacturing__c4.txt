# 標準作業

[標準作業](https://www.m365.fm/entity/standard-work/)(standardized work)は、各作業者の正確な作業方法を工程ごとに定めるもので、掲示されると、カイゼンの基準となります[17]。これには3つの要素があります[17]。

1. **タクトタイム:** 生産を進めるべきリズム。
2. **作業順序:** タクトタイム内で行う作業の正確な順序。
3. **標準手持ち:** スムーズな運用に必要な、機械内の部品を含む工程内在庫。

LEIは3つの様式を挙げています。工程能力表、標準作業組合せ表(手作業時間、歩行時間、機械時間)、そして歩行経路を示す標準作業表です[17]。標準作業は厳格な規則集ではありません。現時点で知られている最善の方法を示すものであり、その作業を行う人々によって改善されていきます。Liker はこう述べています。標準化された作業は、継続的改善と従業員の権限付与の基盤である[10]。歴史の節で触れたTWIの作業指導法は、作業を手順と要点に分解するもので、これを指導する実践的な方法です[59]。

**よくある間違い:** 1ページの目で見る表示の代わりに30ページの作業指示書を用いること、タクトとの関連づけがない標準、標準を変更するためのプロセスがないこと。

# ラインバランシング

[ラインバランシング](https://www.m365.fm/entity/line-balancing/)は、各工程やオペレーターに作業内容を配分し、どの工程もタクトタイムを超えないよう、できるだけタクトタイムに近づけるものです。中心的な道具は作業者バランス図(山積み図とも呼ばれます)で、各作業者を、積み上げられた作業要素の棒グラフとして示し、タクトタイムと比較します[24]。

**作業例(説明用):** 1直は7.5時間、すなわち27,000秒の稼働時間です。需要は450個です。タクトタイム = 27,000 / 450 = 60秒。作業要素の合計は99秒です(A = 25、B = 20、C = 14、D = 22、E = 18)。最低必要人員 = 99 / 60 = 1.65、つまり2名です。作業者1はA、B、Cを行い(59秒)、作業者2はDとEを行います(40秒)。図によって、作業者2の20秒の手待ち時間が見えるようになります。次の一手は、作業者1のムダを減らすか、作業を適切に再配分することです。LEIによると、目標は、各オペレーターの負荷をタクトタイムを超えない範囲でできるだけ近づけるように作業要素を再配分することです[24]。

この例には、2つの実務上の注意点があります。第一に、多くの工場では、変動や小さな乱れを吸収するため、タクトタイムそのものではなく、やや短い計画サイクルタイムに対して計画を立てます。59秒/60秒では、作業者1にほとんど余裕がありません。第二に、手待ち時間は全員に均等に分散させず、最後の作業者に意図的に集中させています。こうすることで手待ちが見えたままになり、カイゼンで作業内容が20秒減れば、後に工程を統合できます。手待ち時間を均等に分散させると、それは作業の中に溶け込んでしまい、ペースを落とすことで埋められてしまうことが多いのです。

# SMED:段階的な段取り替えの短縮

SMEDは「single-minute exchange of die」の略で、段取り替えを一桁分、つまり10分未満で行うことを意味します[12]。その主要な考え方は、1950年代から1960年代にかけて新郷重夫(1909〜1990)によって開発されました[12]。その中には、1950年の東洋工業(現在のマツダ)、1957年の三菱重工業、そして1969年からのトヨタでの取り組みが含まれ、プレスの段取り替えは1〜2時間から数分へと短縮されました[11]。彼は1985年に英語版として『A Revolution in Manufacturing: The SMED System』でこの方法を発表しました[11]。

SMEDがリーンにとって非常に重要な理由は、長い[段取り時間](https://www.m365.fm/entity/setup-time/)が大ロットにつながり、大ロットが高い在庫と長いリードタイムにつながるためです。段取り替えが短ければ小ロットが経済的になり、それこそが流れと平準化を可能にするものです。

**6つのステップによるSMED:**

1. **現在の段取り替えを記録する:** 旧品種の最後の良品から新品種の最初の良品までの段取り替え全体を撮影します。すべての作業を所要時間とともに記録します。
2. **内段取りと外段取りを分ける:** 内段取りは機械を停止した状態でしか行えない作業です(新しい金型の取り付けなど)。外段取りは機械が稼働中に行える作業です(金型の準備など)[12]。この分離だけで、探す作業や取りに行く作業が停止時間から外れるため、ダウンタイムが大きく減ることがよくあります。
3. **内段取りを外段取りに変換する:** 内段取りの作業を、できるだけ外に出します[12]。たとえば、金型を予熱する、プリセットの治具を使う、金型の高さを標準化するなどです。
4. **内段取りを効率化する:** ボルトの代わりにクイッククランプを使う、調整の代わりに位置決めピンを使う、二人で並行して作業する、調整をなくす。
5. **外段取りを効率化する:** 段取り替え用の台車、チェックリスト、5Sに従った固定の仮置き場所。
6. **標準化し、練習する:** 新しい段取り替えを標準作業として文書化し、訓練し、測定します。その後、サイクルが再び始まります。

**よくある間違い:** 段取りの手順1〜3を尽くす前に高価な設備に投資すること。段取り替えの改善をロットの縮小に結びつけず、在庫が変わらないままになること。

# かんばん

かんばんは、プル方式において部品の生産や移動を引き起こし、制御する信号です。日本語の「看板」に由来する言葉で、「合図」や「掲示板」を意味します[15]。かんばんはカード、金属プレート、色つきのボール、電子信号などの形態をとりえます。典型的なカードには、部品名と部品番号、供給元、容器の数量、保管場所と使用場所が記載されています[15]。

LEIは2つの基本的な種類を区別しています[15]。

- **生産かんばん:** 上流工程に、何を、どれだけ作るべきかを指示します。最も単純な場合は、1枚のカードが1容器に対応します。プレスのように段取り替えに時間がかかる工程では、最低在庫量に達したときにのみ生産を開始する信号かんばんを用います。
- **引取りかんばん(運搬かんばん):** 部品を後工程へ移動させることを許可するもので、工程間で内部的に用いる場合と、外部の供給業者向けの仕入先かんばんとして用いる場合があり、長距離の場合は電子化が進んでいます。

**トヨタのかんばんの6つのルール(大野、1988年):** 大野はその著書で6つのルールを示しています[7][51]。

1. 後工程は、かんばんが指示する数量を、必ず前工程から引き取る。
2. 前工程は、かんばんが指示する数量と順序で生産する。
3. かんばんなしに何も作らず、何も運ばない。
4. かんばんは、常に部品または容器に付けておく。
5. 不良品は後工程に渡さない。
6. かんばんの枚数は段階的に減らす。こうすることで、システムはより敏感になり、問題が表面化する。

**作業例:かんばん枚数(説明用):** 基本的な計算式は次のとおりです。かんばん枚数 = 期間あたりの需要 × 補充リードタイム ×(1 + 安全係数)/ 容器の数量。組立エリアが1日400個の部品を使用し、上流からの補充に半日かかり、安全係数が10パーセント、容器に50個入るとすると、400 × 0.5 × 1.1 / 50 = 4.4、すなわち5枚となります。これによりループ内の部品は250個に抑えられ、需要のおよそ半日分をやや上回る量になります。その後SMEDで補充時間が半分になれば、ルール6の趣旨に沿って、かんばんの枚数を減らすことができます。この例では5枚から3枚です。

**かんばんが適さない場合:** 需要の変動が激しい場合、めったに使われない部品、顧客ごとの特注品の場合です。そうした場合は、FIFOレーン、オーダー別管理、あるいはCONWIPの方が適していることが多いものです。

# プル方式とスーパーマーケット

プル方式は、2つの工程の間の在庫に上限を設け、後工程がペースを決めることを可能にします[5]。基本的な形態は3つあります。スーパーマーケット方式(取られた分を補充する)、逐次プル方式(FIFOレーンで上限を設けた受注生産による順番の制御)、そしてそれらの混合形態です。スーパーマーケットとは、後工程が引き取る、あらかじめ最大量と最小量を定めた管理された在庫のことです。プルは、各工程すべてを中央で計画する方式の反対です。スケジュールを受け取るのはペースメーカー工程だけで、上流のすべての工程はかんばんの信号に従います。米国の工場では、MRP/ERPシステムが引き続き資材と能力を計画する一方で、ペースメーカーのスケジュールとかんばんのループが、日々実際に何を作るかを決める、という形になることがよくあります。

# 平準化生産

[平準化](https://www.m365.fm/entity/heijunka/)(Heijunka)は、一定の期間にわたって生産の品種と数量を均すものです[16]。ピークに合わせて上流工程の能力を設定する必要がなくなるため、在庫、設備投資、要員の必要数、リードタイムを減らすことができます。
