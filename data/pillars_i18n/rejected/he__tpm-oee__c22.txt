## מילון מונחים ל-TPM ול-OEE

| מונח | משמעות |
|---|---|
| תג חריגה (F-tag) | תג שנתלה על הציוד כדי לסמן בעיה שנמצאה במהלך ניקוי או בדיקה |
| תחזוקה אוטונומית (jishu hozen) | עמוד TPM שבו המפעילים שומרים על מצב הציוד הבסיסי ומאתרים חריגות |
| תנאים בסיסיים | ניקוי, סיכה והידוק שמונעים מהציוד להתדרדר |
| CILS / CILT | ניקוי, בדיקה, סיכה והידוק או אבטחה: השגרה היומית של תחזוקה אוטונומית |
| CMMS | מערכת ממוחשבת לניהול תחזוקה |
| דירוג קריטיות | דירוג נכסים לפי השפעת הכשל והסבירות שיתרחש |
| ניהול ציוד מוקדם | עמוד TPM שמתכנן יכולת תחזוקה וקלות הפעלה בציוד חדש |
| שיפור ממוקד (kobetsu kaizen) | עמוד TPM להסרה מובנית של הפסדים ספציפיים |
| זמן מחזור אידיאלי | הזמן הטוב ביותר האפשרי לחלק; הבסיס לגורם הביצועים |
| JIPM | המכון היפני לתחזוקת מפעלים, המעניק את פרסי ה-TPM |
| עומס | זמן ייצור מתוכנן ÷ זמן לוח שנה |
| נעילה/תיוג (Lockout/tagout) | נהלים מבוקרי OSHA לשליטה באנרגיה מסוכנת במהלך שירות (29 CFR 1910.147) |
| [עצירות מיקרו](https://www.m365.fm/entity/micro-stops/) (עצירות קטנות) | עצירות קצרות מתחת לסף מוגדר; הפסד ביצועים |
| MTBF / MTTR | זמן ממוצע בין כשלים / זמן ממוצע לתיקון |
| OEE | יעילות ציוד כוללת = זמינות × ביצועים × איכות |
| שיעור נקודה אחת (OPL) | הוראה של דף אחד בנושא אחד, שנלמדת ליד המכונה |
| ביצועים | (זמן מחזור אידיאלי × ספירה כוללת) ÷ זמן הפעלה |
| תחזוקה מתוכננת | עמוד TPM לתחזוקה מבוססת זמן ומבוססת מצב, על ידי פונקציית התחזוקה |
| אחוז תחזוקה מתוכננת | שעות תחזוקה מתוכננת ÷ סך שעות התחזוקה |
| איכות (שיעור) | ספירת תקינים ÷ ספירה כוללת |
| תחזוקת איכות (hinshitsu hozen) | עמוד TPM ששולט במצבי הציוד כדי למנוע פגמים |
| שישה הפסדים גדולים | תקלות, הגדרה והתאמה, עצירות קטנות, האטת מהירות, פגמים ותיקונים, הפסדי הפעלה |
| SMED | החלפת תבנית בדקה אחת, השיטה לקיצור [זמן הגדרה](https://www.m365.fm/entity/setup-time/) |
| TEEP | ביצועי ציוד יעילים כוללים = OEE × עומס |
</translation>
