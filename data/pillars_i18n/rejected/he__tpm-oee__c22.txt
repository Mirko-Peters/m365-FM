## מילון מונחים ל-TPM ו-OEE

| מונח | משמעות |
|---|---|
| תג חריגה (F-tag) | תג שנתלה על ציוד לסימון בעיה שנמצאה בזמן ניקוי או בדיקה |
| תחזוקה אוטונומית (jishu hozen) | עמוד TPM שבו מפעילים שומרים על מצב הציוד הבסיסי ומזהים חריגות |
| תנאים בסיסיים | ניקוי, סיכה והידוק שמונעים מהציוד להתדרדר |
| CILS / CILT | ניקוי, בדיקה, סיכה וביטחון או הידוק: שגרת התחזוקה האוטונומית היומית |
| CMMS | מערכת ממוחשבת לניהול תחזוקה |
| דירוג קריטיות | ניקוד נכסים לפי השפעתה והסבירות של תקלה |
| ניהול ציוד מוקדם | עמוד TPM שמתכנן לתחזוקתיות ולנוחות הפעלה בציוד חדש |
| שיפור ממוקד (kobetsu kaizen) | עמוד TPM להסרה מובנית של הפסדים ספציפיים |
| זמן מחזור אידיאלי | הזמן הטוב ביותר האפשרי לחלק; הבסיס לגורם הביצועים |
| JIPM | המכון היפני לתחזוקת מפעלים, שמעניק את פרסי ה-TPM |
| עומס | זמן ייצור מתוכנן ÷ זמן לוח שנה |
| נעילה/תיוג (Lockout/tagout) | נהלים מוסדרים על ידי OSHA לשליטה באנרגיה מסוכנת בזמן שירות (29 CFR 1910.147) |
| [עצירות מיקרו](https://www.m365.fm/entity/micro-stops/) (עצירות קטנות) | עצירות קצרות מתחת לסף מוגדר; הפסד ביצועים |
| MTBF / MTTR | זמן ממוצע בין תקלות / זמן ממוצע לתיקון |
| OEE | יעילות ציוד כוללת = זמינות × ביצועים × איכות |
| שיעור נקודה אחת (OPL) | הוראה של עמוד אחד בנושא אחד, מועברת ליד המכונה |
| ביצועים | (זמן מחזור אידיאלי × ספירה כוללת) ÷ זמן הפעלה |
| תחזוקה מתוכננת | עמוד TPM לתחזוקה מבוססת זמן ומצב, על ידי פונקציית התחזוקה |
| אחוז תחזוקה מתוכננת | שעות תחזוקה מתוכננות ÷ סך שעות התחזוקה |
| איכות (שיעור) | ספירה תקינה ÷ ספירה כוללת |
| תחזוקת איכות (hinshitsu hozen) | עמוד TPM ששולט במצב הציוד כדי למנוע פגמים |
| שישת ההפסדים הגדולים | תקלות, הכנה והתאמה, עצירות קטנות, הפחתת מהירות, פגמים ותיקונים, הפסדי הפעלה |
| SMED | החלפת תבנית בדקה אחת, השיטה להפחתת [זמן הכנה](https://www.m365.fm/entity/setup-time/) |
| TEEP | ביצועי ציוד אפקטיביים כוללים = OEE × עומס |
</translation>
