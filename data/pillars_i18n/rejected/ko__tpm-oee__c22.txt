## TPM 및 OEE 용어집

| 용어 | 의미 |
|---|---|
| 이상 표시표(F-tag) | 청소나 점검 중 발견한 문제를 표시하기 위해 설비에 거는 꼬리표 |
| 자주보전(지슈 호젠) | 운전자가 설비의 기본 상태를 유지하고 이상을 발견하는 TPM 기둥 |
| 기본 조건 | 설비가 열화되지 않도록 유지하는 청소, 급유, 체결 |
| CILS / CILT | 청소(Clean), 점검(Inspect), 급유(Lubricate), 고정 또는 체결(Secure/Tighten): 일일 자주보전 루틴 |
| CMMS | 전산화된 보전 관리 시스템 |
| 중요도 순위 | 고장의 영향과 발생 가능성에 따라 자산에 점수를 매기는 방식 |
| 초기 설비 관리 | 신규 설비에 보전성과 운전 용이성을 설계 단계부터 반영하는 TPM 기둥 |
| 개별 개선(고베쓰 가이젠) | 특정 손실을 체계적으로 제거하기 위한 TPM 기둥 |
| 이상적 사이클 타임 | 부품 하나를 가공하는 데 가능한 최선의 시간; 성능 요소의 기준 |
| JIPM | TPM 상을 수여하는 일본설비보전협회(Japan Institute of Plant Maintenance) |
| 부하율 | 계획 생산 시간 ÷ 달력 시간 |
| 잠금/표시(Lockout/tagout) | 정비 중 위험 에너지를 통제하는 OSHA 규정 절차(29 CFR 1910.147) |
| [미세 정지](https://www.m365.fm/entity/micro-stops/)(경미 정지) | 정해진 기준값보다 짧은 정지; 성능 손실 |
| MTBF / MTTR | 평균 고장 간격 / 평균 수리 시간 |
| OEE | 종합 설비 효율 = 가동률 × 성능 가동률 × 품질률 |
| 1포인트 레슨(OPL) | 한 가지 주제를 한 장으로 정리해 설비 앞에서 가르치는 지침서 |
| 성능 가동률 | (이상적 사이클 타임 × 총 생산 수량) ÷ 가동 시간 |
| 계획 보전 | 보전 부서가 시간 기준 및 상태 기준으로 수행하는 보전을 다루는 TPM 기둥 |
| 계획 보전 비율 | 계획 보전 시간 ÷ 총 보전 시간 |
| 품질률 | 양품 수량 ÷ 총 생산 수량 |
| 품질 보전(히닌시쓰 호젠) | 결함을 예방하기 위해 설비 상태를 관리하는 TPM 기둥 |
| 6대 로스 | 고장, 셋업 및 조정, 미세 정지, 속도 저하, 불량 및 재작업, 기동 손실 |
| SMED | 금형 교환 시간을 한 자릿수 분 이내로 줄이는 방법인 단일 분 금형 교환(single-minute exchange of die); [段取り時間](https://www.m365.fm/entity/setup-time/) 단축 방법 |
| TEEP | 전체 유효 설비 성능 = OEE × 부하율 |
</translation>
