## Глоссарий TPM и OEE

| Термин | Значение |
|---|---|
| Метка аномалии (метка F) | метка, вешаемая на оборудование для обозначения проблемы, выявленной при очистке или осмотре |
| Автономное техническое обслуживание (дзисю ходзен) | опорный элемент TPM, при котором операторы поддерживают базовое состояние оборудования и выявляют отклонения |
| Базовые условия | очистка, смазка и подтяжка, которые не дают оборудованию деградировать |
| CILS / CILT | очистка, осмотр, смазка и закрепление (подтяжка): ежедневная процедура автономного обслуживания |
| CMMS | компьютеризированная система управления техническим обслуживанием |
| Ранжирование по критичности | оценка активов по влиянию и вероятности отказа |
| Раннее управление оборудованием | опорный элемент TPM, закладывающий ремонтопригодность и простоту эксплуатации в новое оборудование |
| Целенаправленное улучшение (кобэцу кайдзен) | опорный элемент TPM для структурированного устранения конкретных потерь |
| Идеальное время цикла | наилучшее возможное время на одну деталь; основа коэффициента производительности |
| JIPM | Японский институт технического обслуживания предприятий, который присуждает премии TPM |
| Загрузка | плановое время производства ÷ календарное время |
| Блокировка/маркировка (lockout/tagout) | процедуры OSHA по контролю опасной энергии при обслуживании (29 CFR 1910.147) |
| [Микроостановки](https://www.m365.fm/entity/micro-stops/) (мелкие остановки) | короткие остановки ниже заданного порога; потеря производительности |
| MTBF / MTTR | средняя наработка на отказ / среднее время восстановления |
| OEE | общая эффективность оборудования = доступность × производительность × качество |
| Однопунктовый урок (OPL) | одностраничная инструкция по одной теме, проводимая у станка |
| Производительность | (идеальное время цикла × общее количество) ÷ время работы |
| Плановое техническое обслуживание | опорный элемент TPM: обслуживание по времени и по состоянию, выполняемое службой технического обслуживания |
| Доля планового технического обслуживания | часы планового обслуживания ÷ общее количество часов обслуживания |
| Качество (коэффициент) | количество годных ÷ общее количество |
| Обслуживание качества (хинсицу ходзен) | опорный элемент TPM, контролирующий состояние оборудования для предотвращения дефектов |
| Шесть больших потерь | поломки, наладка и настройка, мелкие остановки, снижение скорости, дефекты и переделки, потери на запуске |
| SMED | быстрая переналадка за одну минуту (single-minute exchange of die), метод сокращения [времени переналадки](https://www.m365.fm/entity/setup-time/) |
| TEEP | общая эффективная производительность оборудования = OEE × загрузка |
