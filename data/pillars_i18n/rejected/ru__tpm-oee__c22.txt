## Глоссарий TPM и OEE

| Термин | Значение |
|---|---|
| Метка аномалии (F-метка) | метка, вешаемая на оборудование для обозначения проблемы, выявленной при очистке или осмотре |
| Автономное техобслуживание (дзисю ходзэн) | опора TPM, в рамках которой операторы поддерживают базовое состояние оборудования и выявляют аномалии |
| Базовые условия | очистка, смазка и затяжка, которые не дают оборудованию деградировать |
| CILS / CILT | очистка, осмотр, смазка и закрепление (затяжка): ежедневный порядок автономного техобслуживания |
| CMMS | компьютеризированная система управления техническим обслуживанием |
| Ранжирование по критичности | оценка активов по влиянию и вероятности отказа |
| Раннее управление оборудованием | опора TPM, которая закладывает в новое оборудование ремонтопригодность и удобство эксплуатации |
| Целенаправленное улучшение (кобэцу кайдзэн) | опора TPM для структурированного устранения конкретных потерь |
| Идеальное время цикла | наилучшее возможное время на одну деталь; основа коэффициента производительности |
| JIPM | Японский институт технического обслуживания предприятий, который присуждает премии TPM |
| Загрузка | плановое время производства ÷ календарное время |
| Блокировка/маркировка (lockout/tagout) | процедуры по стандарту OSHA для контроля опасной энергии при обслуживании (29 CFR 1910.147) |
| [Микроостановки](https://www.m365.fm/entity/micro-stops/) (мелкие остановки) | короткие остановки ниже заданного порога; потеря производительности |
| MTBF / MTTR | средняя наработка на отказ / среднее время восстановления |
| OEE | общая эффективность оборудования = готовность × производительность × качество |
| Однопунктовый урок (OPL) | одностраничная инструкция по одной теме, проводимая у станка |
| Производительность | (идеальное время цикла × общее количество) ÷ время работы |
| Плановое техобслуживание | опора TPM для обслуживания по времени и по состоянию, выполняемого службой технического обслуживания |
| Доля плановых работ по техобслуживанию | часы плановых работ по техобслуживанию ÷ общее количество часов техобслуживания |
| Качество (коэффициент) | количество годных ÷ общее количество |
| Планово-предупредительный ремонт качества (хинсицу ходзэн) | опора TPM, которая контролирует состояние оборудования для предотвращения дефектов |
| Шесть больших потерь | поломки, переналадка и настройка, мелкие остановки, снижение скорости, дефекты и переделки, потери на пуске |
| SMED | быстрая переналадка за одну минуту (single-minute exchange of die), метод сокращения [времени переналадки](https://www.m365.fm/entity/setup-time/) |
| TEEP | общая эффективная производительность оборудования = OEE × загрузка |
