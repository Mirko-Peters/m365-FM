## Глоссарий

| Термин | Значение |
|---|---|
| Обнаружение аномалий | Методы, которые изучают нормальное поведение и выявляют отклонения без необходимости в примерах отказов |
| Состояние «как найдено» (as-found) | То, что техник фактически обнаруживает при вскрытии или снятии компонента; эталон для оценки сигналов тревоги |
| BPFO / BPFI / FTF / BSF | Характерные частоты дефектов подшипников: частота прохождения тел качения по наружному кольцу, по внутреннему кольцу, основная частота сепаратора (клети), частота вращения тел качения |
| CBM (обслуживание по состоянию) | Обслуживание, запускаемое при пересечении измеряемым параметром состояния заданного предела |
| CMMS / EAM | Компьютеризированная система управления техобслуживанием / управление активами предприятия; здесь хранятся наряды на работы, данные об активах и история |
| Ранжирование по критичности | Структурированная оценка активов по последствиям и вероятности отказа |
| Периферийные вычисления (edge computing) | Обработка данных вблизи оборудования (шлюз, промышленный ПК) до их передачи дальше |
| Анализ огибающей | Метод вибродиагностики, при котором демодулируются высокочастотные удары, что позволяет выявлять ранние дефекты подшипников и зубчатых передач |
| ESA / MCSA | Анализ электрической сигнатуры / анализ сигнатуры тока двигателя; диагностика по току и напряжению питания двигателя |
| БПФ (FFT) | Быстрое преобразование Фурье; переводит временной сигнал в его частотный спектр |
| Функциональный отказ (F) | Момент, когда актив больше не может выполнять требуемую функцию |
| IIoT | Промышленный интернет вещей: подключенные датчики, устройства и программное обеспечение в промышленных условиях |
| ISO 13374 | Серия стандартов ISO по обработке данных, обмену ими и их представлению для мониторинга состояния и диагностики |
| ISO 17359 | Общие рекомендации по созданию программы мониторинга состояния |
| ISO 20816 | Измерение и оценка вибрации машин (серия, пришедшая на смену ISO 10816) |
| MQTT | Легковесный протокол обмена сообщениями по модели «издатель/подписчик», стандарт OASIS |
| MTBF / MTTR | Средняя наработка на отказ / среднее время восстановления |
| Чистый интервал P-F | Интервал P-F минус интервал между проверками: то предупреждение, на которое действительно можно рассчитывать |
| Кривая P-F / интервал P-F | Кривая изменения состояния во времени от обнаруживаемого потенциального отказа (P) до функционального отказа (F); время между ними |
| PdM (предиктивное обслуживание) | Обслуживание, назначаемое по измеренному состоянию и прогнозу его развития |
| Соответствие плану ТО (PM compliance) | Доля плановых работ по профилактическому обслуживанию, выполненных в согласованный срок |
| Точность / полнота (precision / recall) | Доля сигналов тревоги, которые оказались реальными / доля реальных отказов, о которых своевременно поступил сигнал |
| Предписывающее обслуживание (prescriptive) | Обслуживание, при котором система также рекомендует действие и срок его выполнения |
| RCM (надежностно-ориентированное обслуживание) | Структурированный метод выбора подходящей задачи ТО для каждого вида отказа на основе его последствий |
| RUL (остаточный ресурс) | Оценка времени или количества циклов до достижения активом заданного предельного состояния отказа |
| Sparkplug | Спецификация Eclipse, которая добавляет к MQTT промышленные соглашения, включая управление состоянием устройств |
| Единое пространство имен (UNS) | Архитектурный шаблон, в котором системы публикуют и получают данные в едином иерархическом структурированном пространстве тем |
| Распределение Вейбулла | Статистическое распределение времени до отказа; его параметр формы показывает поведение на ранней стадии, случайные отказы или износовые отказы |
</translation>
