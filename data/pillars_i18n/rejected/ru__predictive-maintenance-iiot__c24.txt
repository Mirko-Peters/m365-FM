## Глоссарий

| Термин | Значение |
|---|---|
| Обнаружение аномалий | Методы, которые изучают нормальное поведение и отмечают отклонения, без необходимости в примерах отказов |
| Состояние «как найдено» (as-found) | То, что техник фактически обнаруживает при вскрытии или снятии компонента; эталон истинности для сигналов тревоги |
| BPFO / BPFI / FTF / BSF | Характеристические частоты дефектов подшипника: частота прохождения тел качения по наружному кольцу, по внутреннему кольцу, основная частота сепаратора (клети), частота вращения тел качения |
| CBM (техническое обслуживание по состоянию) | Обслуживание, запускаемое, когда измеряемое состояние пересекает предельное значение |
| CMMS / EAM | Компьютеризированная система управления техническим обслуживанием / управление активами предприятия; здесь хранятся заказы-наряды, активы и история |
| Ранжирование по критичности | Структурированная оценка активов по последствиям и вероятности отказа |
| Периферийные вычисления (edge computing) | Обработка данных вблизи оборудования (шлюз, промышленный ПК) перед их передачей дальше |
| Анализ огибающей | Метод вибродиагностики, который демодулирует высокочастотные импульсы и выявляет ранние дефекты подшипников и зубчатых передач |
| ESA / MCSA | Анализ электрического сигнатуры / анализ сигнатуры тока двигателя; диагностика по току и напряжению питания двигателя |
| БПФ (FFT) | Быстрое преобразование Фурье; преобразует временной сигнал в его частотный спектр |
| Функциональный отказ (F) | Момент, когда актив больше не может выполнять требуемую функцию |
| IIoT | Промышленный интернет вещей: подключённые датчики, устройства и программное обеспечение в промышленной среде |
| ISO 13374 | Серия стандартов ISO по обработке данных, обмену и представлению информации для мониторинга состояния и диагностики |
| ISO 17359 | Общие указания по организации программы мониторинга состояния |
| ISO 20816 | Измерение и оценка вибрации машин (серия-преемник ISO 10816) |
| MQTT | Облегчённый протокол обмена сообщениями по модели публикации и подписки, стандарт OASIS |
| MTBF / MTTR | Средняя наработка на отказ / среднее время восстановления |
| Чистый интервал P-F | Интервал P-F минус интервал контроля: предупреждение, на которое можно реально рассчитывать |
| Кривая P-F / интервал P-F | Кривая изменения состояния во времени от обнаруживаемого потенциального отказа (P) до функционального отказа (F); время между ними |
| PdM (предиктивное обслуживание) | Обслуживание, назначаемое по измеренному состоянию и прогнозу его развития |
| Соблюдение плана ППР | Доля плановых работ по профилактическому обслуживанию, выполненных в согласованный срок |
| Точность / полнота | Доля сигналов тревоги, которые оказались реальными / доля реальных отказов, о которых предупреждено вовремя |
| Прескриптивное обслуживание | Обслуживание, при котором система также рекомендует действие и его сроки |
| RCM (обслуживание, ориентированное на надёжность) | Структурированный метод выбора правильного вида обслуживания для каждого вида отказа на основе его последствий |
| RUL (остаточный ресурс) | Оценка времени или циклов до достижения актива заданного предельного состояния отказа |
| Sparkplug | Спецификация Eclipse, которая добавляет промышленные соглашения, включая управление состоянием устройств, поверх MQTT |
| Единое пространство имён (UNS) | Архитектурный шаблон, в котором системы публикуют и потребляют данные в едином иерархическом структуре тем |
| Распределение Вейбулла | Статистическое распределение времён отказа; его параметр формы показывает поведение на ранней стадии, случайное или износовое |
</translation>
