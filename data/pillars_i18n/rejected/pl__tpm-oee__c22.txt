## Glosariusz TPM i OEE

| Termin | Znaczenie |
|---|---|
| Etykieta nieprawidłowości (F-tag) | etykieta zawieszana na urządzeniu w celu oznaczenia problemu wykrytego podczas czyszczenia lub przeglądu |
| Autonomiczne utrzymanie ruchu (jishu hozen) | filar TPM, w którym operatorzy utrzymują podstawowy stan urządzeń i wykrywają nieprawidłowości |
| Podstawowe warunki | czyszczenie, smarowanie i dokręcanie, które zapobiegają pogarszaniu się stanu urządzeń |
| CILS / CILT | czyszczenie, sprawdzanie, smarowanie i zabezpieczanie lub dokręcanie: codzienna rutyna autonomicznego utrzymania ruchu |
| CMMS | komputerowy system zarządzania utrzymaniem ruchu |
| Ranking krytyczności | ocena zasobów według wpływu i prawdopodobieństwa awarii |
| Wczesne zarządzanie urządzeniami | filar TPM, który uwzględnia łatwość utrzymania ruchu i obsługi już na etapie projektowania nowych urządzeń |
| Ukierunkowane doskonalenie (kobetsu kaizen) | filar TPM służący systematycznemu eliminowaniu konkretnych strat |
| Idealny czas cyklu | najlepszy możliwy czas wytworzenia jednej sztuki; podstawa współczynnika wydajności |
| JIPM | Japan Institute of Plant Maintenance, instytucja przyznająca nagrody TPM |
| Obciążenie | planowany czas produkcji ÷ czas kalendarzowy |
| Lockout/tagout | procedury OSHA kontrolujące niebezpieczną energię podczas prac serwisowych (29 CFR 1910.147) |
| [Mikropostoje](https://www.m365.fm/entity/micro-stops/) (drobne postoje) | krótkie zatrzymania poniżej określonego progu; strata wydajności |
| MTBF / MTTR | średni czas między awariami / średni czas naprawy |
| OEE | całkowita efektywność urządzeń = dostępność × wydajność × jakość |
| Lekcja jednego punktu (OPL) | jednostronicowa instrukcja dotycząca jednego tematu, przekazywana przy maszynie |
| Wydajność | (idealny czas cyklu × łączna liczba sztuk) ÷ czas pracy |
| Planowe utrzymanie ruchu | filar TPM obejmujący utrzymanie ruchu oparte na czasie i na stanie technicznym, realizowane przez funkcję utrzymania ruchu |
| Odsetek planowego utrzymania ruchu | godziny planowego utrzymania ruchu ÷ łączne godziny utrzymania ruchu |
| Jakość (wskaźnik) | liczba dobrych sztuk ÷ łączna liczba sztuk |
| Utrzymanie jakości (hinshitsu hozen) | filar TPM kontrolujący stan urządzeń w celu zapobiegania wadom |
| Sześć wielkich strat | awarie, przezbrojenia i regulacje, drobne postoje, obniżona prędkość, wady i poprawki, straty rozruchowe |
| SMED | szybka wymiana narzędzi w czasie jednej minuty (single-minute exchange of die), metoda skracania [czasu przezbrojenia](https://www.m365.fm/entity/setup-time/) |
| TEEP | całkowita skuteczna wydajność urządzeń = OEE × obciążenie |
