## 18. מילון מונחים

| מונח | הסבר |
|---|---|
| תכנון וזימון מתקדמים (APS) | תוכנה לתכנון וזימון מוגבל קיבולת |
| סימולציה מבוססת סוכנים (ABS) | מידול של יחידות אוטונומיות (סוכנים) בעלות כללים משלהן, שהאינטראקציה ביניהן יוצרת את התנהגות המערכת |
| AGV / AMR | רכב מונחה אוטומטי / רובוט ניידת אוטונומי [53][54] |
| Asset Administration Shell (AAS) | ייצוג דיגיטלי תקני של נכס בהתאם ל-IEC 63278 [10] |
| צוואר בקבוק (אילוץ) | משאב המגביל את קצב התפוקה של המערכת כולה [39] |
| מפעל דיגיטלי | מונח כולל למודלים, שיטות וכלים דיגיטליים לתכנון ושיפור המפעל האמיתי (הנחיה גרמנית VDI 4499) [16][17] |
| מודל דיגיטלי | ייצוג דיגיטלי ללא החלפת נתונים אוטומטית עם האובייקט הפיזי [5] |
| צל דיגיטלי | ייצוג עם זרימת נתונים אוטומטית מהפיזי לדיגיטלי, אך זרימה חזרה ידנית [5] |
| חוט דיגיטלי | קישור מחובר של מידע לאורך מחזור החיים; מטופל ב-ISO 23247-5 [7] |
| תאום דיגיטלי | ייצוג עם זרימת נתונים אוטומטית בשני הכיוונים [5]; נעשה בו שימוש רחב יותר בפרקטיקה |
| סימולציה מבוססת אירועים בדידים (DES) | סימולציה שבה השעון קופץ מאירוע לאירוע; התקן בסימולציית ייצור |
| DTDL | Digital Twins Definition Language, שפת מידול מבוססת JSON עבור Azure Digital Twins [22] |
| ERP | תכנון משאבי הארגון, מערכת העסק המרכזית הכוללת נתוני אב, הזמנות ותכנון חומרים |
| HiL / SiL / MiL | לולאה חומרתית / תוכנתית / מודלית: גרסאות צימוד להפעלה וירטואלית |
| ISA-95 / IEC 62264 | סדרת תקנים לשילוב מערכות ארגוניות ומערכות בקרה [58] |
| חוק Little | L = λ · W: המלאי הממוצע שווה לקצב התפוקה כפול זמן ההובלה במצב יציב [37] |
| סימולציית זרימת חומרים | סימולציה של זרימות חומרים והזמנות דרך הייצור והלוגיסטיקה, בדרך כלל אירועים בדידים |
| MBOM / EBOM | רשימת חומרים לייצור / רשימת חומרים להנדסה |
| MES | מערכת ביצוע ייצור, ניהול תפעולי ברמה 3 של ISA-95 |
| MTConnect | תקן פתוח לפעולה הדדית של נתוני ייצור, שפורסם כ-ANSI/MTC1.4-2018 [57] |
| OPC UA | תקן תקשורת בלתי תלוי ספק עם מודלי מידע (IEC 62541) |
| מודל PPR | מודל מוצר-תהליך-משאב, עיקרון המבנה של המפעל הדיגיטלי |
| שכפול | הרצה חוזרת של סימולציה עם מספרים אקראיים שונים לצורך רמת ביטחון סטטיסטית [41] |
| אימות תוקף (Validation) | בדיקה האם המודל מייצג את המציאות בדיוק מספיק למטרתו |
| בדיקת נכונות מימוש (Verification) | בדיקה האם המודל מומש נכון |
| הפעלה וירטואלית (Virtual commissioning) | בדיקת תוכנת בקרה מול מודל סימולציה לפני ההפעלה הפיזית [14] |
| VVUQ | אימות, אימות תוקף וכימות אי-ודאות; הוצע על ידי NIST כחלק עתידי של ISO 23247 [48] |
| תקופת חימום | שלב ראשוני של הרצת סימולציה שתוצאותיו נזרקות בשל מצב ההתחלה הריק |
