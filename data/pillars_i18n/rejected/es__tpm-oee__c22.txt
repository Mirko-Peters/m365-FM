## Glosario de TPM y OEE

| Término | Significado |
|---|---|
| Etiqueta de anomalía (F-tag) | etiqueta colocada en el equipo para marcar un problema encontrado durante la limpieza o la inspección |
| Mantenimiento autónomo (jishu hozen) | pilar del TPM en el que los operarios mantienen las condiciones básicas del equipo y detectan anomalías |
| Condiciones básicas | limpieza, lubricación y apriete que evitan que el equipo se deteriore |
| CILS / CILT | limpiar, inspeccionar, lubricar y asegurar o apretar: la rutina diaria de mantenimiento autónomo |
| CMMS | sistema informatizado de gestión del mantenimiento |
| Clasificación por criticidad | puntuación de los activos según el impacto y la probabilidad de fallo |
| Gestión temprana del equipo | pilar del TPM que incorpora la mantenibilidad y la facilidad de operación en los equipos nuevos |
| Mejora focalizada (kobetsu kaizen) | pilar del TPM para eliminar de forma estructurada pérdidas específicas |
| Tiempo de ciclo ideal | mejor tiempo posible por pieza; base del factor de rendimiento |
| JIPM | Japan Institute of Plant Maintenance, que otorga los premios TPM |
| Carga | tiempo de producción planificado ÷ tiempo calendario |
| Bloqueo/etiquetado (lockout/tagout) | procedimientos regulados por OSHA para controlar la energía peligrosa durante las intervenciones (29 CFR 1910.147) |
| [Microparadas](https://www.m365.fm/entity/micro-stops/) (paradas menores) | paradas breves por debajo de un umbral definido; una pérdida de rendimiento |
| MTBF / MTTR | tiempo medio entre fallos / tiempo medio de reparación |
| OEE | eficacia global del equipo = disponibilidad × rendimiento × calidad |
| Lección de un punto (OPL) | instrucción de una sola página sobre un tema, impartida junto a la máquina |
| Rendimiento | (tiempo de ciclo ideal × recuento total) ÷ tiempo de funcionamiento |
| Mantenimiento planificado | pilar del TPM para el mantenimiento basado en el tiempo y en la condición, realizado por la función de mantenimiento |
| Porcentaje de mantenimiento planificado | horas de mantenimiento planificado ÷ horas totales de mantenimiento |
| Calidad (tasa) | recuento de piezas buenas ÷ recuento total |
| Mantenimiento de la calidad (hinshitsu hozen) | pilar del TPM que controla las condiciones del equipo para prevenir defectos |
| Seis grandes pérdidas | averías, preparación y ajuste, microparadas, reducción de velocidad, defectos y retrabajos, pérdidas de arranque |
| SMED | cambio de herramental en un solo minuto (single-minute exchange of die), método para reducir el [tiempo de preparación](https://www.m365.fm/entity/setup-time/) |
| TEEP | rendimiento efectivo total del equipo = OEE × carga |
