## قاموس TPM وOEE

| المصطلح | المعنى |
|---|---|
| بطاقة الشذوذ (F-tag) | بطاقة تُعلَّق على المعدة للإشارة إلى مشكلة وُجدت أثناء التنظيف أو الفحص |
| الصيانة الذاتية (jishu hozen) | ركيزة TPM يحافظ فيها المشغّلون على الظروف الأساسية للمعدات ويكتشفون الشذوذ |
| الظروف الأساسية | التنظيف والتشحيم وإحكام الشد التي تمنع تدهور المعدات |
| CILS / CILT | التنظيف والفحص والتشحيم والتأمين أو الشد: روتين الصيانة الذاتية اليومي |
| CMMS | نظام الحاسوب لإدارة الصيانة |
| ترتيب الأهمية | تقييم الأصول حسب أثر العطل واحتمال حدوثه |
| إدارة المعدات في مرحلة التصميم | ركيزة TPM التي تُدخل قابلية الصيانة وسهولة التشغيل في المعدات الجديدة |
| التحسين المركّز (kobetsu kaizen) | ركيزة TPM للتخلص المنظّم من خسائر محددة |
| زمن الدورة المثالي | أفضل زمن ممكن لكل قطعة؛ وهو أساس عامل الأداء |
| JIPM | المعهد الياباني لصيانة المصانع، الذي يمنح جوائز TPM |
| نسبة التحميل | زمن الإنتاج المخطط ÷ الزمن التقويمي |
| قفل الطاقة وتعليمها (Lockout/tagout) | إجراءات تنظمها OSHA للتحكم في الطاقة الخطرة أثناء الصيانة (29 CFR 1910.147) |
| [التوقفات الصغيرة](https://www.m365.fm/entity/micro-stops/) (minor stops) | توقفات قصيرة أقل من حد محدد؛ وهي خسارة في الأداء |
| MTBF / MTTR | متوسط الزمن بين الأعطال / متوسط زمن الإصلاح |
| OEE | الفعالية الشاملة للمعدات = التوفر × الأداء × الجودة |
| الدرس النقطي الواحد (OPL) | تعليمات من صفحة واحدة حول موضوع واحد، تُلقَّن عند الآلة |
| الأداء | (زمن الدورة المثالي × إجمالي العدد) ÷ زمن التشغيل |
| الصيانة المخططة | ركيزة TPM للصيانة المبنية على الزمن والحالة، تنفذها وظيفة الصيانة |
| نسبة الصيانة المخططة | ساعات الصيانة المخططة ÷ إجمالي ساعات الصيانة |
| الجودة (المعدل) | عدد الجيد ÷ إجمالي العدد |
| صيانة الجودة (hinshitsu hozen) | ركيزة TPM تتحكم في ظروف المعدات لمنع العيوب |
| الخسائر الست الكبرى | الأعطال، والإعداد والضبط، والتوقفات الصغيرة، وتخفيض السرعة، والعيوب وإعادة العمل، وخسائر بدء التشغيل |
| SMED | تبديل القالب في أقل من دقيقة، وهو الأسلوب لتقليل [زمن الإعداد](https://www.m365.fm/entity/setup-time/) |
| TEEP | الأداء الفعّال الشامل للمعدات = OEE × نسبة التحميل |
