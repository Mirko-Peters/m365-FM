## 用語集

| 用語 | 意味 |
|---|---|
| 異常検知 | 正常な挙動を学習し、逸脱を検出する手法。故障事例は不要 |
| 発見時状態（as-found condition） | 技術者が部品を開放または取り外したときに実際に確認する状態。アラートの正解データ |
| BPFO / BPFI / FTF / BSF | ベアリングの特性欠陥周波数：外輪通過周波数（BPFO）、内輪通過周波数（BPFI）、保持器周波数（FTF）、転動体自転周波数（BSF） |
| CBM（状態基準保全） | 測定された状態が限界値を超えたときに実施される保全 |
| CMMS / EAM | コンピュータ化保全管理システム / 企業資産管理。作業指示、設備情報、履歴を管理する場所 |
| 重要度ランキング | 故障の影響度と発生可能性に基づき、設備を構造的にスコアリングすること |
| エッジコンピューティング | データを送信する前に、機械の近く（ゲートウェイや産業用PCなど）で処理すること |
| エンベロープ解析 | 高周波の衝撃成分を復調し、ベアリングや歯車の初期欠陥を明らかにする振動解析手法 |
| ESA / MCSA | 電気シグネチャ解析 / モータ電流シグネチャ解析。モータの電源電流と電圧から診断を行う |
| FFT | 高速フーリエ変換。時間信号を周波数スペクトルに変換する |
| 機能故障（F） | 設備が要求された機能を果たせなくなる時点 |
| IIoT | 産業用モノのインターネット。産業分野で接続されたセンサ、機器、ソフトウェア |
| ISO 13374 | 状態監視と診断のためのデータ処理、通信、提示に関するISO規格シリーズ |
| ISO 17359 | 状態監視プログラムを構築するための一般指針 |
| ISO 20816 | 機械振動の測定と評価（ISO 10816の後継シリーズ） |
| MQTT | 軽量なパブリッシュ/サブスクライブ型メッセージングプロトコル。OASIS規格 |
| MTBF / MTTR | 平均故障間隔 / 平均修復時間 |
| 正味P-F間隔 | P-F間隔から点検間隔を差し引いた値。実際に当てにできる警告の時間 |
| P-F曲線 / P-F間隔 | 検出可能な潜在故障（P）から機能故障（F）に至るまでの状態の時間推移曲線、およびその間の時間 |
| PdM（予知保全） | 測定された状態と、その推移の予測に基づいて時期を決める保全 |
| PM遵守率 | 期限が来た予防保全の作業指示のうち、合意された期間内に完了した割合 |
| 適合率 / 再現率 | アラートのうち実際の故障であった割合 / 実際の故障のうち、適時にアラートが出された割合 |
| 処方的保全（prescriptive maintenance） | システムが対応策とその時期も推奨する保全 |
| RCM（信頼性中心保全） | 故障モードごとの影響に基づき、適切な保全作業を選定する構造化された手法 |
| RUL（残存耐用寿命） | 設備が定められた故障限界に達するまでの推定時間または推定サイクル数 |
| Sparkplug | MQTTの上に、デバイス状態管理を含む産業向けの規約を加えたEclipseの仕様 |
| 統合名前空間（UNS） | システムがデータを、単一の共有された階層的トピック構造に発行し、利用するアーキテクチャパターン |
| ワイブル分布 | 故障時間のための統計分布。その形状パラメータは初期故障、偶発故障、摩耗故障のいずれかの挙動を示す |
