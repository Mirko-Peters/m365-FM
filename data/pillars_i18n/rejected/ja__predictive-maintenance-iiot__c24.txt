## 用語集

| 用語 | 意味 |
|---|---|
| 異常検知 | 正常な挙動を学習し、逸脱を検出する手法。故障事例は不要 |
| 発見時状態（As-found condition） | 技術者が部品を開放または取り外したときに実際に確認される状態。アラートの正解データ |
| BPFO / BPFI / FTF / BSF | 軸受の特性欠陥周波数：外輪欠陥周波数（BPFO）、内輪欠陥周波数（BPFI）、保持器周波数（FTF）、ボール自転周波数（BSF） |
| 状態基準保全（CBM） | 測定された状態が限界値を超えたときに実施される保全 |
| CMMS / EAM | 保全管理システム（CMMS）／企業資産管理（EAM）。作業指示、設備、履歴を管理する場所 |
| 重要度ランキング | 故障の影響度と発生可能性に基づき、設備を構造的にスコア付けすること |
| エッジコンピューティング | データを送信する前に、機械の近傍（ゲートウェイや産業用PC）で処理すること |
| エンベロープ解析 | 高周波の衝撃を復調し、軸受や歯車の初期欠陥を明らかにする振動解析手法 |
| ESA / MCSA | 電気シグネチャ解析（ESA）／モーター電流シグネチャ解析（MCSA）。モーターの電源電流と電圧から診断を行う |
| FFT | 高速フーリエ変換。時間信号を周波数スペクトルに変換する |
| 機能停止（F） | 設備が要求される機能を果たせなくなる時点 |
| IIoT | 産業用IoT。産業分野で接続されたセンサー、機器、ソフトウェア |
| ISO 13374 | 状態監視および診断のためのデータ処理、通信、表示に関するISO規格シリーズ |
| ISO 17359 | 状態監視プログラムを構築するための一般的指針 |
| ISO 20816 | 機械振動の測定および評価（ISO 10816の後継シリーズ） |
| MQTT | 軽量なパブリッシュ／サブスクライブ型メッセージングプロトコル。OASIS標準 |
| MTBF / MTTR | 平均故障間隔（MTBF）／平均修復時間（MTTR） |
| 正味P-F間隔 | P-F間隔から点検間隔を差し引いたもの。実際に当てにできる警告時間 |
| P-Fカーブ / P-F間隔 | 検知可能な潜在故障（P）から機能停止（F）までの、状態の時間推移曲線およびその間の時間 |
| PdM（予知保全） | 測定された状態とその進展の予測に基づいて時期を決める保全 |
| PM遵守率 | 期日が到来した予防保全作業指示のうち、合意された期間内に完了した割合 |
| 適合率 / 再現率 | 適合率：アラートのうち実際の故障であった割合。再現率：実際の故障のうち、適時にアラートされた割合 |
| 規範的保全（Prescriptive maintenance） | システムが対応策とそのタイミングも提案する保全 |
| RCM（信頼性中心保全） | 故障モードごとに、その影響に基づいて適切な保全作業を選定する構造化された手法 |
| RUL（残存有効寿命） | 設備が定められた故障限界に達するまでの推定時間または推定サイクル数 |
| Sparkplug | MQTTの上に、デバイス状態管理を含む産業向けの規約を加えるEclipse仕様 |
| 統合名前空間（UNS） | システムがひとつの共有された階層的トピック構造でデータを公開・利用するアーキテクチャのパターン |
| ワイブル分布 | 故障時間の統計分布。その形状パラメータは初期故障、偶発故障、摩耗故障の傾向を示す |
</translation>
