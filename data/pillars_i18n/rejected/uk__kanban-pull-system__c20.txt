## Глосарій канбану

| Термін | Визначення |
|---|---|
| Кількість у контейнері (кількість упаковки) | Фіксована кількість деталей на один канбан; одиниця контуру |
| CONWIP | Постійна незавершена робота (Constant work in process); система витягування з одним набором карток для всієї лінії [3][5] |
| Барабан-буфер-мотузка (DBR) | Метод управління з теорії обмежень: обмеження задає темп, часовий буфер його захищає, запуск прив'язаний до нього |
| E-kanban | Електронний сигнал канбану, який спрацьовує від сканування або датчика [10] |
| Аварійний канбан | Тимчасова додаткова картка для подолання дефіциту; знімається після використання |
| Черга FIFO | Черга з максимальною кількістю між двома процесами, перший прийшов — перший пішов |
| Хейдзюнка | Вирівнювання типу та обсягу виробництва протягом фіксованого періоду [18] |
| Коробка хейдзюнки | Візуальний графік з типами продукції по одній осі та часовими слотами (піч) по іншій [18] |
| Точно в строк (JIT) | Виробництво лише того, що потрібно, тоді, коли потрібно, і в потрібній кількості [8] |
| Канбан | Сигнальний пристрій, що дозволяє виробництво або переміщення в системі витягування; японською «знак» або «вивіска» [1] |
| Канбан-пост | Коробка або стійка, де збираються канбани для забирання |
| Закон Літтла | Середній WIP = пропускна здатність × середній час виконання [6] |
| Контур | Одне відношення постачальник–споживач для однієї номенклатурної позиції з її набором канбанів |
| Пейсмейкер | Єдиний процес, який отримує графік виробництва |
| Піч | Час на виготовлення одного контейнера: такт × кількість упаковки [19] |
| POLCA | Парні комірки з перекриваними контурами карток та авторизацією; витягування для цехів із великою номенклатурою та малими обсягами [20][21] |
| Виробничий канбан | Картка, що дозволяє процесу виготовити певний тип і кількість [1] |
| Система витягування | Виробнича система, що явно обмежує WIP [2] |
| Система проштовхування | Система, що запускає роботу за графіком без обмеження WIP |
| Час поповнення | Час від вичерпання контейнера (повернення його картки) до повернення повного контейнера в місце зберігання |
| Runners, repeaters, strangers | Сегментація деталей за регулярністю попиту, що використовується для вибору між канбаном і виробництвом під замовлення |
| Коефіцієнт безпеки | Відсоток, доданий до попиту під час поповнення для покриття коливань |
| Сигнальний канбан (трикутний канбан) | Картка, що запускає партію, коли запас досягає точки запуску [1] |
| Супермаркет | Контрольована точка зберігання з фіксованими адресами та максимальними кількостями, з якої нижчий процес забирає матеріали |
| Канбан постачальника | Канбан на вилучення до зовнішнього постачальника, часто електронний [1] |
| Такт | Доступний час, поділений на попит клієнта |
| Система двох бінів | Два контейнери на деталь; порожній бін є сигналом поповнення [10] |
| Канбан вилучення | Картка, що дозволяє переміщення деталей до нижчого процесу [1] |
| WIP | Незавершене виробництво: матеріал, що розпочато, але не завершено |
