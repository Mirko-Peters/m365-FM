## Kanban-woordenlijst

| Term | Definitie |
|---|---|
| Containerhoeveelheid (pack-out-hoeveelheid) | Vast aantal onderdelen per kanban; de eenheid van de lus |
| CONWIP | Constant work in process; een pull-systeem met één set kaarten voor een hele lijn [3][5] |
| Drum-buffer-rope (DBR) | Beheersmethode uit de theorie van beperkingen: de beperking bepaalt het tempo, een tijdbuffer beschermt die, en de vrijgave wordt daarop afgestemd |
| E-kanban | Elektronisch kanbansignaal, geactiveerd door scan of sensor [10] |
| Noodkanban | Tijdelijke extra kaart om te herstellen van een tekort; wordt na gebruik ingetrokken |
| FIFO-baan | Wachtrij met een maximale hoeveelheid tussen twee processen, eerst in, eerst uit |
| Heijunka | Egaliseren van het type en de hoeveelheid productie over een vaste periode [18] |
| Heijunkabox | Visueel schema met producttypes op de ene as en tijdvakken (pitch) op de andere [18] |
| Just-in-time (JIT) | Alleen maken wat nodig is, wanneer het nodig is, in de benodigde hoeveelheid [8] |
| Kanban | Signaalmiddel dat productie of afname in een pull-systeem autoriseert; Japans voor "signaal" of "uithangbord" [1] |
| Kanbanpost | Bak of rek waarin kanbans worden verzameld voor afhaling |
| Wet van Little | Gemiddelde WIP = doorvoer × gemiddelde doorlooptijd [6] |
| Lus | Eén leverancier-verbruikerrelatie voor één artikelnummer met de bijbehorende kanbans |
| Pacemaker | Het enkele proces dat het productieschema ontvangt |
| Pitch | Tijd om één container te maken: takttijd × pack-out-hoeveelheid [19] |
| POLCA | Paired-cell overlapping loops of cards with authorization; pull voor high-mix, low-volume bedrijven [20][21] |
| Productiekanban | Kaart die een proces autoriseert om een type en hoeveelheid te maken [1] |
| Pull-systeem | Een productiesysteem dat WIP expliciet beperkt [2] |
| Push-systeem | Een systeem dat werk volgens een schema vrijgeeft zonder WIP-plafond |
| Aanvuldoorlooptijd | Tijd vanaf het leegmaken van een container (het vrijgeven van de kaart) tot de volle container weer op zijn opslagpunt staat |
| Runners, repeaters, strangers | Segmentatie van onderdelen op basis van de regelmatigheid van de vraag, gebruikt om te kiezen tussen kanban en make-to-order |
| Veiligheidsfactor | Percentage dat tijdens het aanvullen aan de vraag wordt toegevoegd om variatie op te vangen |
| Signaalkanban (driehoekkanban) | Kaart die een batch activeert wanneer de voorraad een triggerpunt bereikt [1] |
| Supermarkt | Gecontroleerd voorraadpunt met vaste adressen en maximale hoeveelheden, waaruit het stroomafwaartse proces afneemt |
| Leverancierskanban | Afnamekanban naar een externe leverancier, vaak elektronisch [1] |
| Takttijd | Beschikbare tijd gedeeld door de klantvraag |
| Tweebaksysteem | Twee containers per onderdeel; een lege bak is het aanvulsignaal [10] |
| Afnamekanban | Kaart die het verplaatsen van onderdelen naar een stroomafwaarts proces autoriseert [1] |
| WIP | Work in process: materiaal dat is gestart maar nog niet af is |
