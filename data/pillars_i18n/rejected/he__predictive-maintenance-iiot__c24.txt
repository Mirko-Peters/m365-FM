## מילון מונחים

| מונח | משמעות |
|---|---|
| זיהוי אנומליות | שיטות שלומדות התנהגות תקינה ומסמנות סטיות ממנה, ללא צורך בדוגמאות של כשלים |
| מצב כפי שנמצא (As-found) | מה שהטכנאי בפועל מוצא כשהוא פותח או מוציא רכיב; זהו הבסיס לאמיתות של ההתראות |
| BPFO / BPFI / FTF / BSF | תדירויות פגם אופייניות של מיסבים: תדירות מעבר כדור בטבעת החיצונית, בטבעת הפנימית, תדירות הכלוב היסודית (cage), ותדירות סיבוב הכדור סביב צירו |
| CBM (תחזוקה מבוססת מצב) | תחזוקה שמופעלת כאשר מצב הנמדד חוצה גבול מוגדר |
| CMMS / EAM | מערכת לניהול תחזוקה ממוחשבת / ניהול נכסים ארגוני; המקום שבו נמצאים פקודות עבודה, נכסים והיסטוריה |
| דירוג קריטיות | דירוג מובנה של נכסים לפי ההשלכות והסבירות לכשל |
| מחשוב קצה (Edge computing) | עיבוד נתונים קרוב למכונה (שער תקשורת, מחשב תעשייתי) לפני שליחתם הלאה |
| ניתוח עטיפה (Envelope analysis) | טכניקת רטט שמפרקת פעימות בתדר גבוה כדי לחשוף פגמים מוקדמים במיסבים ובהילוכים |
| ESA / MCSA | ניתוח חתימה חשמלית / ניתוח חתימת זרם מנוע; אבחון מזרם וממתח אספקת המנוע |
| FFT | טרנספורמציית פורייה מהירה; ממירה אות בזמן לספקטרום התדרים שלו |
| כשל תפקודי (F) | הנקודה שבה נכס אינו יכול עוד לבצע את התפקוד הנדרש ממנו |
| IIoT | האינטרנט התעשייתי של הדברים: חיישנים, התקנים ותוכנה מחוברים בסביבה תעשייתית |
| ISO 13374 | סדרת תקני ISO לעיבוד נתונים, תקשורת והצגה לניטור מצב ואבחון |
| ISO 17359 | הנחיות כלליות להקמת תוכנית לניטור מצב |
| ISO 20816 | מדידה והערכה של רטט מכונות (הסדרה שמחליפה את ISO 10816) |
| MQTT | פרוטוקול הודעות קל משקל מסוג פרסום/מנוי, תקן של OASIS |
| MTBF / MTTR | זמן ממוצע בין כשלים / זמן ממוצע לתיקון |
| מרווח P-F נטו | מרווח P-F פחות מרווח הבדיקה: ההתראה שאפשר לסמוך עליה בפועל |
| עקומת P-F / מרווח P-F | עקומת המצב לאורך זמן, מכשל פוטנציאלי הניתן לזיהוי (P) ועד לכשל תפקודי (F); הזמן שביניהם |
| PdM (תחזוקה חזויה) | תחזוקה שמתוזמנת לפי מצב נמדד בתוספת תחזית להתפתחותו |
| עמידה בתחזוקה מונעת (PM compliance) | שיעור פקודות העבודה לתחזוקה מונעת שהגיעו לביצוע ובוצעו בתוך החלון המוסכם |
| דיוק / כיסוי (Precision / recall) | שיעור ההתראות שהיו אמיתיות / שיעור הכשלים האמיתיים שנתפסו בהתראה בזמן |
| תחזוקה preskriptivית (Prescriptive maintenance) | תחזוקה שבה המערכת גם ממליצה על הפעולה ועל תזמונה |
| RCM (תחזוקה מרכזת אמינות) | שיטה מובנית לבחירת משימת התחזוקה המתאימה לכל מנגנון כשל, על בסיס השלכותיו |
| RUL (אורך חיים שנותר) | הערכה של הזמן או המחזורים עד שנכס מגיע לגבול כשל מוגדר |
| Sparkplug | מפרט של Eclipse שמוסיף מוסכמות תעשייתיות, כולל ניהול מצב התקנים, מעל MQTT |
| מרחב שמות מאוחד (UNS) | דפוס ארכיטקטורה שבו מערכות מפרסמות וצורכות נתונים במבנה נושאים היררכי אחד ומשותף |
| התפלגות Weibull | התפלגות סטטיסטית לזמני כשל; פרמטר הצורה שלה מראה התנהגות של תקופת ילדות, אקראיות או בלאי |
