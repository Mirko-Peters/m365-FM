## מילון מונחים

| מונח | משמעות |
|---|---|
| זיהוי אנומליות | שיטות שלומדות התנהגות תקינה ומסמנות סטיות ממנה, ללא צורך בדוגמאות של תקלות |
| מצב כפי שנמצא (As-found) | מה שהטכנאי בפועל מוצא בעת פתיחה או הוצאה של רכיב; זהו הבסיס לאמת לגבי התראות |
| BPFO / BPFI / FTF / BSF | תדרי התקלה האופייניים של מסב: ball pass frequency outer race (תדר מעבר כדורים בטבעת החיצונית), ball pass frequency inner race (תדר מעבר כדורים בטבעת הפנימית), fundamental train frequency (תדר הכלוב), ball spin frequency (תדר סיבוב הכדור) |
| CBM (תחזוקה מבוססת מצב) | תחזוקה שמופעלת כאשר מצב שנמדד חוצה גבול מוגדר |
| CMMS / EAM | מערכת לניהול תחזוקה ממוחשבת / ניהול נכסים ארגוניים; המקום שבו נמצאים הזמנות עבודה, נכסים והיסטוריה |
| דירוג קריטיות | ניקוד מובנה של נכסים לפי ההשלכות והסבירות של תקלה |
| מחשוב קצה (Edge computing) | עיבוד נתונים קרוב למכונה (שער תקשורת, מחשב תעשייתי) לפני שליחתם הלאה |
| ניתוח עטיפה (Envelope analysis) | טכניקת רטט שמפרקת התנגשויות בתדר גבוה כדי לחשוף פגמים מוקדמים במסבים ובהילוכים |
| ESA / MCSA | ניתוח חתימה חשמלית / ניתוח חתימת זרם מנוע; אבחון מזרם וממתח אספקת המנוע |
| FFT | טרנספורמציית פורייה מהירה; ממירה אות בזמן לספקטרום התדרים שלו |
| כשל תפקודי (F) | הנקודה שבה נכס אינו יכול עוד לבצע את התפקוד הנדרש ממנו |
| IIoT | האינטרנט התעשייתי של הדברים: חיישנים, התקנים ותוכנה מחוברים בסביבה תעשייתית |
| ISO 13374 | סדרת תקנים של ISO לעיבוד נתונים, תקשורת והצגה לניטור מצב ואבחון |
| ISO 17359 | הנחיות כלליות להקמת תוכנית לניטור מצב |
| ISO 20816 | מדידה והערכה של רטט מכונות (סדרה שמחליפה את ISO 10816) |
| MQTT | פרוטוקול הודעות קל משקל מסוג פרסום/הרשמה, תקן של OASIS |
| MTBF / MTTR | זמן ממוצע בין כשלים / זמן ממוצע לתיקון |
| מרווח P-F נטו | מרווח P-F פחות מרווח הבדיקה: האזהרה שאפשר לסמוך עליה בפועל |
| עקומת P-F / מרווח P-F | עקומת המצב לאורך זמן מנקודת כשל פוטנציאלי הניתן לזיהוי (P) ועד לכשל תפקודי (F); הזמן ביניהן |
| PdM (תחזוקה חזויה) | תחזוקה שמתוזמנת לפי מצב שנמדד בתוספת תחזית להתפתחותו |
| עמידה בתחזוקה מונעת (PM compliance) | שיעור הזמנות העבודה של תחזוקה מונעת שהגיעו למועדן והושלמו בתוך החלון שסוכם |
| דיוק / רגישות (Precision / recall) | שיעור ההתראות שהיו אמיתיות / שיעור התקלות האמיתיות שזוהו בזמן |
| תחזוקה preskriptivית (Prescriptive maintenance) | תחזוקה שבה המערכת ממליצה גם על הפעולה ועל תזמונה |
| RCM (תחזוקה ממוקדת אמינות) | שיטה מובנית לבחירת משימת התחזוקה הנכונה לכל מנגנון כשל, על בסיס השלכותיו |
| RUL (אורך חיים שיורי) | הערכה של הזמן או המחזורים עד שנכס מגיע לגבול כשל מוגדר |
| Sparkplug | מפרט של Eclipse שמוסיף מוסכמות תעשייתיות, ובהן ניהול מצב התקן, מעל MQTT |
| מרחב שמות אחיד (UNS) | דפוס ארכיטקטורה שבו מערכות מפרסמות וצורכות נתונים במבנה נושאים היררכי משותף אחד |
| התפלגות ויבול (Weibull) | התפלגות סטטיסטית לזמני כשל; פרמטר הצורה שלה מראה התנהגות של תחילת חיים, אקראיות או בלאי |
