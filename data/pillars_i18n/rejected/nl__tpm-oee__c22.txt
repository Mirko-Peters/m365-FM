## TPM- en OEE-woordenlijst

| Term | Betekenis |
|---|---|
| Afwijkingslabel (F-label) | label dat aan machines wordt gehangen om een probleem te markeren dat tijdens reiniging of inspectie is gevonden |
| Autonoom onderhoud (jishu hozen) | TPM-pijler waarin operators de basisconditie van machines bewaken en afwijkingen signaleren |
| Basisconditie | reiniging, smering en aanhalen die voorkomen dat machines verslechteren |
| CILS / CILT | reinigen, inspecteren, smeren en vastzetten of aanhalen: de dagelijkse routine van autonoom onderhoud |
| CMMS | geautomatiseerd onderhoudsbeheersysteem |
| Kritiekheidsranking | scoring van assets op basis van de impact en kans op storing |
| Vroegtijdig machinebeheer | TPM-pijler die onderhoudbaarheid en bedienbaarheid in nieuwe machines ontwerpt |
| Gerichte verbetering (kobetsu kaizen) | TPM-pijler voor het gestructureerd wegnemen van specifieke verliezen |
| Ideale cyclustijd | best mogelijke tijd per stuk; basis van de prestatiefactor |
| JIPM | Japan Institute of Plant Maintenance, dat de TPM-prijzen uitreikt |
| Belasting | geplande productietijd ÷ kalendertijd |
| Lockout/tagout | door OSHA voorgeschreven procedures om gevaarlijke energie tijdens onderhoud te beheersen (29 CFR 1910.147) |
| [Microstops](https://www.m365.fm/entity/micro-stops/) (kleine stilstanden) | korte stilstanden onder een vastgestelde drempel; een prestatieverlies |
| MTBF / MTTR | gemiddelde tijd tussen storingen / gemiddelde hersteltijd |
| OEE | totale materiaalefficiëntie van machines = beschikbaarheid × prestatie × kwaliteit |
| Eénpuntsles (OPL) | instructie van één pagina over één onderwerp, aan de machine gegeven |
| Prestatie | (ideale cyclustijd × totaal aantal) ÷ draaitijd |
| Gepland onderhoud | TPM-pijler voor tijd- en conditiegebaseerd onderhoud door de onderhoudsafdeling |
| Percentage gepland onderhoud | uren gepland onderhoud ÷ totale onderhoudsuren |
| Kwaliteit (percentage) | goed aantal ÷ totaal aantal |
| Kwaliteitsonderhoud (hinshitsu hozen) | TPM-pijler die machinecondities beheerst om defecten te voorkomen |
| Zes grote verliezen | storingen, omstellen en afstellen, kleine stilstanden, verminderde snelheid, defecten en herwerk, opstartverliezen |
| SMED | single-minute exchange of die: de methode om de [omsteltijd](https://www.m365.fm/entity/setup-time/) te verkorten |
| TEEP | totale effectieve machineprestatie = OEE × belasting |
</translation>
