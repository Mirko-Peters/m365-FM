## Woordenlijst TPM en OEE

| Term | Betekenis |
|---|---|
| Afwijkingslabel (F-label) | label dat op machines wordt gehangen om een probleem te markeren dat tijdens reiniging of inspectie is ontdekt |
| Autonoom onderhoud (jishu hozen) | TPM-pijler waarbij operators de basisconditie van machines bewaken en afwijkingen signaleren |
| Basisconditie | reiniging, smering en aandraaien die voorkomen dat machines verslechteren |
| CILS / CILT | reinigen, inspecteren, smeren en vastzetten of aandraaien: de dagelijkse routine van autonoom onderhoud |
| CMMS | computergestuurd onderhoudsbeheersysteem |
| Kritiekheidsranking | scoring van assets op basis van de impact en de kans op storing |
| Vroegtijdig machinebeheer | TPM-pijler die onderhoudbaarheid en bedienbaarheid in nieuwe machines ontwerpt |
| Gerichte verbetering (kobetsu kaizen) | TPM-pijler voor het gestructureerd wegnemen van specifieke verliezen |
| Ideale cyclustijd | best mogelijke tijd per stuk; basis van de prestatiefactor |
| JIPM | Japan Institute of Plant Maintenance, dat de TPM-prijzen uitreikt |
| Belading | geplande productietijd ÷ kalendertijd |
| Lockout/tagout | door OSHA gereguleerde procedures om gevaarlijke energie tijdens onderhoud te beheersen (29 CFR 1910.147) |
| [Micro-stops](https://www.m365.fm/entity/micro-stops/) (kleine stilstanden) | korte stilstanden onder een vastgestelde drempelwaarde; een prestatieverlies |
| MTBF / MTTR | gemiddelde tijd tussen storingen / gemiddelde hersteltijd |
| OEE | overall equipment effectiveness = beschikbaarheid × prestatie × kwaliteit |
| Eenpuntsles (OPL) | instructie van één pagina over één onderwerp, gegeven bij de machine |
| Prestatie | (ideale cyclustijd × totaal aantal) ÷ draaitijd |
| Gepland onderhoud | TPM-pijler voor tijd- en conditiegebaseerd onderhoud door de onderhoudsafdeling |
| Percentage gepland onderhoud | geplande onderhoudsuren ÷ totale onderhoudsuren |
| Kwaliteit (percentage) | goed aantal ÷ totaal aantal |
| Kwaliteitsonderhoud (hinshitsu hozen) | TPM-pijler die machinecondities beheerst om defecten te voorkomen |
| Zes grote verliezen | storingen, omstelling en afstelling, kleine stilstanden, verminderde snelheid, defecten en herwerk, opstartverliezen |
| SMED | single-minute exchange of die, de methode om de [omsteltijd](https://www.m365.fm/entity/setup-time/) te verkorten |
| TEEP | total effective equipment performance = OEE × belading |
</translation>
