## Глосарій TPM і OEE

| Термін | Значення |
|---|---|
| Ярлик аномалії (F-tag) | ярлик, що вішають на обладнання для позначення проблеми, виявленої під час очищення чи огляду |
| Автономне обслуговування (jishu hozen) | стовп TPM, у межах якого оператори підтримують базовий стан обладнання та виявляють аномалії |
| Базові умови | очищення, змащення та затягування, які запобігають погіршенню стану обладнання |
| CILS / CILT | очищення, огляд, змащення та закріплення або затягування: щоденна рутина автономного обслуговування |
| CMMS | комп'ютеризована система управління технічним обслуговуванням |
| Ранжування критичності | оцінювання активів за впливом і ймовірністю відмови |
| Раннє управління обладнанням | стовп TPM, що закладає у нове обладнання придатність до обслуговування та зручність експлуатації |
| Цільове вдосконалення (kobetsu kaizen) | стовп TPM для структурованого усунення конкретних втрат |
| Ідеальний час циклу | найкращий можливий час на одну деталь; основа коефіцієнта продуктивності |
| JIPM | Японський інститут обслуговування заводів, який присуджує премії TPM |
| Завантаження | плановий час виробництва ÷ календарний час |
| Lockout/tagout | процедури OSHA для контролю небезпечної енергії під час обслуговування (29 CFR 1910.147) |
| [Мікрозупинки](https://www.m365.fm/entity/micro-stops/) (minor stops) | короткі зупинки тривалістю нижче визначеного порогу; втрата продуктивності |
| MTBF / MTTR | середній час між відмовами / середній час ремонту |
| OEE | загальна ефективність обладнання = доступність × продуктивність × якість |
| Урок однієї точки (OPL) | одностороння інструкція з однієї теми, що проводиться біля верстата |
| Продуктивність | (ідеальний час циклу × загальна кількість) ÷ час роботи |
| Планове обслуговування | стовп TPM для планового та засновано на стані обслуговування, що виконується службою технічного обслуговування |
| Відсоток планового обслуговування | години планового обслуговування ÷ загальні години обслуговування |
| Якість (коефіцієнт) | кількість придатних ÷ загальна кількість |
| Підтримка якості (hinshitsu hozen) | стовп TPM, що контролює стан обладнання для запобігання дефектам |
| Шість великих втрат | поломки, переналагодження та регулювання, мікрозупинки, зниження швидкості, дефекти та переробка, втрати на запуску |
| SMED | швидка переналагодження за хвилини, метод скорочення [часу переналагодження](https://www.m365.fm/entity/setup-time/) |
| TEEP | сукупна ефективна продуктивність обладнання = OEE × завантаження |
