## Глосарій TPM та OEE

| Термін | Значення |
|---|---|
| Ярлик аномалії (F-ярлик) | ярлик, що вішається на обладнання для позначення проблеми, виявленої під час очищення або огляду |
| Автономне технічне обслуговування (jishu hozen) | опора TPM, за якої оператори підтримують базовий стан обладнання та виявляють аномалії |
| Базовий стан | очищення, змащування та затягування, що запобігають погіршенню обладнання |
| CILS / CILT | очистити, оглянути, змастити та закріпити або затягнути: щоденний регламент автономного технічного обслуговування |
| CMMS | комп’ютеризована система управління технічним обслуговуванням |
| Ранжування за критичністю | оцінювання активів за впливом і ймовірністю відмови |
| Раннє управління обладнанням | опора TPM, що закладає ремонтопридатність і зручність експлуатації в нове обладнання |
| Цільове вдосконалення (kobetsu kaizen) | опора TPM для системного усунення конкретних втрат |
| Ідеальний час циклу | найкращий можливий час на одну деталь; основа коефіцієнта продуктивності |
| JIPM | Японський інститут технічного обслуговування обладнання, який присуджує призи TPM |
| Завантаження | планований час виробництва ÷ календарний час |
| Блокування/маркування (lockout/tagout) | процедури OSHA для контролю небезпечної енергії під час обслуговування (29 CFR 1910.147) |
| [Мікрозупинки](https://www.m365.fm/entity/micro-stops/) (дрібні зупинки) | короткі зупинки тривалістю менше визначеного порогу; втрата продуктивності |
| MTBF / MTTR | середній час між відмовами / середній час відновлення |
| OEE | загальна ефективність обладнання = доступність × продуктивність × якість |
| Урок однієї точки (OPL) | односторінкова інструкція з однієї теми, що проводиться біля верстата |
| Продуктивність | (ідеальний час циклу × загальна кількість) ÷ час роботи |
| Планове технічне обслуговування | опора TPM для обслуговування за часом і за станом, що виконує служба технічного обслуговування |
| Відсоток планового технічного обслуговування | години планового технічного обслуговування ÷ загальні години технічного обслуговування |
| Якість (коефіцієнт) | кількість придатних ÷ загальна кількість |
| Підтримання якості (hinshitsu hozen) | опора TPM, що контролює стан обладнання для запобігання дефектам |
| Шість великих втрат | поломки, переналагодження та регулювання, мікрозупинки, зниження швидкості, дефекти та переробка, втрати на запуску |
| SMED | одна хвилина на переналагодження, метод скорочення [часу переналагодження](https://www.m365.fm/entity/setup-time/) |
| TEEP | сукупна ефективна продуктивність обладнання = OEE × завантаження |
</translation>
