## リーン用語集：主要用語 A から Z まで

| 用語 | 簡潔な定義 |
|---|---|
| A3 レポート | 問題解決、分析、アクションプランを 1 枚の A3（約 11 × 17 インチ）用紙にまとめたもの |
| アンドン | 異常を即座に見える化する信号（ランプ、紐、ボタン） |
| CONWIP | システム内の仕掛品量を一定に保つ管理方式。多品種少量生産に適している |
| サイクルタイム | 1 個の部品を加工するのに実際にかかる時間 |
| DOWNTIME | 8 つのムダ（不良、過剰生産、手待ち、人材の未活用、運搬、在庫、動作、加工の無駄）を覚えるための米国式の語呂合わせ |
| FIFO レーン | 容量を制限したバッファで、到着順に部品を次工程へ渡す |
| フロー比率 | リードタイムに占める加工時間の割合（プロセスサイクル効率とも呼ぶ） |
| 現場（ゲンバ） | 価値が生み出される場所。工場では生産ラインやセル |
| 現地現物（ゲンチ・ゲンブツ） | 報告に頼らず、自分の目で現場・現物を確かめること |
| 反省（ハンセイ） | プロジェクトや失敗の後に行う体系的な振り返り |
| 平準化（ヘイジュンカ） | 量と品種の組み合わせを平準化して生産すること |
| 方針管理（ホシン・カンリ） | 経営層から現場まで戦略（方針）を展開すること |
| 自働化（ジドウカ） | 異常時に停止し、工程に品質を作り込むこと。TPS の second pillar |
| ジャストインタイム | 必要なものを、必要なときに、必要な量だけ作ること |
| 改善（カイゼン） | 全従業員による、小さなステップでの継続的改善（継続的改善、CI） |
| リーダー標準作業 | 現場巡回の定時実施や階層別会議など、リーダー自身の標準作業 |
| リードタイム | 部品や注文が価値の流れに入ってから出るまでの時間 |
| ムダ・ムラ・ムリ | 無駄、ばらつき、無理 |
| OEE | 設備総合効率：稼働率 × 性能稼働率 × 良品率 |
| 一個流し | 部品をバッチではなく 1 個ずつ作り、次工程へ渡すこと |
| ペースメーカー工程 | 生産計画を受け取る唯一の工程。上流の工程はすべてプルによって追従する |
| ピッチ | タクトタイム × 容器の数量。平準化ボックスの時間間隔 |
| ポカヨケ | ミスを防止する、またはミスを即座に知らせる簡単な仕掛け |
| SMED | 段取り作業を内段取りと外段取りに分けて変換し、段取り替えを一桁分（10 分未満）で行う手法 |
| スーパーマーケット | 最小数量と最大数量を管理した在庫。後工程がここから部品を引き取る |
| タクトタイム | 稼働可能な生産時間 ÷ 顧客需要 |
| TIMWOODS | 同じ 8 つのムダを覚えるための欧州式の語呂合わせ |
| TPM | 全員参加の生産保全：設備を全員で守り育てる活動 |
| TWI | Training Within Industry：1940 年に始まった米国のプログラム。作業指導、作業改善、人間関係の 3 つを扱う |
| 山積み（ヤマズミ） | 各作業者の作業内容をタクトタイムと比較して積み上げた棒グラフ |
