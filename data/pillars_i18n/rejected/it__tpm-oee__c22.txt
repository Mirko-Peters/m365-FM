## Glossario TPM e OEE

| Termine | Significato |
|---|---|
| Cartellino di anomalia (F-tag) | cartellino appeso alle attrezzature per segnalare un problema rilevato durante la pulizia o l'ispezione |
| Manutenzione autonoma (jishu hozen) | pilastro del TPM in cui gli operatori mantengono le condizioni di base delle attrezzature e rilevano le anomalie |
| Condizioni di base | pulizia, lubrificazione e serraggio che impediscono il deterioramento delle attrezzature |
| CILS / CILT | pulire, ispezionare, lubrificare e fissare o serrare: la routine quotidiana di manutenzione autonoma |
| CMMS | sistema informatizzato di gestione della manutenzione |
| Classifica di criticità | attribuzione di un punteggio agli asset in base all'impatto e alla probabilità di guasto |
| Gestione precoce delle attrezzature | pilastro del TPM che integra manutenibilità e facilità d'uso nelle nuove attrezzature |
| Miglioramento mirato (kobetsu kaizen) | pilastro del TPM per l'eliminazione strutturata di specifiche perdite |
| Tempo ciclo ideale | tempo migliore possibile per pezzo; base del fattore di prestazione |
| JIPM | Japan Institute of Plant Maintenance, che assegna i premi TPM |
| Carico | tempo di produzione pianificato ÷ tempo di calendario |
| Lockout/tagout | procedure regolate dall'OSHA per controllare l'energia pericolosa durante gli interventi (29 CFR 1910.147) |
| [Micro-fermate](https://www.m365.fm/entity/micro-stops/) (fermate minori) | brevi fermate inferiori a una soglia definita; una perdita di prestazione |
| MTBF / MTTR | tempo medio tra i guasti / tempo medio di riparazione |
| OEE | efficacia globale delle attrezzature = disponibilità × prestazione × qualità |
| Lezione in un punto (OPL) | istruzione su una singola pagina dedicata a un argomento, impartita alla macchina |
| Prestazione | (tempo ciclo ideale × conteggio totale) ÷ tempo di funzionamento |
| Manutenzione pianificata | pilastro del TPM per la manutenzione a tempo e basata sulle condizioni, svolta dalla funzione manutenzione |
| Percentuale di manutenzione pianificata | ore di manutenzione pianificata ÷ ore totali di manutenzione |
| Qualità (tasso) | conteggio dei pezzi buoni ÷ conteggio totale |
| Manutenzione della qualità (hinshitsu hozen) | pilastro del TPM che controlla le condizioni delle attrezzature per prevenire i difetti |
| Sei grandi perdite | guasti, attrezzaggio e regolazione, micro-fermate, riduzione della velocità, difetti e rilavorazioni, perdite di avviamento |
| SMED | cambio stampo in meno di dieci minuti (single-minute exchange of die), metodo per ridurre il [tempo di attrezzaggio](https://www.m365.fm/entity/setup-time/) |
| TEEP | prestazione effettiva totale delle attrezzature = OEE × carico |
</translation>
