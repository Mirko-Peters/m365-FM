## 5S 점검표: 템플릿, 점수 체계, 주기

점검(audit)은 영역을 5S 기준에 따라 평가하는 방법입니다. 이를 통해 영역의 상태를 시간의 흐름과 영역 간에 비교할 수 있습니다. 또한 팀이 매일 자가 점검을 할 수 있는 체크리스트가 됩니다. 가장 좋은 점검은 짧고, 구체적이며, 매번 같은 방식으로 채점되는 점검입니다.

### 점검 템플릿 (25개 항목, 0~4점)

각 항목은 5단계 척도로 채점합니다. **0** = 미실시, **1** = 시작 단계, 큰 공백 존재, **2** = 부분적으로 실시, 여러 공백 존재, **3** = 실시됨, 사소한 공백 존재, **4** = 완전히 실시되고 유지됨. 최대 점수: 25개 항목 × 4점 = 100점.

| # | 범주 | 점검 항목 | 점수 (0–4) |
|---|---|---|---|
| 1 | Sort | 영역에 불필요한 물품, 자재, 설비가 없음 | |
| 2 | Sort | 서랍, 캐비닛, 캐비닛 위, 설비 뒤에 불필요한 물품이 없음 | |
| 3 | Sort | 레드태그 영역이 사용 중이며, 검토 기간을 넘긴 태그가 없음 | |
| 4 | Sort | 작업대에는 현재 리비전의 도면과 작업 지침만 있음 | |
| 5 | Sort (안전) | 교대 작업에 필요한 양을 넘는 인화성 물질이나 화학물질이 없음 | |
| 6 | Set in order | 모든 공구, 게이지, 지그에 표시된 보관 위치가 있고 그곳에 있거나 사용 중임 | |
| 7 | Set in order | 보관 위치에 주소와 품목이 표기되어 있고, 표기가 ERP/MES와 일치함 | |
| 8 | Set in order | 최소/최대 재고 수준이 표시되어 있고 준수됨 | |
| 9 | Set in order | 통로, 셀, WIP 위치가 현장 범례에 따라 표시되어 있고 표시가 온전함 | |
| 10 | Set in order (안전) | 분전반, 소화기, 세안기, 출입구 앞의 통행 금지 구역이 비어 있고 표시되어 있음 | |
| 11 | Shine | 바닥이 깨끗하고 건조하며, 통행로에 기름, 냉각수, 칩이 없음 | |
| 12 | Shine | 기계와 설비가 깨끗하며, 새로운 누유가 없음 | |
| 13 | Shine | 이상 태그가 기록되어 있고, 기한을 넘긴 태그가 없음 | |
| 14 | Shine | 청소 도구가 사용 지점에 있고 상태가 양호함 | |
| 14 | Shine | 청소 도구가 사용 지점에 있고 상태가 양호함 | |
| 15 | Shine (안전) | 에너지 차단이 필요한 청소 작업이 계획에 표시되어 있고 준수됨 | |
| 16 | Standardize | 사진 기준이 게시되어 있고 현재 상태와 일치함 | |
| 17 | Standardize | 구역 담당자가 표시된 5S 맵이 게시되어 있고 최신 상태임 | |
| 18 | Standardize | 주기와 시간이 명시된 청소 및 점검 계획이 게시되어 있음 | |
| 19 | Standardize | 시각 관리 요소(색상, 라벨, 태그)가 현장 표준을 따름 | |
| 20 | Standardize (안전) | 표지판과 화학용기 라벨이 있고 읽을 수 있음 | |
| 21 | Sustain | 일일 5S 루틴이 실시됨 (체크리스트 서명 또는 기록) | |
| 22 | Sustain | 지난 점검의 지적 사항이 종결되었거나 담당자와 기한이 지정되어 있음 | |
| 23 | Sustain | 점검 점수와 추이가 영역 게시판에 게시되어 있음 | |
| 24 | Sustain | 지난 점검 이후 최소 한 건의 5S 개선이 실행됨 | |
| 25 | Sustain | 요청 시 팀원들이 영역 기준을 설명할 수 있음 | |

항목 20은 작업장 화학물질 용기의 라벨을 규정하는 OSHA 유해성 소통 기준(29 CFR 1910.1200)과 관련됩니다. (f)(6)항은 작업장의 모든 유해 화학물질 용기에 출하 용기 라벨 정보, 또는 제품 식별자와 일반 유해성 정보를 표기하도록 요구합니다. (f)(8)항은 용기를 옮긴 근로자가 즉시 사용하기 위한 휴대용 용기만 예외로 인정합니다 [46]. Set in order 단계에서 재라벨링하기 전에 보조 용기에 이 규정이 어떻게 적용되는지 EHS에 문의하십시오.

### 사례: 셀 4 채점 (예시)

| 범주 | 항목 | 최대 | 기준선 (4주차) | 12주차 | 12개월차 |
|---|---|---|---|---|---|
| Sort | 1–5 | 20 | 7 | 16 | 17 |
| Set in order | 6–10 | 20 | 5 | 13 | 17 |
| Shine | 11–15 | 20 | 8 | 15 | 16 |
| Standardize | 16–20 | 20 | 2 | 9 | 15 |
| Sustain | 21–25 | 20 | 1 | 7 | 14 |
| **합계** | 25 | **100** | **23** | **60** | **79** |

두 가지 패턴이 일반적으로 나타납니다. Sort와 Shine은 행사성 활동이기 때문에 빠르게 개선됩니다. Standardize와 Sustain은 루틴과 리더십 시간이 필요하기 때문에 뒤처지는데, 이는 ASQ가 경고한 바로 그 현상입니다 [2]. 다섯 범주의 점수를 보여주는 레이더 차트는 이 패턴을 한눈에 보여주며, 영역 게시판에 쓰기 좋은 시각 자료입니다.

### 점검 주기와 계층별 점검

| 수준 | 담당 | 빈도 | 범위 | 소요 시간 |
|---|---|---|---|---|
| 자가 점검 | 작업자 / 구역 담당자 | 매일, 교대 종료 시 | 담당 구역, 짧은 체크리스트(5~8개 항목) | 5분 |
| 영역 점검 | 감독자 또는 팀 리더 | 매주 | 25개 항목 전체 점검 | 20–30분 |
| 교차 점검 | 다른 영역의 감독자 | 매월 | 전체 점검 | 30분 |
| 리더십 점검 | 공장장, 운영 이사 | 매월, 영역 순환 | 전체 점검 및 팀과의 대화 | 30–45분 |
