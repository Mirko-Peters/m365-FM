## מילון מונחים לקנבן

| מונח | הגדרה |
|---|---|
| כמות מיכל (כמות אריזה) | מספר קבוע של חלקים לכל קנבן; יחידת הלולאה |
| CONWIP | עבודה קבועה בתהליך (Constant work in process); מערכת משיכה עם סט כרטיסים אחד לקו שלם [3][5] |
| Drum-buffer-rope (DBR) | שיטת בקרה מתורת האילוצים: צוואר הבקבוק קובע את הקצב, מאגר זמן מגן עליו, והשחרור קשור אליו |
| E-kanban | אות קנבן אלקטרוני, מופעל בסריקה או בחיישן [10] |
| קנבן חירום | כרטיס נוסף זמני להתאוששות ממחסור; מוסר לאחר השימוש |
| תור FIFO | תור עם כמות מקסימלית בין שני תהליכים, ראשון נכנס ראשון יוצא |
| Heijunka | איזון סוג וכמות הייצור לאורך תקופה קבועה [18] |
| קופסת Heijunka | לוח זמנים חזותי עם סוגי מוצרים על ציר אחד וחריצי זמן (pitch) על הציר השני [18] |
| ייצור בזמן בדיוק (JIT) | ייצור רק מה שנחוץ, כאשר נחוץ, בכמות הנחוצה [8] |
| Kanban | התקן איתות המתיר ייצור או משיכה במערכת משיכה; מילה יפנית שפירושה "שלט" או "לוח שלטים" [1] |
| תחנת קנבן | קופסה או מדף שבהם נאספים הקנבנים לאיסוף |
| חוק ליטל | WIP ממוצע = תפוקה × זמן אספקה ממוצע [6] |
| לולאה | מערכת יחסים אחת ספק-צרכן למק"ט אחד עם סט הקנבנים שלו |
| Pacemaker | התהליך היחיד שמקבל את לוח הייצור |
| Pitch | הזמן לייצור מיכל אחד: takt time × כמות אריזה [19] |
| POLCA | Paired-cell overlapping loops of cards with authorization; משיכה לחנויות בתמהיל גבוה וכמויות נמוכות [20][21] |
| קנבן ייצור | כרטיס המתיר לתהליך לייצר סוג וכמות [1] |
| מערכת משיכה | מערכת ייצור המגבילה במפורש את ה-WIP [2] |
| מערכת דחיפה | מערכת המשחררת עבודה לפי לוח זמנים ללא תקרה ל-WIP |
| זמן אספקה להשלמה | הזמן מרגע רוקנו של מיכל (שחרור הכרטיס שלו) ועד שהמיכל המלא חוזר לנקודת האחסון שלו |
| Runners, repeaters, strangers | פילוח חלקים לפי סדירות הביקוש, המשמש לבחירה בין קנבן לייצור לפי הזמנה |
| גורם בטיחות | אחוז המתווסף לביקוש במהלך השלמה לכיסוי שונות |
| קנבן איתות (קנבן משולש) | כרטיס המפעיל אצווה כאשר המלאי מגיע לנקודת הפעלה [1] |
| סופרמרקט | נקודת מלאי מבוקרת עם כתובות קבועות וכמויות מקסימליות, ממנה התהליך הבא שולף |
| קנבן ספק | קנבן משיכה לספק חיצוני, לעיתים אלקטרוני [1] |
| Two-bin system | שני מיכלים לכל חלק; מיכל ריק הוא אות ההשלמה [10] |
| Water spider (mizusumashi) | מנהל חומרים על מסלול קבוע שמעביר קנבנים ומיכלים |
| קנבן משיכה | כרטיס המתיר העברת חלקים לתהליך הבא [1] |
| WIP | עבודה בתהליך: חומר שהחל להיות מעובד ואינו גמור |
