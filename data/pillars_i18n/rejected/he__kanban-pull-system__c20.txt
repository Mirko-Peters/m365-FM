## מילון מונחים של קנבן

| מונח | הגדרה |
|---|---|
| כמות מיכל (כמות אריזה) | מספר קבוע של חלקים לכל קנבן; יחידת הלולאה |
| CONWIP | Constant work in process (עבודה קבועה בתהליך); מערכת משיכה עם סט אחד של כרטיסים לקו שלם [3][5] |
| Drum-buffer-rope (DBR) | שיטת בקרה מתורת האילוצים: צוואר הבקבוק קובע את הקצב, מאגר זמן מגן עליו, והשחרור מקושר אליו |
| E-kanban | אות קנבן אלקטרוני, מופעל בסריקה או בחיישן [10] |
| קנבן חירום | כרטיס נוסף זמני להתאוששות ממחסור; מוסר לאחר השימוש |
| FIFO lane | תור עם כמות מקסימלית בין שני תהליכים, ראשון נכנס ראשון יוצא |
| Heijunka | איזון סוג וכמות הייצור לאורך תקופה קבועה [18] |
| Heijunka box | לוח זמנים חזותי עם סוגי מוצרים בציר אחד ומשבצות זמן (pitch) בציר השני [18] |
| Just-in-time (JIT) | ייצור רק מה שנחוץ, כשהוא נחוץ, בכמות הנחוצה [8] |
| Kanban | התקן איתות המתיר ייצור או משיכה במערכת משיכה; מילה יפנית שפירושה "שלט" או "לוח שלטים" [1] |
| Kanban post | קופסה או מתלה שבהם נאספים הקנבנים לאיסוף |
| Little's law | WIP ממוצע = תפוקה × זמן אספקה ממוצע [6] |
| לולאה | קשר ספק-צרכן אחד למק"ט אחד עם סט הקנבנים שלו |
| Pacemaker | התהליך היחיד שמקבל את לוח הייצור |
| Pitch | הזמן לייצור מיכל אחד: takt time × כמות אריזה [19] |
| POLCA | Paired-cell overlapping loops of cards with authorization; משיכה לסדנאות תמהיל גבוה וכמויות נמוכות [20][21] |
| קנבן ייצור | כרטיס המתיר לתהליך לייצר סוג וכמות [1] |
| מערכת משיכה | מערכת ייצור המגבילה במפורש את ה-WIP [2] |
| מערכת דחיפה | מערכת שמשחררת עבודה לפי לוח זמנים ללא תקרת WIP |
| זמן אספקה מחדש | הזמן מרגע רוקנו של מיכל (שחרור הכרטיס שלו) ועד שהמיכל המלא חוזר לנקודת האחסון שלו |
| Runners, repeaters, strangers | פילוח חלקים לפי סדירות הביקוש, המשמש לבחירה בין קנבן לייצור לפי הזמנה |
| גורם בטיחות | אחוז המתווסף לביקוש במהלך אספקה מחדש לכיסוי שונות |
| קנבן אות (קנבן משולש) | כרטיס המפעיל אצווה כאשר המלאי מגיע לנקודת הפעלה |
| Supermarket | נקודת מלאי מבוקרת עם כתובות קבועות וכמויות מקסימליות, שממנה התהליך במורד הזרם שולף |
| קנבן ספק | קנבן משיכה אל ספק חיצוני, לעיתים אלקטרוני [1] |
| Two-bin system | שני מיכלים לכל חלק; מיכל ריק הוא אות האספקה מחדש [10] |
| Water spider (mizusumashi) | מטפל בחומרים על מסלול קבוע, המעביר קנבנים ומיכלים |
| קנבן משיכה | כרטיס המתיר העברת חלקים לתהליך במורד הזרם [1] |
| WIP | Work in process (עבודה בתהליך): חומר שהתחיל להיות מעובד ולא הסתיים |
