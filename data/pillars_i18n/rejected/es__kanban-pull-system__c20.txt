## Glosario de kanban

| Término | Definición |
|---|---|
| Cantidad por contenedor (cantidad de empaque) | Número fijo de piezas por kanban; la unidad del bucle |
| CONWIP | Trabajo en proceso constante; un sistema de arrastre con un único juego de tarjetas para toda una línea [3][5] |
| Tambor-amortiguador-cuerda (DBR) | Método de control de la teoría de restricciones: la restricción marca el ritmo, un amortiguador de tiempo la protege y la liberación de material se vincula a ella |
| Kanban electrónico (e-kanban) | Señal kanban electrónica, activada por escaneo o sensor [10] |
| Kanban de emergencia | Tarjeta extra temporal para recuperarse de un faltante; se retira después de usarse |
| Carril FIFO | Cola con una cantidad máxima entre dos procesos, primero en entrar, primero en salir |
| Heijunka | Nivelación del tipo y la cantidad de producción durante un periodo fijo [18] |
| Caja heijunka | Programa visual con tipos de producto en un eje y franjas de tiempo (pitch) en el otro [18] |
| Justo a tiempo (JIT) | Fabricar solo lo necesario, cuando se necesita y en la cantidad necesaria [8] |
| Kanban | Dispositivo de señalización que autoriza la producción o el retiro en un sistema de arrastre; en japonés significa "señal" o "letrero" [1] |
| Buzón kanban | Caja o rack donde se recogen los kanban para su retiro |
| Ley de Little | WIP promedio = rendimiento × tiempo de entrega promedio [6] |
| Bucle | Una relación proveedor-consumidor para un número de parte con su juego de kanban |
| Marcapasos | El único proceso que recibe el programa de producción |
| Pitch | Tiempo para fabricar un contenedor: tiempo takt × cantidad de empaque [19] |
| POLCA | Bucles superpuestos de tarjetas con autorización entre celdas emparejadas; arrastre para talleres de alta mezcla y bajo volumen [20][21] |
| Kanban de producción | Tarjeta que autoriza a un proceso a fabricar un tipo y una cantidad [1] |
| Sistema de arrastre | Sistema de producción que limita explícitamente el WIP [2] |
| Sistema de empuje | Sistema que libera trabajo según un programa, sin límite de WIP |
| Tiempo de reposición | Tiempo desde que se vacía un contenedor (se libera su tarjeta) hasta que el contenedor lleno regresa a su punto de almacenamiento |
| Runners, repeaters, strangers | Segmentación de piezas por regularidad de la demanda, utilizada para elegir entre kanban y fabricación bajo pedido |
| Factor de seguridad | Porcentaje añadido a la demanda durante la reposición para cubrir la variación |
| Kanban de señal (kanban triangular) | Tarjeta que dispara un lote cuando el inventario alcanza un punto de activación [1] |
| Supermercado | Punto de stock controlado con direcciones fijas y cantidades máximas, del cual el proceso posterior retira material |
| Kanban de proveedor | Kanban de retiro hacia un proveedor externo, a menudo electrónico [1] |
| Tiempo takt | Tiempo disponible dividido entre la demanda del cliente |
| Sistema de dos contenedores | Dos contenedores por pieza; un contenedor vacío es la señal de reposición [10] |
| Retiro kanban | Tarjeta que autoriza mover piezas a un proceso posterior [1] |
| WIP | Trabajo en proceso: material iniciado pero no terminado |
