## TPM・OEE用語集

| 用語 | 意味 |
|---|---|
| 異常タグ（Fタグ） | 清掃や点検で見つかった不具合を示すために設備に掛けるタグ |
| 自主保全（自主保全活動） | オペレーターが設備の基本状態を維持し、異常を発見するTPMの柱 |
| 基本条件 | 設備の劣化を防ぐ清掃、給油、締付け |
| CILS / CILT | 清掃（Clean）、点検（Inspect）、給油（Lubricate）、締付け・固定（Secure or Tighten）：日常の自主保全ルーティン |
| CMMS | コンピュータ化された保全管理システム |
| 重要度ランキング | 故障の影響度と発生可能性による設備資産の採点 |
| 初期流動管理 | 新設備に保全性と操作性を組み込むことを設計段階で行うTPMの柱 |
| 個別改善（個別改善活動） | 特定の損失を体系的に除去するためのTPMの柱 |
| 理想サイクルタイム | 1個あたりの最短可能時間。性能稼働率の基準となる |
| JIPM | 日本プラントメンテナンス協会。TPM賞を授与する |
| 負荷率 | 計画生産時間 ÷ カレンダー時間 |
| ロックアウト／タグアウト | 保守作業中の危険エネルギーを管理する手順（OSHA規制、29 CFR 1910.147） |
| [マイクロストップ](https://www.m365.fm/entity/micro-stops/)（小停止） | 定められた閾値を下回る短時間の停止。性能ロス |
| MTBF / MTTR | 平均故障間隔 / 平均修復時間 |
| OEE | 総合設備効率 = 稼働率 × 性能稼働率 × 品質率 |
| ワンポイントレッスン（OPL） | 1つのテーマについての1枚の説明書。現場で教育する |
| 性能稼働率 | （理想サイクルタイム × 総生産数）÷ 稼働時間 |
| 計画保全 | 時間基準保全と状態基準保全を保全部門が行うTPMの柱 |
| 計画保全率 | 計画保全時間 ÷ 総保全時間 |
| 品質率 | 良品数 ÷ 総生産数 |
| 六大損失 | 故障、段取り・調整、小停止、速度低下、不良・手直し、立ち上がり損失 |
| SMED | 段取り替え時間を短縮する手法（シングル段取り） |
| TEEP | 総合有効設備効率 = OEE × 負荷率 |
</translation>
