## TPM・OEE用語集

| 用語 | 意味 |
|---|---|
| 異常札（Fタグ） | 清掃や点検で見つかった不具合を示すために設備に掛ける札 |
| 自主保全（自主保全活動） | オペレーターが設備の基本状態を維持し、異常を発見するTPMの柱 |
| 基本条件 | 設備の劣化を防ぐための清掃、給油、締め付け |
| CILS / CILT | 清掃（Clean）、点検（Inspect）、給油（Lubricate）、締め付け（Secure/Tighten）：日常の自主保全ルーティン |
| CMMS | コンピュータ化された保全管理システム |
| 重要度ランキング | 故障の影響度と発生確率による設備資産の評価付け |
| 初期流動管理 | 新設備に保全性と操作性を組み込むTPMの柱 |
| 個別改善（个别改善） | 特定のロスを体系的に除去するためのTPMの柱 |
| 理想サイクルタイム | 1個あたりの理論上の最短時間。性能稼働率の基準となる |
| JIPM | 日本プラントメンテナンス協会。TPM賞を授与する |
| 稼働率（負荷率） | 計画生産時間 ÷ カレンダー時間 |
| ロックアウト／タグアウト | 保守作業中の危険エネルギーを管理するための手順。OSHA規制（29 CFR 1910.147） |
| [マイクロストップ](https://www.m365.fm/entity/micro-stops/)（小停止） | 定められた閾値未満の短時間停止。性能ロスの一つ |
| MTBF / MTTR | 平均故障間隔 / 平均修復時間 |
| OEE | 総合設備効率 = 時間稼働率 × 性能稼働率 × 良品率 |
| 1ポイントレッスン（OPL） | 1つのテーマについて1枚にまとめ、設備の前で教える指導書 |
| 性能稼働率 | （理想サイクルタイム × 総生産数）÷ 稼働時間 |
| 計画保全 | 保全部門が時間基準および状態基準で行う保全を対象とするTPMの柱 |
| 計画保全率 | 計画保全時間 ÷ 総保全時間 |
| 良品率（品質稼働率） | 良品数 ÷ 総生産数 |
| 品質保全 | 不良を防ぐために設備の状態を管理するTPMの柱 |
| 6大ロス | 故障ロス、段取り・調整ロス、小停止ロス、速度低下ロス、不良・手直しロス、立ち上がりロス |
| SMED | 段取り替えを短時間化する手法（シングル段取り）。[段取り時間](https://www.m365.fm/entity/setup-time/)の短縮に用いる |
| TEEP | 設備の総合有効性 = OEE × 稼働率 |
</translation>
