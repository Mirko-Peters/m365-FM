## مسرد المصطلحات

| المصطلح | المعنى |
|---|---|
| كشف الشذوذ | طرق تتعلم السلوك الطبيعي وتُبلغ عن الانحرافات عنه، دون الحاجة إلى أمثلة للأعطال |
| الحالة كما وُجدت | ما يجده الفني فعلياً عند فتح مكوّن ما أو إزالته؛ وهي المرجع الحقيقي للتنبيهات |
| BPFO / BPFI / FTF / BSF | ترددات العيوب المميزة للمحامل: تردد مرور الكرات على حلقة المسار الخارجية، وعلى حلقة المسار الداخلية، والتردد الأساسي للقفص (FTF)، وتردد دوران الكرات حول نفسها (BSF) |
| CBM (الصيانة المبنية على الحالة) | صيانة تُطلق عندما تتجاوز حالة مقاسة حداً معيناً |
| CMMS / EAM | نظام إدارة الصيانة المحوسب / إدارة الأصول المؤسسية؛ حيث تُحفظ أوامر العمل والأصول والسجل |
| ترتيب الأهمية | تقييم منظم للأصول حسب عواقب الفشل واحتمال وقوعه |
| الحوسبة الطرفية | معالجة البيانات قرب الآلة (البوابة أو الحاسوب الصناعي) قبل إرسالها |
| تحليل الغلاف | تقنية اهتزاز تفكّ تشكيل الصدمات عالية التردد لكشف عيوب المحامل والتروس في مراحلها المبكرة |
| ESA / MCSA | تحليل البصمة الكهربائية / تحليل بصمة تيار المحرك؛ تشخيص من تيار التغذية وجهد المحرك |
| FFT | تحويل فورييه السريع؛ يحوّل الإشارة الزمنية إلى طيفها الترددي |
| الفشل الوظيفي (F) | النقطة التي يعجز عندها الأصل عن أداء وظيفته المطلوبة |
| IIoT | إنترنت الأشياء الصناعي: المستشعرات والأجهزة والبرمجيات المتصلة في البيئات الصناعية |
| ISO 13374 | سلسلة معايير ISO لمعالجة بيانات مراقبة الحالة والتشخيص ونقلها وعرضها |
| ISO 17359 | إرشادات عامة لإعداد برنامج مراقبة الحالة |
| ISO 20816 | قياس اهتزاز الآلات وتقييمه (السلسلة التي خلفت ISO 10816) |
| MQTT | بروتوكول مراسلة خفيف من نوع النشر/الاشتراك، وهو معيار OASIS |
| MTBF / MTTR | متوسط الزمن بين الأعطال / متوسط زمن الإصلاح |
| فترة P-F الصافية | فترة P-F مطروحاً منها فترة الفحص: مقدار الإنذار المبكر الذي يمكن الاعتماد عليه فعلياً |
| منحنى P-F / فترة P-F | منحنى الحالة عبر الزمن من الفشل المحتمل القابل للكشف (P) حتى الفشل الوظيفي (F)؛ والزمن الفاصل بينهما |
| PdM (الصيانة التنبؤية) | صيانة يُحدد توقيتها بالحالة المقاسة مع توقع تطورها |
| الامتثال لصيانة الوقاية | نسبة أوامر عمل الصيانة الوقائية المستحقة التي أُنجزت ضمن الإطار المتفق عليه |
| الدقة / الاسترجاع | نسبة التنبيهات الصحيحة / نسبة الأعطال الحقيقية التي جرى التنبيه إليها في الوقت المناسب |
| الصيانة الوصفية | صيانة يقترح فيها النظام أيضاً الإجراء وتوقيته |
| RCM (الصيانة المتمحورة حول الموثوقية) | منهج منظم لاختيار مهمة الصيانة المناسبة لكل نمط عطل بحسب عواقبه |
| RUL (العمر الافتراضي المتبقي) | تقدير للزمن أو الدورات المتبقية حتى يبلغ الأصل حداً محدداً للفشل |
| Sparkplug | مواصفة Eclipse تضيف أعرافاً صناعية، منها إدارة حالة الأجهزة، فوق MQTT |
| مساحة الأسماء الموحدة (UNS) | نمط معماري تنشر فيه الأنظمة بياناتها وتستهلكها ضمن بنية موضوعات هرمية مشتركة واحدة |
| توزيع ويبل | توزيع إحصائي لأزمنة الفشل؛ يُظهر معامل الشكل فيه سلوك المرحلة المبكرة أو العشوائي أو مرحلة التآكل |
</translation>
