## مسرد المصطلحات

| المصطلح | المعنى |
|---|---|
| كشف الشذوذ | أساليب تتعلم السلوك الطبيعي وتُبلغ عن الانحرافات عنه، دون الحاجة إلى أمثلة للأعطال |
| الحالة كما وُجدت | ما يجده الفني فعلياً عند فتح مكوّن ما أو إزالته؛ وهي المرجع الفعلي للتنبيهات |
| BPFO / BPFI / FTF / BSF | ترددات أعطال المحامل المميزة: تردد مرور الكرات بالحلقة الخارجية، وتردد مرورها بالحلقة الداخلية، والتردد الأساسي للقفص (FTF)، وتردد دوران الكرات حول نفسها (BSF) |
| الصيانة المبنية على الحالة (CBM) | صيانة تُطلق عندما يتجاوز حالٌ مقاس حداً محدداً |
| CMMS / EAM | نظام إدارة الصيانة المحوسب / إدارة الأصول المؤسسية؛ وهما المكان الذي تُحفظ فيه أوامر العمل والأصول والسجل |
| ترتيب الأهمية | تقييم منظم للأصول حسب عواقب الأعطال واحتمال حدوثها |
| الحوسبة الطرفية | معالجة البيانات قرب الآلة (البوابة أو الحاسب الصناعي) قبل إرسالها إلى الجهات الأخرى |
| تحليل الغلاف (Envelope analysis) | تقنية اهتزاز تفصل الصدمات عالية التردد لكشف عيوب المحامل والتروس في مراحلها المبكرة |
| ESA / MCSA | تحليل البصمة الكهربائية / تحليل بصمة تيار المحرك؛ وهو تشخيص من تيار التغذية وفولتية المحرك |
| FFT | تحويل فورييه السريع؛ يحوّل الإشارة الزمنية إلى طيفها الترددي |
| العطل الوظيفي (F) | النقطة التي لم يعد فيها الأصل قادراً على أداء وظيفته المطلوبة |
| IIoT | إنترنت الأشياء الصناعي: أجهزة استشعار وأجهزة وبرمجيات متصلة في البيئات الصناعية |
| ISO 13374 | سلسلة ISO الخاصة بمعالجة البيانات والاتصال وعرضها في مراقبة الحالة والتشخيص |
| ISO 17359 | إرشادات عامة لإعداد برنامج مراقبة الحالة |
| ISO 20816 | قياس اهتزاز الآلات وتقييمه (السلسلة اللاحقة لمعيار ISO 10816) |
| MQTT | بروتوكول مراسلة خفيف الوزن قائم على النشر والاشتراك، وهو معيار من OASIS |
| MTBF / MTTR | متوسط الزمن بين الأعطال / متوسط زمن الإصلاح |
| فترة P-F الصافية | فترة P-F ناقص فترة الفحص: وهي مدة الإنذار المبكر التي يمكن الاعتماد عليها فعلياً |
| منحنى P-F / فترة P-F | منحنى الحالة مع الزمن من الفشل المحتمل القابل للكشف (P) حتى العطل الوظيفي (F)؛ والزمن الفاصل بينهما |
| PdM (الصيانة التنبؤية) | صيانة يُحدَّد توقيتها بالحالة المقاسة مع توقع تطورها |
| الامتثال لصيانة الوقاية (PM compliance) | نسبة أوامر عمل الصيانة الوقائية المستحقة التي أُنجزت ضمن النافذة المتفق عليها |
| الدقة / الاستدعاء | نسبة التنبيهات الحقيقية / نسبة الأعطال الحقيقية التي تم التنبيه إليها في الوقت المناسب |
| الصيانة الوصفية (Prescriptive) | صيانة يقترح فيها النظام أيضاً الإجراء وتوقيته |
| RCM (الصيانة المتمحورة حول الموثوقية) | منهج منظم لاختيار مهمة الصيانة الملائمة لكل نمط عطل بناءً على عواقبه |
| RUL (العمر المتبقي المفيد) | تقدير الزمن أو الدورات المتبقية حتى يصل الأصل إلى حد عطل محدد |
| Sparkplug | مواصفة من Eclipse تضيف أعرافاً صناعية، ومنها إدارة حالة الأجهزة، فوق بروتوكول MQTT |
| المساحة الموحدة للبيانات (UNS) | نمط معماري تنشر فيه الأنظمة البيانات وتستهلكها ضمن بنية موضوعات هرمية مشتركة واحدة |
| توزيع ويبل | توزيع إحصائي لأزمنة الأعطال؛ ويُظهر معامل الشكل فيه سلوك العطل المبكر أو العشوائي أو التآكل |
