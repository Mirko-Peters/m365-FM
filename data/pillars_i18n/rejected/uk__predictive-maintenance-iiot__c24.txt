## Глосарій

| Термін | Значення |
|---|---|
| Виявлення аномалій | Методи, які вивчають нормальну поведінку та позначають відхилення без потреби в прикладах відмов |
| Стан, виявлений під час огляду (as-found) | Те, що технік фактично виявляє під час відкриття або demontажу компонента; об'єктивна основа для оцінки сигналів тривоги |
| BPFO / BPFI / FTF / BSF | Характеристичні частоти дефектів підшипника: частота проходження кульок по зовнішньому кільцю, по внутрішньому кільцю, основна частота сепаратора (клітки), частота обертання кульки |
| CBM (технічне обслуговування за станом) | Обслуговування, що запускається, коли виміряний стан перевищує граничне значення |
| CMMS / EAM | Комп'ютеризована система управління технічним обслуговуванням / управління активами підприємства; місце зберігання наряд-завдань, активів та історії |
| Ранжування за критичністю | Структурована оцінка активів за наслідками та ймовірністю відмови |
| Периферійні обчислення (Edge computing) | Обробка даних поблизу машини (шлюз, промисловий ПК) до їх передавання далі |
| Аналіз огинаючої (envelope) | Метод вібраційного аналізу, що демодулює високочастотні удари, щоб виявити ранні дефекти підшипників і зубчастих передач |
| ESA / MCSA | Аналіз електричного сигналу / аналіз сигнатури струму двигуна; діагностика за струмом і напругою живлення двигуна |
| FFT | Швидке перетворення Фур'є; перетворює часовий сигнал на його частотний спектр |
| Функціональна відмова (F) | Момент, коли актив більше не може виконувати необхідну йому функцію |
| IIoT | Промисловий інтернет речей: з'єднані датчики, пристрої та програмне забезпечення в промисловому середовищі |
| ISO 13374 | Серія стандартів ISO щодо обробки даних, зв'язку та подання інформації для моніторингу стану й діагностики |
| ISO 17359 | Загальні настанови щодо створення програми моніторингу стану |
| ISO 20816 | Вимірювання та оцінка вібрації машин (серія-наступник ISO 10816) |
| MQTT | Легкий протокол обміну повідомленнями за принципом публікації/підписки, стандарт OASIS |
| MTBF / MTTR | Середній час напрацювання на відмову / середній час відновлення |
| Чистий інтервал P-F | Інтервал P-F мінус інтервал інспекцій: попередження, на яке можна реально розраховувати |
| Крива P-F / інтервал P-F | Крива стану в часі від виявлюваної потенційної відмови (P) до функціональної відмови (F); час між ними |
| PdM (прогнозне технічне обслуговування) | Обслуговування, призначене за виміряним станом і прогнозом його розвитку |
| Дотримання графіка PM | Частка запланованих робіт планового обслуговування, виконаних у погодженому вікні |
| Точність / повнота | Частка сигналів тривоги, що були реальними / частка реальних відмов, про які вчасно подано сигнал |
| Приписувальне обслуговування (Prescriptive maintenance) | Обслуговування, за якого система також рекомендує дію та її час |
| RCM (надійнісно-орієнтоване обслуговування) | Структурований метод вибору відповідного виду обслуговування для кожного виду відмови на основі її наслідків |
| RUL (залишковий ресурс) | Оцінка часу або циклів до досягнення активом визначеної граничної межі відмови |
| Sparkplug | Специфікація Eclipse, що додає промислові конвенції, зокрема керування станом пристроїв, поверх MQTT |
| Уніфікований простір імен (UNS) | Архітектурний шаблон, за якого системи публікують і споживають дані в одній спільній ієрархічній структурі тем |
| Розподіл Вейбулла | Статистичний розподіл часів відмов; його параметр форми показує поведінку на ранньому етапі, випадкову або зношувальну |
</translation>
