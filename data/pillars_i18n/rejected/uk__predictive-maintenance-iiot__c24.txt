## Глосарій

| Термін | Значення |
|---|---|
| Виявлення аномалій | Методи, які навчаються нормальній поведінці та позначають відхилення без потреби в прикладах відмов |
| Стан, виявлений при огляді (as-found condition) | Те, що технік фактично виявляє під час відкриття або демонтажу компонента; еталон для оцінки сигналів тривоги |
| BPFO / BPFI / FTF / BSF | Характеристичні частоти дефектів підшипника: частота проходження тіл кочення по зовнішньому кільцю, по внутрішньому кільцю, основна частота обойми (сепаратора), частота обертання тіл кочення |
| CBM (condition-based maintenance) | Технічне обслуговування, що запускається, коли виміряний стан перевищує граничне значення |
| CMMS / EAM | Комп'ютеризована система керування технічним обслуговуванням / управління активами підприємства; місце зберігання заявок на роботи, активів та історії |
| Ранжування за критичністю | Структурне оцінювання активів за наслідками та ймовірністю відмови |
| Периферійні обчислення (edge computing) | Обробка даних поблизу обладнання (шлюз, промисловий ПК) перед їх передачею далі |
| Аналіз огинаючої (envelope analysis) | Метод вібраційної діагностики, що демодулює високочастотні удари для виявлення ранніх дефектів підшипників і зубчастих передач |
| ESA / MCSA | Аналіз електричних сигнатур / аналіз сигнатур струму двигуна; діагностика за струмом і напругою живлення двигуна |
| FFT | Швидке перетворення Фур'є; перетворює часовий сигнал на його частотний спектр |
| Функціональна відмова (F) | Момент, коли актив більше не може виконувати потрібну йому функцію |
| IIoT | Промисловий інтернет речей: з'єднані між собою датчики, пристрої та програмне забезпечення в промислових умовах |
| ISO 13374 | Серія стандартів ISO щодо обробки, передавання та подання даних для моніторингу стану та діагностики |
| ISO 17359 | Загальні настанови щодо створення програми моніторингу стану |
| ISO 20816 | Вимірювання та оцінювання вібрації машин (серія-наступник ISO 10816) |
| MQTT | Легкий протокол обміну повідомленнями за моделлю публікації та підписки, стандарт OASIS |
| MTBF / MTTR | Середній час напрацювання на відмову / середній час відновлення |
| Чистий інтервал P-F | Інтервал P-F за вирахуванням інтервалу інспекції: те попередження, на яке справді можна розраховувати |
| Крива P-F / інтервал P-F | Крива зміни стану у часі від виявлюваної потенційної відмови (P) до функціональної відмови (F); проміжок часу між ними |
| PdM (predictive maintenance) | Технічне обслуговування, призначене за виміряним станом і прогнозом його розвитку |
| Відповідність графіку ТО (PM compliance) | Частка запланованих робіт планово-попереджувального обслуговування, виконаних у погодженому вікні |
| Точність / повнота (precision / recall) | Частка сигналів тривоги, що виявилися справжніми / частка справжніх відмов, про які вчасно подано сигнал |
| Приписувальне обслуговування (prescriptive maintenance) | Обслуговування, у якому система також рекомендує дію та її час |
| RCM (reliability-centered maintenance) | Структурований метод вибору відповідного виду обслуговування для кожного виду відмови на основі її наслідків |
| RUL (remaining useful life) | Оцінений час або кількість циклів до досягнення активом визначеної граничної межі відмови |
| Sparkplug | Специфікація Eclipse, що додає промислові угоди, зокрема керування станом пристроїв, до MQTT |
| Уніфікований простір імен (UNS) | Архітектурний шаблон, у якому системи публікують і споживають дані в одній спільній ієрархічній структурі тем |
| Розподіл Вейбулла | Статистичний розподіл часів відмов; його параметр форми показує поведінку на ранньому етапі, випадкову поведінку або поведінку зносу |
</translation>
