## Glosariusz

| Termin | Znaczenie |
|---|---|
| Wykrywanie anomalii | Metody, które uczą się normalnego zachowania i sygnalizują odchylenia, bez potrzeby przykładów awarii |
| Stan stwierdzony (as-found) | To, co technik rzeczywiście zastaje po otwarciu lub demontażu komponentu; punkt odniesienia dla alarmów |
| BPFO / BPFI / FTF / BSF | Charakterystyczne częstotliwości uszkodzeń łożysk: częstotliwość przejścia kulek po bieżni zewnętrznej, po bieżni wewnętrznej, częstotliwość podstawowa koszyka (FTF), częstotliwość obrotu kulki (BSF) |
| CBM (utrzymanie ruchu oparte na stanie) | Konserwacja uruchamiana, gdy mierzony stan przekroczy wartość graniczną |
| CMMS / EAM | Komputerowy system zarządzania utrzymaniem ruchu / zarządzanie aktywami przedsiębiorstwa; miejsce przechowywania zleceń pracy, maszyn i historii |
| Ranking krytyczności | Ustrukturyzowana punktacja maszyn według skutków i prawdopodobieństwa awarii |
| Obliczenia brzegowe (edge computing) | Przetwarzanie danych w pobliżu maszyny (bramka, przemysłowy komputer) przed ich dalszym przesłaniem |
| Analiza obwiedni (envelope) | Technika analizy drgań, która demoduluje wysokoczęstotliwościowe udary, aby ujawnić wczesne uszkodzenia łożysk i kół zębatych |
| ESA / MCSA | Analiza sygnatury elektrycznej / analiza sygnatury prądu silnika; diagnostyka na podstawie prądu i napięcia zasilania silnika |
| FFT | Szybka transformata Fouriera; zamienia sygnał czasowy na widmo częstotliwościowe |
| Awaria funkcjonalna (F) | Punkt, w którym maszyna nie może już wykonywać wymaganej funkcji |
| IIoT | Przemysłowy internet rzeczy: połączone czujniki, urządzenia i oprogramowanie w środowisku przemysłowym |
| ISO 13374 | Seria norm ISO dotycząca przetwarzania, komunikacji i prezentacji danych w monitorowaniu stanu i diagnostyce |
| ISO 17359 | Ogólne wytyczne dotyczące wdrażania programu monitorowania stanu |
| ISO 20816 | Pomiar i ocena drgań maszyn (seria następcza po ISO 10816) |
| MQTT | Lekki protokół komunikacyjny publish/subscribe, standard OASIS |
| MTBF / MTTR | Średni czas między awariami / średni czas naprawy |
| Rzeczywisty przedział P-F | Przedział P-F pomniejszony o interwał inspekcji: ostrzeżenie, na które można faktycznie liczyć |
| Krzywa P-F / przedział P-F | Krzywa stanu w czasie od wykrywalnej potencjalnej awarii (P) do awarii funkcjonalnej (F); czas między nimi |
| PdM (utrzymanie predykcyjne) | Konserwacja planowana według mierzonego stanu oraz prognozy jego rozwoju |
| Zgodność PM | Udział zleceń prewencyjnych wykonanych w uzgodnionym terminie spośród tych, które były wymagane |
| Precyzja / czułość (recall) | Udział alarmów, które były prawdziwe / udział rzeczywistych awarii, o których zdążono zaalarmować |
| Utrzymanie preskryptywne | Konserwacja, w której system dodatkowo rekomenduje działanie i jego termin |
| RCM (utrzymanie ruchu zorientowane na niezawodność) | Ustrukturyzowana metoda doboru właściwego zadania konserwacyjnego dla każdego rodzaju awarii na podstawie jej skutków |
| RUL (pozostały czas użytkowania) | Szacowany czas lub liczba cykli do osiągnięcia przez maszynę zdefiniowanej granicy awarii |
| Sparkplug | Specyfikacja Eclipse, która dodaje do MQTT konwencje przemysłowe, w tym zarządzanie stanem urządzeń |
| Zunifikowana przestrzeń nazw (UNS) | Wzorzec architektury, w którym systemy publikują i odbierają dane w jednej, wspólnej, hierarchicznej strukturze tematów |
| Rozkład Weibulla | Rozkład statystyczny czasów awarii; jego parametr kształtu wskazuje zachowanie wczesne, losowe lub zużyciowe |
