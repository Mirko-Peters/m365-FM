## Glosariusz

| Termin | Znaczenie |
|---|---|
| Wykrywanie anomalii | Metody, które uczą się normalnego zachowania i oznaczają odchylenia, bez potrzeby przykładów awarii |
| Stan wykryty (as-found) | To, co technik faktycznie stwierdza po otwarciu lub demontażu komponentu; punkt odniesienia dla alarmów |
| BPFO / BPFI / FTF / BSF | Charakterystyczne częstotliwości uszkodzeń łożysk: częstotliwość przejścia kulek przez bieżnię zewnętrzną, wewnętrzną, częstotliwość podstawowa klatki (koszyka), częstotliwość obrotu kulki |
| CBM (utrzymanie oparte na stanie) | Utrzymanie ruchu uruchamiane, gdy mierzony stan przekracza granicę |
| CMMS / EAM | Komputerowy system zarządzania utrzymaniem ruchu / zarządzanie majątkiem przedsiębiorstwa; miejsce, w którym znajdują się zlecenia pracy, składniki majątku i historia |
| Ranking krytyczności | Ustrukturyzowana ocena składników majątku według konsekwencji i prawdopodobieństwa awarii |
| Obliczenia brzegowe (edge computing) | Przetwarzanie danych blisko maszyny (bramka, przemysłowy komputer PC) przed ich dalszym przesłaniem |
| Analiza obwiedni (envelope) | Technika analizy drgań, która demoduluje wysokoczęstotliwościowe udary, aby ujawnić wczesne uszkodzenia łożysk i kół zębatych |
| ESA / MCSA | Analiza sygnatury elektrycznej / analiza sygnatury prądu silnika; diagnostyka na podstawie prądu i napięcia zasilania silnika |
| FFT | Szybka transformata Fouriera; przekształca sygnał czasowy w jego widmo częstotliwościowe |
| Awaria funkcjonalna (F) | Punkt, w którym składnik majątku nie może już wypełniać wymaganej funkcji |
| IIoT | Przemysłowy internet rzeczy: połączone czujniki, urządzenia i oprogramowanie w środowisku przemysłowym |
| ISO 13374 | Seria norm ISO dotyczących przetwarzania, komunikacji i prezentacji danych w monitorowaniu stanu i diagnostyce |
| ISO 17359 | Ogólne wytyczne dotyczące tworzenia programu monitorowania stanu |
| ISO 20816 | Pomiar i ocena drgań maszyn (seria następcza po ISO 10816) |
| MQTT | Lekki protokół komunikacyjny publikuj/subskrybuj, standard OASIS |
| MTBF / MTTR | Średni czas między awariami / średni czas naprawy |
| Netto przedział P-F | Przedział P-F pomniejszony o interwał kontroli: ostrzeżenie, na które można faktycznie liczyć |
| Krzywa P-F / przedział P-F | Krzywa stanu w czasie od wykrywalnej potencjalnej awarii (P) do awarii funkcjonalnej (F); czas między nimi |
| PdM (utrzymanie predykcyjne) | Utrzymanie zaplanowane według mierzonego stanu oraz prognozy jego rozwoju |
| Zgodność PM | Udział zleceń prewencyjnych utrzymania ruchu zrealizowanych w uzgodnionym terminie |
| Precyzja / czułość (recall) | Udział alarmów, które były prawdziwe / udział rzeczywistych awarii, o których zaalarmowano na czas |
| Utrzymanie preskryptywne | Utrzymanie, w którym system dodatkowo rekomenduje działanie i jego termin |
| RCM (utrzymanie ukierunkowane na niezawodność) | Ustrukturyzowana metoda doboru właściwego zadania utrzymaniowego dla każdego trybu awarii na podstawie jego konsekwencji |
| RUL (pozostały użyteczny czas życia) | Szacowany czas lub liczba cykli do osiągnięcia przez składnik majątku określonej granicy awarii |
| Sparkplug | Specyfikacja Eclipse, która dodaje konwencje przemysłowe, w tym zarządzanie stanem urządzeń, do protokołu MQTT |
| Ujednolicona przestrzeń nazw (UNS) | Wzorzec architektury, w którym systemy publikują i odbierają dane w jednej wspólnej, hierarchicznej strukturze tematów |
| Rozkład Weibulla | Rozkład statystyczny czasów awarii; jego parametr kształtu wskazuje zachowanie we wczesnym okresie eksploatacji, losowe lub zużyciowe |
