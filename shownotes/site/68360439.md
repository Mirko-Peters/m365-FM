## FAQ

**Why doesn't Copilot in Excel change my spreadsheet?**

You are probably only using chat. The episode explains that chat answers questions and points out matching rows but does not edit anything, while the app skills side applies formulas, formatting, tables and transformations to the sheet. Each change appears as a preview first, so you approve what Copilot proposes before it becomes permanent.

**Which Copilot prompts clean messy data in Excel?**

The episode groups them into three commands: normalize, validate and transform. Examples include standardizing all date columns to one format, highlighting rows with high totals that lack shipping data, and creating a summary table of revenue per normalized region for Power BI. One prompt to clean headers, remove duplicates and align formats covers most routine cleanup.

**Why does messy Excel data break Power BI and Power Automate?**

Excel has no schema enforcement, no input validation and no relational discipline, so inconsistent entries pass silently. Trailing spaces break lookups and make flows fail, mixed number and text columns stop formulas, renamed headers break Power Automate, and differently labeled regions produce wrong Power BI totals. Cleaning data with Copilot before export prevents these downstream failures.
