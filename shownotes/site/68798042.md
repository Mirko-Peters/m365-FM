## FAQ

**Why doesn't Intune scale on its own for large device fleets?**

Intune declares what devices should be, but it does not reconcile drift, purge stale devices or orchestrate conditional workflows by itself. At thousands of endpoints, manual exports, standing admin rights and deferred cleanup pile up. The episode pairs Intune with Azure Automation, Azure Functions, managed identities, Microsoft Graph and Log Analytics.

**How do I automatically disable stale Intune devices?**

Run a scheduled Azure Automation runbook under a system-assigned managed identity that queries Microsoft Graph for devices not synced for 60 days. Exclude tagged devices such as loaners, lab and break-glass hardware, disable the rest, notify custodians and log each action with a reason to Log Analytics, keeping a grace window for restores.

**Why use managed identities instead of client secrets for Intune automation?**

Managed identities remove stored keys entirely. The identity lives and dies with the runbook or function app and holds only the Graph permissions granted to it, so there are no recycled client secrets or forgotten app registrations. If an application identity is unavoidable, keep it in Key Vault with role-based access and rotation.
