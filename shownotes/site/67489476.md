## FAQ

**What is the difference between GitHub Copilot agent mode and autocomplete?**

Autocomplete finishes lines, while agent mode coordinates changes across files. When a method changes, agent mode can propose matching edits in related configuration files or deployment templates instead of leaving you to hunt them down. The episode stresses that you still open the diff, run unit tests and decide whether to accept or reject the edits.

**Can GitHub Copilot agent mode fix errors that span multiple files in an Azure project?**

Yes, it is designed to look beyond the line a stack trace highlights. In the episode's example, a queue trigger fails because the binding does not match the method signature, and agent mode can propose the code change, the corrected binding and edits to deployment scripts, which you then review, test and confirm.

**How can I scaffold a feature from a plain-language spec with GitHub Copilot?**

Describe the feature in plain language, for example a reporting module with an API endpoint, storage and role-based access, and agent mode generates a baseline across your solution. The episode shows controllers, models and service registrations being created, while some spots still need manual refinement because the output does not always match project conventions.
