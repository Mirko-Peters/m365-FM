## FAQ

**Why does a Power BI gateway work in test but fail in production?**

Usually because production firewalls filter outbound traffic more strictly than test environments. The gateway makes dynamic outbound connections to Azure services, and a passing portal connection test only proves one handshake worked at that moment. In the episode, relaxed outbound rules in test hid the problem until production blocked the gateway's calls, causing repeated Service Bus errors.

**How do you fix Power BI gateway firewall problems?**

Whitelist fully qualified domain names instead of chasing changing IP addresses. The episode's diagnostic path was to check firewall logs for inbound versus outbound drops, temporarily open outbound traffic during a controlled maintenance window, then run packet captures to trace destination names. Adding the correct FQDN entries stopped the errors without reinstalling the gateway or rewriting configs.

**When should you use a VNet data gateway instead of an on-premises data gateway?**

Consider it when most key data already lives in Azure, your organization is tired of perimeter firewall change requests, and your team can handle Azure networking basics like NSGs, subnets, private endpoints and route tables. It reduces firewall and service account pain, but data source permissions and Azure network configuration still need careful checking.
