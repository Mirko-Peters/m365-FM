## FAQ

**What does the Microsoft 365 Agents SDK provide for building agents?**

It standardizes identity, conversation state, channel protocol and delivery so your code can focus on reasoning and tools. The SDK offers sign-in handlers for act-as-user access, turn state that survives across nodes, Activity protocol adapters for Teams, web chat, Slack and Copilot Studio, and automatic streaming detection, while staying model agnostic.

**Why do custom AI agents for Microsoft 365 fail security review?**

They usually run as a blanket service principal instead of acting as the user, which breaks permission fidelity and audit trails. DIY bots also tend to ignore Purview signals, skip DLP enforcement and produce conversations nobody can discover. Security teams reject agents that cannot respect sensitivity labels, retention and legal hold.

**Is the Microsoft 365 Agents SDK free to use?**

According to the episode, the SDK itself is open source and free; you pay only for the downstream services you choose, such as models, search and storage. That way you inherit enterprise plumbing like identity, state and channel adapters while keeping your own orchestrator, for example Semantic Kernel, Azure AI Foundry or OpenAI.
