## FAQ

**How can you keep the cost of an internal AI assistant under control?**

Combine hybrid model routing with per-user budgets. Edgar's team saw costs rise sharply after connecting Anthropic models to their Mela AI assistant. They added an orchestration layer that sends simple tasks to local models and complex ones to cloud models, and gave each user a monthly budget per model before switching them to a cheaper model.

**When should you use Copilot Studio instead of Microsoft Foundry?**

Use Copilot Studio when low-code or no-code agents inside a defined space are enough, and Microsoft Foundry when you need full control. Edgar describes three levels: Microsoft 365 Copilot creates agents from a prompt, Copilot Studio works in a confined container, and Foundry lets you build anything, including pro-code and locally hosted agents.

**What do evaluations in Microsoft Foundry test?**

Evaluations compare an agent's answers against a list of expected questions and results to show whether it meets expectations. Edgar uses them to check overall performance, to test for prompt injection and malicious use, and to measure hallucination, so the team can monitor how accurately the application responds before and after it goes into production.
