## FAQ

**When should you move data from SharePoint lists to Dataverse or SQL?**

Move it when you need transactional integrity, complex joins or multi-hop lookups. The episode treats SharePoint as a collaboration substrate, not a relational database, and advises one lookup per critical view. Pushing beyond that eventually hits thresholds, breaks delegation and leaves apps showing blank screens.

**Why is item-level permission in SharePoint a problem?**

Breaking inheritance on every item forces the server to check an access control list for each row whenever a user queries the list, which destroys performance at scale. The episode recommends securing data at site or list level, using separate lists or sources for different audiences, and assigning permissions to groups, never individuals.

**How do you stop Power Automate flows from failing silently?**

Build defensive design into every flow. Add trigger conditions so flows run only on meaningful changes, set concurrency limits to avoid race conditions, and wrap main actions in a try scope with a catch branch that alerts you on failure. Otherwise a flow can fail for weeks until a user asks about an approval.
