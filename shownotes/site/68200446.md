## FAQ

**Why use PowerShell instead of the Microsoft 365 admin center for Copilot?**

PowerShell scales and leaves evidence, while the admin center is built for visibility. Bulk tasks like disabling Copilot for all non-executive users require clicking into each user in the portal, whereas a script handles the whole tenant at once, logs every action with timestamps and can be repeated, versioned and shown to auditors.

**How can I check which users have Copilot licenses with PowerShell?**

Query users with a license filter by SKU, select the properties you need and export the result as a CSV with timestamps. The episode contrasts this with scrolling, filtering and exporting from the admin center, then cleaning duplicates in Excel. Scripts can also group users by department and cross-reference them against compliance policies.

**What does auditing Copilot with PowerShell give auditors that dashboards do not?**

It gives raw, timestamped records instead of summarized trends. Using audit log searches and Graph endpoints, admins can see who changed what and when, export results as JSON, and run nightly scheduled exports into storage. The episode argues these archives become defensible evidence, while admin center activity views are simplified summaries meant for management slides.
