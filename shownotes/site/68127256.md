## FAQ

**What is the difference between an AI agent and automation?**

Automation executes fixed rules you gave it, while an AI agent observes, plans and acts with some autonomy. Automation is fast and consistent but breaks when details change. An agent can carry memory across tasks, adjust to changing conditions and make decisions without constant oversight, using a feedback loop rather than replaying a script.

**What are the five core components of an AI agent?**

The five components are perception, memory, reasoning, learning and action. Perception takes in signals, memory combines short-term session context with long-term stores, reasoning weighs options against goals, learning adjusts behavior from outcomes, and action executes through APIs and commands. If one is missing, the episode argues, the system falters and is not a real agent.

**Which Microsoft platform should I use to build an agent?**

Choose by user type, mission complexity, data sensitivity and integration needs. SharePoint agents suit end users working with documents, Copilot Studio suits low-code conversational helpers, Azure AI Foundry fits complex, regulated enterprise systems, and Semantic Kernel and AutoGen suit developers who need orchestration. For well-defined, repeatable processes, plain automation is still fine.
