## FAQ

**Why is sharing Power BI reports by link or PDF a problem?**

Ad hoc links and emailed PDFs cut reports off from their lineage. Users cannot see endorsements, owners or refresh health, copies drift into conflicting numbers, and nobody can trace who viewed or exported what. The episode recommends org apps as the only doorway, with alternate paths removed and labels, endorsements and navigation visible.

**Where should row-level security be defined in Power BI?**

Define row-level and object-level security in the certified dataset, not as filters or hidden visuals in a report. Build a test matrix per persona, test in the service with view as and sample users from Azure AD groups, and keep role names identical across development, test and production, stored in source control.

**How do deployment pipelines keep Power BI dashboards trustworthy?**

They move content in order from development to test to production, so changes are reviewed before users see them. The episode pairs pipelines with Git for PBIR files and dataset definitions, automated checks for labels, model size and query duration, plain-language version notes for each promotion, and a previous build kept ready for rollback.
