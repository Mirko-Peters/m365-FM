## FAQ

**Why isn't infrastructure as code enough to govern Azure?**

Because a template only describes how a resource looks, not whether it may exist at all. Without Azure Policy, a Bicep template becomes a fast way to deploy non-compliant infrastructure, and nothing stops someone from opening a resource to the internet afterwards. Deny policies at the control plane reject forbidden states before resources are created.

**What is bounded autonomy for AI agents in Azure?**

Bounded autonomy means defining an agent's intent, constraints and escalation paths, then letting it act freely inside those limits. A cost optimization agent might deallocate unused test resources but never touch backups or production databases, escalating to a human instead. Microsoft Entra Agent ID gives each agent its own identity governed by conditional access.

**What should an Azure administrator do first to improve governance?**

Start with a measured assessment rather than a big transformation. Audit Azure Policy usage and non-compliant resources, review service principals for broad permissions and missing owners, and check whether subscriptions are created manually or through automation. Then pick the one deny policy that removes the greatest risk, test it in a non-production subscription, and review monthly.
