## FAQ

**Why does Microsoft 365 Copilot give inconsistent answers?**

Copilot reflects the context it retrieves, so inconsistent answers usually come from a fragmented tenant rather than a weak model. Broken SharePoint inheritance, overshared sites, inconsistent sensitivity labels and duplicate documents feed conflicting evidence into retrieval, and the model blends it. Better prompts cannot fix that; permission trimming, authoritative sources and relevance windows can.

**What is the difference between a context window and a relevance window?**

The context window is the technical limit of what the model can ingest, while the relevance window is the governance boundary of evidence allowed for a specific decision. A relevance window names eligible sources, versions and time horizons, applies precedence rules when sources conflict, and makes the system escalate instead of guessing when evidence is missing.

**How should you start a Copilot and agent pilot?**

Start with a seven-day context inventory, then run a 30-day pilot on one painful workflow. The inventory assigns owners and finds the top three context breaks. The pilot implements Graph memory, Dataverse state, Fabric learning and Copilot interaction with explicit refusal conditions, and measures cycle time, rework, exception rate and permission faults.
