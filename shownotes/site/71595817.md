## FAQ

**How is a Copilot cowork engine different from a chat assistant?**

An assistant reacts to questions and returns chat responses, while a cowork engine executes an intent in the background and delivers an artifact. Asked to prepare an audit pack, it pulls contracts from SharePoint, external data through Microsoft Graph connectors and approvals from Teams, then saves a decision-ready pack to OneDrive with every claim linked to its source.

**How does governance keep a cowork engine from exposing sensitive data?**

Governance is built into execution, so the engine sees only what the user is permitted to see through Microsoft Entra ID. Generated artifacts inherit sensitivity labels from their sources via Microsoft Purview, outputs follow retention policies from creation, and every claim links back to its source document so humans can verify the result quickly.

**How do you measure the ROI of a Copilot cowork engine?**

Use time to decision as the primary metric: the elapsed time from a request to a validated output a human can act on. Also track rework rate, which should fall as the memory layer matures. Start by shadowing one high-frequency workflow, such as a weekly status report, and timing the searching, not just the writing.
