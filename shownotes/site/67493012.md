## FAQ

**Why can guests in Microsoft Teams see more files than intended?**

Guests can see more because Teams files live in SharePoint, which controls access through inheritance rather than channels. A guest added to one channel may click into the underlying document library and reach folders unrelated to their project. The episode describes a sales library that also held HR guidelines and payroll samples, visible to an external partner.

**What are the three identity layers behind a Microsoft 365 guest account?**

A guest is three things at once: the invitation and authentication method, the directory object in Azure AD (now Microsoft Entra ID), and the app-level permissions. Each app interprets the identity with its own rules. If any one layer is left unmanaged, such as a lingering directory object, access can persist after the project ends.

**How do you make guest access policies scale for hundreds of external users?**

Classify scenarios into tiers instead of applying one policy to everyone, then automate. Separate short-term project guests from long-term partners and shared channels, set expiration rules unless owners confirm renewal, use access reviews so project leads validate who still belongs, and remove unused accounts from sensitive groups. Manual approvals alone collapse as contractor numbers grow.
