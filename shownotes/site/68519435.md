## FAQ

**What hardware do you need to run Azure Local on a mini PC?**

You need one machine with virtualization support, a boot disk and a second SSD for storage, plus power and Ethernet. The episode says modern mini PCs with an Intel i5, i7 or AMD Ryzen and 16 to 32 gigabytes of RAM are capable, and demos have used Intel NUCs and refurbished business desktops.

**Does Azure Local need Active Directory?**

No, small Azure Local deployments can use local identity with Azure Key Vault instead. Nodes authenticate to each other with certificates, while Key Vault stores cluster certificates, encryption keys, BitLocker secrets and admin credentials in one auditable place. You choose this option during deployment, so there are no domain controllers, replication schedules or DNS dependencies to maintain.

**Is Azure Arc free to use?**

Azure Arc's core registration is free, according to the episode. Once attached, a machine behaves like an Azure resource in the portal. You start paying only when you enable optional services such as Microsoft Defender for Cloud, Azure Policy or Azure Monitor, which bill per core or per gigabyte ingested, so you pay for governance rather than compute.
