## FAQ

**When does public cloud on Azure make sense for an enterprise?**

Public-first Azure fits organizations with high change velocity, bursty demand and at least moderate cloud maturity. It works when teams consume managed services instead of rebuilding them and governance can keep pace. It breaks for steady always-on workloads, latency-bound systems and estates where creation is cheap but deletion has no owner.

**What does Azure Arc actually do in a hybrid environment?**

Azure Arc extends Azure Resource Manager to servers, Kubernetes clusters and some data services outside Azure. Onboarded resources get tags, role assignments, policy evaluation and a place in one inventory. It does not make workloads portable or remove latency; it makes governance consistent by anchoring it in Azure.

**How should leaders decide between public cloud, hybrid and multi-cloud?**

Score five axes from one to five: regulatory pressure, latency sensitivity, cost predictability, internal cloud maturity and change velocity. The scores point toward public-first by design, hybrid-first by design, contained multi-cloud by accident, or rare multi-cloud by design. The episode suggests running it in a single 90-minute session with security, platform, application, finance and business owners.
