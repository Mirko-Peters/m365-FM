## FAQ

**What is the request for information action in Copilot Studio?**

It is an action inside a Copilot Studio agent flow that pauses execution until a person responds to an Outlook actionable message. The message contains an embedded mini form with mandatory fields, and the flow only continues once every required value is provided, so missing or questionable data gets confirmed before it is written anywhere.

**Why do AI-driven flows end up writing bad data to Dataverse?**

Mostly because they trust whatever human input they receive. A blank purpose-of-visit field or a mistyped email is treated as valid and passed downstream. The episode describes null values breaking conditions, phantom Dataverse rows with timestamps but no data, approvals granted without safety clearance, and fractured table relationships that later surface in dashboards and audits.

**How does an AI prompt work together with RFI in an agent flow?**

The prompt detects gaps and the RFI gets them fixed by a person. The AI prompt checks a submission and returns structured JSON stating whether it is valid and why. If not, the flow branches to an RFI, the requester fills the missing fields in Outlook, and the flow updates the Dataverse record with a logged confirmation.
