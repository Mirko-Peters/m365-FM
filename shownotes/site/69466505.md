## FAQ

**What is architectural drift in Power BI and Microsoft Fabric?**

Architectural drift is when the meaning of your data changes without explicit intent, review or an accountable owner. Unlike a defect, nothing breaks: measures still return numbers and reports still render. Drift starts in measures, relationships, Power Query transformations, calculation groups and report semantics, and AI agents accelerate it.

**Why are AI agents risky when they edit Power BI relationships?**

Relationship changes rewire filter propagation across the whole model, even when no measure text changes. Agents add relationships by matching key names, flip cross-filter direction to both or reach for many-to-many shortcuts so one visual works. The model still returns numbers, but other reports quietly answer different questions and the schema becomes hard to review.

**Which Power BI tasks are safe to hand to AI agents?**

Agents fit repetitive work with stable semantics and a containable blast radius: descriptions, metadata hygiene, translations, display folders, formatting strings and applying an existing certified measure library. They should not create relationships, redesign schemas or define business KPIs. Mirko's rule is to automate repetition, not meaning, because business decisions need an accountable owner.
