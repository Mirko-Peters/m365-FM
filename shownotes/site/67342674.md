## FAQ

**Why does Microsoft 365 Copilot not know about my company's legacy data?**

Out of the box, Copilot only covers content inside Microsoft 365, such as Outlook, Teams, OneDrive and SharePoint. Internal wikis, old CRMs, custom ticketing platforms and file shares stay invisible, so questions about older processes or customer history return generic answers until those systems are connected, for example through Graph connectors.

**Should I use a Copilot plugin or a Graph connector?**

Use a plugin for one specific integration, such as a critical service with a defined API, and a Graph connector when you need broad, ongoing access to large amounts of business data. Plugins teach Copilot a single new skill, while connectors widen what Copilot can see across entire silos without custom scripts for each source.

**Do Graph connectors respect existing permissions in Microsoft 365?**

Yes, Graph connectors keep the access controls you have already set, so they are not a backdoor. Data is indexed into Microsoft Graph, and Copilot applies the same user permissions and policies regardless of where the content came from. Someone without access to finance records will not see them through Copilot, however clever the prompt.
