## FAQ

**What is Microsoft Rayfin and how is it different from a low-code tool or API gateway?**

Rayfin is a backend definition framework: an open-source SDK and CLI that describes your data models, APIs, authentication, storage and access policies in code. One command compiles that definition into a governed database, isolated functions and wired-up authentication inside Microsoft Fabric, so it is neither a drag-and-drop tool nor just another gateway.

**Why do custom APIs become a problem when you add AI agents?**

Custom APIs were built for human-paced, synchronous request and response, while agents plan sequences, call several APIs in parallel and act autonomously. The episode explains that agents need retry-safe operations, guardrails and stateless, schema-driven tools, so existing APIs end up being retrofitted with rollback logic, rate limiting, validation and audit trails.

**How do you migrate from custom APIs to Rayfin without a big-bang rewrite?**

Use the strangler fig pattern with a facade and an anti-corruption layer. Pick a constrained pilot domain, inventory its APIs, route traffic through a gateway and translate old contracts to the new backend. Move read operations first, then writes and critical workflows, and retire each API once it has no consumers left.
