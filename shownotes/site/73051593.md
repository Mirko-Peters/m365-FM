## FAQ

**What is the difference between A2A and MCP?**

MCP connects an agent to tools, data sources and APIs, while A2A connects agents directly to each other. The episode calls them complementary rather than competing: MCP is the vertical link from an agent down to its tools, and A2A is the horizontal link between agents working side by side on a shared task.

**What is an A2A agent card?**

An agent card is a machine-readable document an A2A agent publishes at a standard well-known URL on its domain. It works like a resume, listing the agent's name, capabilities, skill tags, endpoint, authentication requirements and input and output formats, so an orchestrator can discover it without a central registry.

**How do you connect an external agent to Copilot Studio with A2A?**

You create a connected agent in Copilot Studio and paste the external agent's endpoint URL. Copilot Studio fetches its agent card, reads capabilities, authentication and formats, and builds a connector behind the scenes. The external agent can run on another cloud, as long as it speaks the A2A protocol, with no custom integration code.
