## FAQ

**Why do AI coding agents create insecure Microsoft Entra app registrations?**

AI coding agents sample common defaults from public code rather than your identity policy. Asked to build an Entra integration, they choose client secrets over certificates, request broad Graph write scopes, add offline access and use localhost or wildcard redirects. Each choice works, but copied across repos it multiplies privileged grants nobody intended.

**What is a Spec Kit constitution for identity governance?**

A constitution is a short, machine-checkable list of non-negotiable rules. Examples from the episode include no client secrets for workloads, no user or group exclusions in Conditional Access, scope allow lists per app class, PIM above a threshold and prohibited role pairs. Every feature carries a spec ID that pipelines and approvals reference.

**Which metrics show whether identity governance is working?**

The episode recommends curves instead of tickets closed or trainings delivered. Track consent velocity, blocked permissions, standing privileged roles, PIM activation frequency, effective Conditional Access coverage per persona and MTTR for access incidents. Blocked permissions should spike early and then settle, because zero blocks means the gates are not catching anything.
