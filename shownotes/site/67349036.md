## FAQ

**What is spreadmart chaos in Power BI?**

Spreadmart chaos is when many teams build slightly different copies of the same dataset and measures. Each request spawns another copy, formulas get tweaked, and versions drift until three definitions of total sales exist. Executives then see different numbers for the same metric, meetings turn into debates, and every independent dataset becomes a hidden maintenance project.

**What are calculation groups in Power BI and why use them?**

Calculation groups let you define logic such as year to date, month to date or trailing twelve months once and apply it to any measure. Instead of separate measures for every KPI and time view, users pick from one field. Models shrink, definitions stay consistent everywhere, and new views become a small update to the group.

**How does row-level security work in a Microsoft Fabric semantic model?**

Row-level security rules are defined directly in the semantic model, so every report built on it enforces them automatically. A sales manager in California sees only California numbers, while global leadership sees everything. Users can still build their own reports, and IT changes a rule once instead of copying datasets or updating permissions per report.
