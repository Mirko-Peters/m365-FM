## FAQ

**How do I call Microsoft Graph from PowerShell without modules?**

Use a three-part pattern: get a token, set headers and call the REST endpoint with Invoke-RestMethod. The Authorization header carries the bearer token, Content-Type is application/json for requests with a body, and advanced queries need ConsistencyLevel: eventual. Then follow @odata.nextLink for paging and honor Retry-After when throttled.

**Which authentication flow should I use for Microsoft Graph scripts?**

It depends on where the script runs. Device code suits local testing at a console. Client credentials with a certificate fit unattended automation through an app registration with only the needed application permissions. Managed identity is preferred whenever the workload runs in Azure, because there are no secrets to store or rotate.

**Why does my Graph call return 401 even though I have a token?**

The most common cause is a wrong token audience. A token requested for management.azure.com is rejected by graph.microsoft.com. Request the token for https://graph.microsoft.com instead, using the .default scope with client credentials, Graph scopes with device code, and the Graph resource when asking the managed identity endpoint for a token.
