## FAQ

**Why do single Copilot agents hallucinate?**

According to the episode, hallucination is mostly an architecture problem. One agent that retrieves, reasons and answers works under token pressure with weak retrieval and no reranking, so low-signal chunks crowd out good passages and the model fills the gaps. Splitting retrieval, rerank, generation and verification into separate agents makes each stage testable.

**How do you stop AI agents from leaking content users should not see?**

Make retrieval permission-aware by querying Microsoft Search or the Copilot retrieval API with the user's delegated token instead of a broad service-principal index. A red team agent strips injected instructions, and a blue policy agent checks each tool call against Purview labels, Microsoft Graph permissions and Conditional Access before anything reaches generation.

**What does an AI-generated answer need to pass an audit?**

It needs a replayable record: the original prompt, system message, retrieved passages with file IDs and versions, rerank scores, model version, deployment type and region, token usage and line-level citations. Routing every call through Azure API Management with correlation IDs lets a compliance agent re-enact the session and produce a dossier later.
