## FAQ

**Why do manual SharePoint permission reviews fail at enterprise scale?**

Manual reviews fail because permissions change faster than any spreadsheet snapshot. Large tenants can hold thousands of sites, and access can be inherited, overridden at library, folder or file level, or granted through nested groups. In one example from the episode, a review taking over eighty admin hours still missed guests with access through a nested group.

**How should PnP PowerShell authenticate for unattended permission audits?**

Use app-only authentication with a certificate instead of an interactive user login. You create an app registration, grant it the needed SharePoint and Microsoft Graph permissions, and store the certificate in Azure Key Vault. Scheduled scripts can then connect without prompts, MFA or expiring passwords, and the certificate can be rolled over in one place.

**How do you find inherited SharePoint permissions with Microsoft Graph?**

You have to walk up the hierarchy yourself. A file with no unique permissions inherits from above, so the process checks file, folder, library and site in turn, expands group memberships into real users and guests, and follows paging links and retry-after values. The result is one flattened dataset of effective access per resource.
