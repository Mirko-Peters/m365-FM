## Key takeaways

- Sovereignty is not a region, SKU or compliance pack; it is enforceable authority over identity, keys, data and the control plane that can change all three.
- The EU Data Boundary improves residency but jurisdiction such as the CLOUD Act still reaches the provider, so only external key custody with attested secure key release turns compelled disclosure into unreadable ciphertext.
- A default-deny design minimizes [Conditional Access](https://www.m365.fm/entity/conditional-access/?utm_source=podcast&utm_medium=shownotes&utm_campaign=microsoft-365-sovereignty-why-sovereignty-is-not-a-product) exceptions, versions and restores identity configuration, scopes Azure Arc and landing zones to sovereignty domains, and uses disconnected Azure Local when no external dependency is acceptable.

## FAQ

**Does the EU Data Boundary make Microsoft 365 and Azure sovereign?**

No. The EU Data Boundary commits that customer data for covered services is stored and processed within the EU and EFTA, which improves residency and reduces cross-border processing. It answers where data sits, not who holds authority. Microsoft still receives legal orders and operates the control plane, so identity and admin authority are not transferred.

**How does the CLOUD Act affect data stored in EU Azure regions?**

The CLOUD Act lets US law enforcement compel US technology companies to produce data in their possession, custody or control, even when it is stored abroad, subject to warrants and judicial process. Keeping data in Frankfurt does not remove the provider from legal reach, so the episode recommends external key custody that keeps compelled exports unreadable.

**What is the difference between connected and disconnected Azure Local?**

Connected Azure Local keeps hardware on premises but uses Azure Arc to project it into Azure Resource Manager, so control and identity still run through the cloud and Entra. Disconnected Azure Local runs its own local control plane and an identity provider built on Active Directory, trading fewer services and more operational work for independence.
