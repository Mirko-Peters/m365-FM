## FAQ

**Do I need to learn a new stack to build Microsoft Teams apps?**

No, Teams acts as a host for the React, Node and Express app you already build. The new parts are setup: a manifest that tells Teams how to display the app, identity registration, and tools such as Teams Toolkit or the Developer Portal for scaffolding, manifest editing and local tunneling.

**How do I turn an existing React app into a Teams personal tab?**

Run the app locally as usual, point the Teams manifest at its URL or a tunneled endpoint, and upload the app package into Teams for testing. The app then loads in an iframe in the Teams sidebar. Components, state management and API calls stay the same; only the hosting location changes.

**Why does login or routing break in a Teams tab?**

A Teams tab runs inside an iframe, so full-window redirects and server-side redirects often fail. For sign-in, use the pop-up flow supported by the Teams JavaScript SDK or Microsoft identity libraries and pass the token back to the app. For routing, keep navigation client-side with in-app routing instead of server-driven redirects.
