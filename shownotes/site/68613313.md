## FAQ

**What is the Workflows agent in Microsoft 365 Copilot?**

The Workflows agent is a Frontier agent inside Microsoft 365 Copilot that turns natural language into automations. You describe the outcome and it assembles the steps across Outlook, Teams, SharePoint, Planner and Microsoft Graph, including triggers, manager lookups, task creation and embedded AI steps to summarize or classify, then shows you a test run.

**When should I still use Power Automate instead of the Workflows agent?**

Use Power Automate for long-running, multi-branch or regulated processes. It handles approvals with escalations and SLAs, retries, idempotency, compensation logic and per-action visual traces for audits. The agent works under a 100-second window when calling external systems, so complex onboarding, finance checklists or chains across several back-office systems belong in Power Automate.

**How do the Workflows agent and Power Automate work together in a hybrid setup?**

The agent handles the conversational front end and Power Automate handles durable execution. The agent captures context, summarizes it and confirms with a human in chat, then triggers a flow with a compact payload of IDs and essentials. The flow performs schema-locked writes, retries, audit stamps and SLA tracking, which fits CRM updates and onboarding.
