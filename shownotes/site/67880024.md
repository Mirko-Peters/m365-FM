## FAQ

**How do I connect a SharePoint list to Power BI?**

Use Power BI Desktop: choose Get data, select the SharePoint Online list connector and paste only the site URL, not the list view link or query strings, then pick your list. Sign in with your organizational account, not a personal Microsoft account. Skip the quick export button in lists if you need scheduled refresh or advanced customization.

**Why does SharePoint list data look messy in Power BI?**

Power BI shows how SharePoint actually stores data: choice fields arrive as nested tables, person fields as records with emails, claims and IDs, lookups as linked tables and dates in UTC. Clean it in Power Query by renaming columns, flattening records, converting time zones, removing system metadata and dropping every field you don't need.

**Which Power BI license do viewers need for a report embedded in SharePoint?**

Viewers usually need Power BI Pro, unless your tenant runs Premium capacity, where access is tied to the capacity instead. Free suits reports only you use. Embedding doesn't bypass permissions, so publish to a shared workspace, grant access through groups and test any row-level security with a non-admin account before announcing the dashboard.
