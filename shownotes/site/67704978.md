## FAQ

**Should I use Azure CLI or Azure PowerShell for Azure automation?**

Use whichever fits the task instead of picking one side forever. Azure CLI returns JSON, which suits quick scripts, build pipelines and CI/CD. Azure PowerShell returns objects, which makes filtering, sorting and reporting easier, for example when bulk editing identities or exporting resource properties into a structured report.

**Can I run Azure CLI commands inside PowerShell?**

Yes, you can call az directly inside a PowerShell session and work with its output right away. In the episode's example, the CLI pulls a list of VMs, PowerShell loops through it, finds the ones with missing tags and exports them to CSV. Watch for quoting and escaping differences between shells.

**Why does my Azure script work locally but fail in Azure Automation?**

Usually because of authentication. Locally you are signed in under your own profile with a cached session, but a hosted environment like Azure Automation has none. Assign a managed identity or service principal, check which permissions that identity has, and confirm that the right CLI or module versions are installed.
