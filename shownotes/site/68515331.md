## FAQ

**What does the Security Copilot phishing triage agent do?**

It investigates reported emails on its own and decides whether they need escalation. The agent parses each message, checks linked domains, evaluates sender behavior and correlates with Defender threat signals. It shows its reasoning as a visual workflow, and when an analyst marks an alert as harmless, it uses that correction to reprioritize similar alerts next time.

**How does the Conditional Access optimization agent find access gaps?**

It continuously scans users, devices, service principals and group memberships against your Conditional Access policies in Microsoft Entra. When it detects drift, such as missing MFA or an inactive contractor keeping privileged rights, it proposes corrections in plain language. Admins approve or modify them, and every recommendation and decision is logged for audits.

**Can security teams build their own Security Copilot agents?**

Yes, the agent builder lets teams describe a security task in plain language, and Copilot turns it into operational logic. Custom agents can call tools, query data and run on events, scans or schedules. Each one runs under an isolated identity with its own permissions and audit log, so it can be restricted or revoked anytime.
