## FAQ

**What is Azure Event Hubs used for?**

Azure Event Hubs ingests high-volume event streams such as IoT telemetry, application logs, clickstreams and financial transactions. It is a fully managed streaming platform, not a queue or database. Multiple consumer groups can read the same stream independently at their own pace, and events stay available for replay during the retention period.

**How do partitions and throughput units work in Event Hubs?**

Partitions are like highway lanes that keep events in order and enable parallel reads; you choose between 2 and 32 when creating the hub and cannot change it later. Throughput units define capacity: one unit gives one megabyte per second in and two megabytes per second out, with auto-inflate for spikes.

**Which Event Hubs tier should I start with?**

Start with the Standard tier and scale up only when needed. Standard offers up to seven days of retention, Event Hubs Capture, Kafka compatibility and up to 20 consumer groups. Basic is cheaper but limited to one day, Premium adds 90-day retention and network isolation, and Dedicated provides a single-tenant cluster.
