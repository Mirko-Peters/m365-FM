## FAQ

**What is the difference between Copilot and a Copilot agent?**

A Copilot agent acts, while plain Copilot mainly answers. The episode describes an agent as Copilot with a job description, connected organizational knowledge and tools it can use. Asked about an expense report, Copilot explains the steps, while an agent can open the form, fill in the receipt numbers and hand it back for approval.

**How do you build a Copilot agent without writing code?**

Start with Agent Builder inside Copilot: describe the agent in plain language, connect a few trusted knowledge sources, test it and share it. When the agent needs to reach other systems, copy it into Copilot Studio, the low-code option. The pro-code path with Azure and Microsoft Foundry is only for jobs a simple agent cannot handle.

**How much do Copilot agents cost to run?**

Agent usage is billed in Copilot Credits, and at the time of recording a simple answer costs about one credit, a generated answer two, an action five and grounding in organizational data ten. Pay as you go runs about a penny per credit, and Microsoft disables custom agents when a tenant exceeds 125 percent of prepaid capacity.
