## FAQ

**What do I need to use @powerpages in GitHub Copilot Chat?**

You need Visual Studio Code with the Power Platform Tools extension, the GitHub Copilot Chat extension, and the Power Platform CLI authenticated against your Dataverse environment. You then download your site content into VS Code. That local copy is what lets Copilot give context-aware answers instead of generic web snippets about your Power Pages site.

**Why are some Copilot features for Power Pages missing in my tenant?**

Some of these features are still in preview, and tenant admins control whether they are turned on. According to the episode, admins toggle them through the Copilot hub in the Power Platform admin center. If a feature shown in a demo is unavailable for you, it is an admin setting, not a bug.

**How can Copilot help debug Liquid template errors in Power Pages?**

Paste the problem code into Copilot Chat with an @powerpages explain prompt to get a plain-language walkthrough of what the tag does and why its placement matters. Then apply a small rewrite, often one Copilot suggests in the same chat, and test again. Always review and test its suggestions before deploying to production.
