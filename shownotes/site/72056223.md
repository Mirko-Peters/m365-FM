## FAQ

**What is Microsoft Foundry in simple terms?**

Microsoft Foundry is a platform for deploying AI models securely, including OpenAI and Anthropic models, hosted in Microsoft data centers with encryption, private subnets and managed identities. On top, it adds observability, content filtering and prompt injection protection, plus services and an SDK to build agents and flows through a web interface or code.

**What architecture works for most enterprise AI apps on Azure?**

Jannik usually builds the app as a container, deploys it through a GitHub pipeline to Azure App Service and connects it over the network to models in Foundry. A SQL database or table storage holds data when needed. For retrieval he adds Azure AI Search, which he calls simple and high quality.

**Why can adding many MCP tools hurt AI agent quality?**

Too many tools flood the model with context. With hundreds of tools you can run out of the context window, and models struggle to find what matters. Jannik prefers orchestration that passes only the context a task needs, often uses CLI commands instead of MCP, and notes that less context also saves tokens and cost.
