## FAQ

**What is latency to value in enterprise integration?**

Latency to value is the time between a business event happening and the organization successfully acting on it. Mirko Peters argues it matters more than uptime or throughput, because every minute an event waits in a queue or polling cycle is lost advantage, for example when a port disruption goes unnoticed for an hour.

**Why does polling-based middleware hurt AI agents?**

AI agents working on batch-ingested data make decisions based on a snapshot of the past, so their output is wrong regardless of model quality. Polling also misses the context of an event: it sees that a record changed but not why or in what sequence, which is exactly the metadata language models need.

**How do you start moving from scheduled syncs to event-driven architecture?**

Start by auditing your polling loops and picking one high-volume batch sync, such as inventory updates or shipping notifications. Replace it with a Dataverse webhook or a Microsoft Graph change notification to prove the push model, then scale through an event catalog and later connect real-time streams to Microsoft Fabric.
