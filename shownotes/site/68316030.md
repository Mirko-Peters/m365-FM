## FAQ

**What are generative pages in Power Apps?**

Generative pages are an AI feature in model-driven Power Apps that builds a page from a plain-language prompt. The agent reads your Dataverse metadata and generates responsive React and TypeScript code that follows Fluent design and respects existing relationships, security roles and field-level security. You can refine the result with follow-up prompts or reference images.

**Can I edit the code that generative pages create?**

Not directly, because the generated React code is read-only. To change something, even a small margin, you reprompt the agent and regenerate the page. That makes precise wording essential, because vague prompts produce inconsistent pages that teams later have to reconcile, which is why prompts should be standardized and versioned.

**Should I use manual canvas design or AI-generated pages?**

Use manual design for unique experiences like prototypes or high-touch executive dashboards, and generative pages for repeatable enterprise apps such as catalogs, inspection portals and inventory apps. For most teams the episode recommends a hybrid: generate the base structure, refine specific interactions by hand, and maintain a library of approved prompt templates.
