## FAQ

**Why do Power Apps built on SharePoint lists get slow or return incomplete data?**

Usually because queries are not delegable or filter on non-indexed columns. The episode recommends indexing the primary filter and lookup columns, keeping one lookup per list view the app relies on, using a safe filtered base view under the 5,000 item threshold, and moving multi-hop relational designs to Dataverse or SQL.

**How should Power Automate flows handle errors and retries?**

Wrap the main logic in a try scope and add a catch scope that runs on failure, timeout or skip. Classify errors: retry 429 and 5xx responses with exponential delay up to three attempts, report 400-level validation failures to the maker, and log unknown errors with a correlation GUID for tracing.

**How do you stop a Copilot Studio agent from answering sensitive questions?**

Give it one bounded purpose and whitelisted SharePoint knowledge sources, with web search turned off and citations required. Instructions make it refuse personal or confidential data and route HR, legal or security requests to a human queue. It runs with the user's identity, respects DLP and logs refusals.
