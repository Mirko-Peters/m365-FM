## FAQ

**Does Microsoft 365 Copilot bypass SharePoint permissions?**

No. Copilot applies permissions at the retrieval step, before the language model writes anything, so it only uses content the asking user can already reach. The catch is that it also honors bad permissions, such as old company-wide links, public groups and broken inheritance, which used to stay hidden because finding those files took effort.

**Do SharePoint hub sites control who can access associated sites?**

No. A hub site connects sites through shared navigation, a wider search scope and common branding, but it grants and removes no permissions. Each associated site keeps its own owners, members and visitors. Hubs still help search and Copilot by clustering related sites, so the episode recommends grouping them by domain rather than by org chart.

**What is the difference between restricted access control and restricted content discovery?**

Restricted access control limits a site to named groups and blocks everyone else, even people with direct permissions or sharing links. Restricted content discovery leaves permissions unchanged but keeps the site's files out of organization-wide search and Copilot answers. The episode treats discovery restriction as a temporary stopgap, because the wide access still exists underneath it.
