## FAQ

**How do Fabric data agents answer questions across CRM and ERP data?**

They translate plain-language questions into the queries your connected systems need. Once Fabric connectors bring CRM, ERP and database sources into one hub, Copilot with Fabric data agents interprets a question such as revenue trends from high-value clients and fetches combined results, so users never write SQL or read API documentation.

**What are Fabric connectors and why do they matter?**

Fabric connectors are pre-built components that already know how to authenticate, map key fields and handle data structures for common systems. The episode names Dynamics 365, SQL, Oracle, SAP and Salesforce among others. Instead of brittle point-to-point integrations, every system lands in Fabric, turning integration into a configuration task rather than custom engineering.

**How do I build a first AI data chatbot with Copilot and Fabric?**

Start by connecting your key data sources in Fabric, then enable Copilot with Fabric data agents on them. Step one is authenticating your ERP, CRM and supporting SQL or file sources through their connectors. Step two is telling the system which data sets feed conversational queries, without custom coding or model training.
