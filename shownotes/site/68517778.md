## FAQ

**Why doesn't my own MCP server show up in Copilot Studio?**

The Model Context Protocol filter in Copilot Studio only lists Microsoft's built-in servers, such as the Dataverse MCP server. An external MCP server needs a custom connector created in Power Apps, imported from the MCP streamable GitHub template, with a correct host, schema and streaming setup before it appears.

**How do I configure the host and base URL in an MCP custom connector?**

Put only the bare domain into the host field, without the https scheme, slashes or the API MCP path. Then remove the API MCP prefix from the base URL, because Copilot Studio already adds it when building paths. Leaving it in creates a doubled path that the server rejects, often showing up as empty responses.

**How can I test whether an MCP connector in Copilot Studio really works?**

Add the connector as a tool and ask a controlled question against the Microsoft Learn MCP server, such as how to set up SharePoint as a knowledge source. A working setup returns text incrementally with citations to Learn. Empty answers, truncated markdown or a generic cannot-help reply point to path, streaming or schema problems.
