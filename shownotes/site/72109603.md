## FAQ

**When should I use Copilot Studio instead of Microsoft Foundry?**

Use Copilot Studio when the solution lives inside one Microsoft 365 tenant and connects enterprise pieces into a workflow. Microsoft Foundry sits in Azure and gives full control, including orchestrating multiple LLMs and MCP servers. Ralph Rivas notes that a Foundry solution can run across multiple tenants and customers, which a Copilot Studio solution cannot.

**What should an organization prepare before enabling Microsoft 365 Copilot?**

Get data, security and governance in order before switching it on. Ralph Rivas says Copilot works at scale and quickly exposes gaps in data hygiene, security and policies. If you skip tools like Microsoft Purview because of cost, you still need something that does what they do, plus data classification and clear data policies.

**What is the difference between a custom copilot and an agent?**

A custom copilot is a broad chat interface tailored to the organization, while an agent is narrowly focused on one job. Ralph Rivas compares the custom copilot to the business as a whole and agents to the people doing specific work, such as handling travel arrangements, and warns against building agents that try to answer everything.
