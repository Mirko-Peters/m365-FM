## FAQ

**How do data access governance reports help prepare SharePoint for Copilot?**

They show admins which sites are potentially overshared, so exposure can be fixed before Copilot surfaces it. Reports cover external sharing, sensitivity-labeled files and broad groups like Everyone except external users. They work at site level, run once a day and can take hours, so treat them as recurring intelligence that still needs action.

**What is the difference between block download and restricted access control in SharePoint?**

Block download lets users view files in the browser but stops downloading, printing and syncing, while restricted access control limits a site to members of a specific Microsoft 365 or Entra security group. Copilot can still surface content protected only by block download, whereas restricted access control keeps both people and Copilot out.

**How much does SharePoint Advanced Management cost and how is SharePoint Premium billed?**

At the time of recording, SharePoint Advanced Management costs three dollars per user per month for the admins and site owners who need it, on top of a qualifying SharePoint or Microsoft 365 license. Content processing such as OCR, eSignature and translation runs pay-as-you-go, so you can start on selected sites and expand where it pays off.
