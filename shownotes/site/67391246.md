## FAQ

**How does Microsoft Fabric track data lineage?**

Fabric captures lineage automatically as a side effect of using the platform. When a Data Factory pipeline runs, it records the source, each transformation step and every downstream table, view or report, even across workspaces, so the lineage view shows everything feeding a dataset back to the ingestion point without manual documentation.

**How do permissions work across a Fabric Lakehouse and Power BI?**

Fabric uses the workspace as the control point, so permissions cascade from Lakehouse tables to the Power BI datasets and reports built on them unless you override them on purpose. A table restricted to finance stays finance-only in Power BI, and removing someone from the workspace removes their access everywhere.

**What does Microsoft Purview add to Fabric governance?**

Purview adds an organization-wide catalog on top of Fabric workspaces. It aggregates lineage, classifications, sensitivity labels and audit data into one searchable layer, so compliance teams can find every place a sensitive field appears, and business glossary terms link definitions like net revenue to the actual data objects.
