## FAQ

**How is Azure similar to a mainframe?**

Azure works like a mainframe scaled to global size: workloads go into a shared pool, the platform decides where they run, and capacity is allocated in real time. Contention, noisy neighbors and throttling still exist in multi-tenant infrastructure, they are just hidden by automation, so designs either work with those trade-offs or against them.

**Why do cloud admins still use the command line instead of the portal?**

Terminals win for precision and repeatability, while graphical interfaces win for discoverability. A script turns repetitive portal clicks into one reliable, shareable file that teammates can rerun to reproduce an issue, and its error logs show exactly what failed. That is why Git, PowerShell and the Azure CLI remain everyday tools.

**What can developers today learn from the Altair 8800?**

The Altair 8800 teaches that constraints create clarity. With only toggle switches and a tiny amount of memory, programmers had to plan structure and outcome before entering a single instruction. The same discipline helps today when sizing cloud resources, choosing efficient connectors, or defining acceptance criteria before building an automation.
