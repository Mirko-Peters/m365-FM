## FAQ

**Can Copilot in Outlook read mailboxes I don't have access to?**

No. Copilot in Outlook works through Microsoft Graph and is bound by the same permissions Outlook enforces, so it cannot open mailboxes you are not delegated to. The real risk is people sharing generated summaries carelessly, which is why sensitivity labels, DLP policies and Purview activity logging should be configured before rollout.

**Do sensitivity labels carry over to Copilot-generated content?**

Yes, when configured. The episode explains that a summary of an email labeled highly confidential inherits that label, and labels on source files carry into generated text unless administrators disable inheritance. Screenshots and copy-paste can still bypass protection, so admins should verify label propagation, enable policy tips and capture Copilot activity in audit logs.

**What should admins set up before rolling out Copilot in Microsoft 365 apps?**

Admins should treat the rollout as a compliance project. Validate SharePoint and drive permissions, confirm sensitivity labels propagate, check DLP triggers and enable Copilot audit logging in Purview. Use the Copilot Control System in the Microsoft 365 admin center to toggle features per app, and assign the AI Administrator role instead of granting global admin rights.
