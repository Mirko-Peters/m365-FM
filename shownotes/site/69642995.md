## FAQ

**What is the Model Context Protocol (MCP) in simple terms?**

MCP is a protocol that defines how an AI host talks to external capability servers, using JSON-RPC 2.0 messages. Servers advertise tools, resources and prompts, and the host decides what the model may request. The episode argues it is a governable integration boundary rather than a plugin system or standardized function calling.

**Should an MCP server use on-behalf-of or managed identity to call Microsoft Graph?**

Use on-behalf-of when the user owns the action and managed identity when the workload does. OBO keeps calls attributable to the user and lets Graph enforce their permissions and Conditional Access. Managed identity suits background work like indexing or nightly reports, but loses user-level accountability, so write tools should stay rare and gated.

**Where should a remote MCP server be hosted in Azure?**

Azure Container Apps is the default the episode recommends for a governable HTTP MCP service. Azure Functions can work for short-lived, stateless read tools, but cold starts can push the agent loop into retries. AKS makes sense only if you already run Kubernetes as a first-class platform and need its controls.
