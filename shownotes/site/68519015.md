## FAQ

**How is the GPT-4o real-time API different from Teams transcription?**

Teams transcription is historical, while the GPT-4o real-time API works during the conversation. It streams audio in and out over a low-latency WebSocket channel, starts forming meaning while you speak and lets you interrupt mid-answer. Earlier voice SDKs queued audio and processed it in batches, which produced late, robotic replies.

**Why put a middle-tier proxy between GPT-4o and Azure AI Search?**

The proxy keeps GPT-4o from ever touching the search index directly. It executes search tool calls on the model's behalf, sanitizes outputs and logs activity for compliance. That one layer adds auditing, throttling, rate limits and policy enforcement, and it lets departments such as HR or finance share one AI core with isolated data scopes.

**Should a voice Copilot run entirely inside Power Platform?**

No, the episode advises keeping heavy processing in Azure. Power Platform enforces API request limits, and a chatty voice assistant would exhaust that quota quickly. Copilot Studio or Power Apps should handle the voice front end and bind to proxy endpoints, while Azure carries retrieval, reasoning and the audio workload, and real-time API tokens stay out of the app.
