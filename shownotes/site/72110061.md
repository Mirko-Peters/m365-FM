## FAQ

**Why does Microsoft 365 Copilot usage drop after the rollout?**

Usage drops because many organizations buy licenses, run a single explanation session and then leave people alone. Evi van der Velden sees adoption reports spike and then fall as users return to old routines. Lasting success comes from building a habit, with repeated guidance and examples tied to real business tasks rather than home use.

**What does it mean that Copilot is a mirror for organizations?**

It means Copilot reveals problems that already existed: wrong permissions, overcrowded storage and missing archival policies. Before, people browsed folders and rarely noticed. Now Copilot pulls a ten-year-old document into its answers, so organizations must decide which data is still valuable, which should be deleted and which belongs in cold storage.

**What is the difference between technical and functional governance in Microsoft 365?**

Technical governance controls how people access the environment, for example devices and Conditional Access. Functional governance covers how SharePoint sites and teams are created, which templates are used and how the data life cycle, archiving or deletion is handled. Evi argues the focus is shifting to functional governance, which is key to being ready for Copilot.
