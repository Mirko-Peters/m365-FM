## FAQ

**Should you pause a Microsoft 365 Copilot rollout until governance is fixed?**

No, the episode argues that pausing defers productivity value while governance debt keeps growing, because new orphaned sites, unclassified data and permission drift accumulate during the wait. Instead, run remediation and a scoped Copilot deployment in parallel, so deployment pressure gives governance work a real deadline, executive attention and the resources it previously lacked.

**Does Microsoft 365 Copilot bypass SharePoint permissions?**

No. Copilot respects the same Microsoft Graph permission model as every other Microsoft 365 app, so if a user cannot access a document today, Copilot cannot retrieve it. What changes is the speed of finding and synthesizing information across sources. Copilot does not create new risk; it reveals oversharing and permission drift that already exist.

**How does SharePoint Advanced Management help with orphaned sites?**

SharePoint Advanced Management policies automatically detect sites without the required minimum number of owners, with two recommended for redundancy, and notify site members. They can assign temporary administrators from a designated pool whose job is to find the real owner. Site lifecycle policies also flag inactive sites and can set them read-only or archive them.
