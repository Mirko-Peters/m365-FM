## FAQ

**Does Microsoft 365 Copilot bypass user permissions?**

No, Copilot works within the permissions a user already has, but it changes how information is consumed. It can blend content from SharePoint, OneDrive, emails and meeting notes into one answer, so a user may receive sensitive details from files they never opened or knew existed, which traditional file-level audit trails do not describe.

**Why are permissions and DLP not enough for Copilot?**

Permissions and DLP were designed around explicit file access and data leaving the organization, not AI synthesis. DLP stops content in emails or uploads, while Copilot pulls context from files a person can already reach. Sensitivity labels in Microsoft Purview add content-level rules that travel with the data, including into AI-generated content.

**In what order should you roll out Purview controls for Copilot?**

Start with sensitivity labels, then enable auditing with sufficient retention, and add insider risk management last. Labels define which data needs guardrails, auditing proves how content is used, and insider risk rules need that classification and logging to give signals context. Skipping the order leads to reclassification and rework after adoption has scaled.
