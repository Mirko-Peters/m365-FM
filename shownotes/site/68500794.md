## FAQ

**Why does Microsoft 365 Copilot alone not deliver measurable ROI?**

Copilot on its own saves moments, not money, because summaries, drafted replies and suggestions stay isolated. The episode argues ROI appears only when those suggestions trigger Power Automate workflows that execute actions, stay within governance rules and log results, so time savings can be documented and repeated at scale rather than remaining one-off conveniences.

**How do you build a custom connector for Copilot in Power Automate?**

In Power Automate, go to custom connectors and create one from an OpenAPI file, then set authentication to Microsoft Entra ID (formerly Azure AD) and define resource URLs. Run the test operation, save and publish. Register it at environment or solution level, not per user, and avoid hard-coded personal credentials that later break production flows.

**How does concurrency control speed up Power Automate flows?**

Concurrency control lets triggers and Apply to each loops run up to 50 iterations in parallel instead of sequentially. Batch large inputs, cap parallelism to respect connector API limits, and add retry policies. Only parallelize independent data, because branches touching the same record create race conditions, and configure run-after settings to handle failed branches.
