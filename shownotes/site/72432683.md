## FAQ

**What should an organization set up in Microsoft Purview before rolling out Copilot?**

Start with sensitivity labels, data loss prevention and data lifecycle management, the three core Purview features Peter Rising recommends. Labels classify and protect documents so Copilot respects them, DLP stops sensitive data such as credit card numbers from leaking, and retention policies keep data only as long as regulations require.

**Is Copilot oversharing a Copilot problem or a data governance problem?**

Peter Rising treats it as a data governance issue, or rather a data opportunity. Copilot can only work with what permissions let it access, so controlling, labeling and permissioning the data is where protection starts. He suggests SharePoint Advanced Management, knowing where data lives and Defender for Cloud Apps to control which apps reach it.

**Do AI agents in Agent 365 need new security tools?**

No, according to Peter Rising there are no special new security tools for agents in Agent 365. Agents can have their own identities, and they are protected and governed with the same Entra and Purview controls used for human identities. The agent registry adds controls over who can install, see and work with agents.
