## FAQ

**Can Microsoft 365 Copilot show users data they should not have access to?**

Yes, if Copilot runs with application permissions in Microsoft Graph that are broader than the signed-in user's rights. Application permissions ignore individual user restrictions unless deliberately scoped, so a user can receive content from sites they never had direct access to. Admins should map each Copilot scenario to the minimum permissions it needs.

**How do I see what data Copilot has accessed in my tenant?**

Use the audit log search in Microsoft Purview and filter for the operations Copilot performs, narrowed by the application ID of your Copilot deployment in Entra ID. Then look for patterns such as unusual query volumes from low-need accounts or confidential labeled content appearing in departments that normally never touch it.

**How do I configure a DLP policy that covers Copilot output?**

Create a new data loss prevention policy in the Microsoft Purview compliance portal and include Exchange, SharePoint, OneDrive and Teams as locations. Define conditions using sensitive information types or sensitivity labels, then set actions such as blocking sharing, showing a policy tip or requiring justification, so AI-generated content is treated as its own channel.
