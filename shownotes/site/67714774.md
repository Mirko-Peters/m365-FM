## FAQ

**Does a Microsoft 365 SLA compensate for lost productivity during an outage?**

No. According to the episode, cloud contracts typically limit the provider's liability, so lost time, productivity and revenue remain your problem. The provider works to restore service, but recovery is best effort. Mirko recommends reading your own tenant agreement and SLA to see how compensation and liability are actually described.

**Why do several Microsoft 365 apps fail at the same time?**

Because they share underlying dependencies such as identity, storage, DNS and network routing. If sign-in through Microsoft Entra ID fails, users can lose Teams, Outlook and nearly every connected workload. Local causes like internal DNS failures, overloaded firewall appliances or recent device policy changes can also look like a global outage.

**How can I prepare my organization for a Microsoft 365 outage?**

Audit your critical dependencies, document fallback procedures and run recovery drills. Add redundancy for mission-critical processes, such as a documented manual workflow that bypasses automation, and set up monitoring that flags slowdowns early. Fallbacks only count once tested, so practice them before a real outage instead of leaving the plan on a shelf.
