## FAQ

**When should I use Copilot Studio instead of Azure AI Foundry?**

Use Copilot Studio for fast, low-code prototypes and lightweight bots such as HR or IT FAQs inside Microsoft 365. The episode describes teams launching help desk bots in under two weeks using connectors and existing SharePoint content. It hides model controls, so it is best for proving value before compliance or complex integration requirements appear.

**What are the signs that a Copilot Studio bot should move to Azure AI Foundry?**

Move when the bot needs data outside Microsoft 365, when hallucinations become a real risk, or when audits and compliance enter the picture. The episode calls these the three migration triggers. Foundry then adds creativity controls, evaluation gates, data lake connectors, telemetry and audit logs that tie each query to user identity.

**How does RAG stop an enterprise chatbot from hallucinating?**

RAG makes the model search indexed company content before it writes an answer, so responses come from sources that actually exist. Combined with identity-aware access control, users only see content they have rights to, like a bouncer checking IDs. This works only if permissions and indexing are set up correctly; otherwise wrong answers return.
