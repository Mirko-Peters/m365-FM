## FAQ

**What permissions does a Power Automate flow need to read Purview audit logs?**

The flow's service account needs the audit log reader role in Purview and must authenticate without MFA prompts, since automation cannot respond to an authenticator. Store credentials in Azure Key Vault or connection references. Without the role, the agent sees nothing and reports no issues found, which the episode calls blindness disguised as success.

**How does the GRC agent decide which activity is high risk?**

It applies numeric thresholds you define in Power Automate conditions. After filtering out noise and duplicates, the flow groups events by user and operation, counts them, and assigns high, medium or normal risk when counts cross set limits, for example on privileged escalations or external shares. Quiet days produce an explicit no-findings message, not silence.

**How do you keep Copilot Studio compliance reports consistent?**

Give Copilot Studio tight prompt instructions: exact headings such as overview, key findings and recommendations, a professional neutral tone, no speculative language and quantifiable metrics. Use context variables for values like report date and record count, check in Power Automate that the response is not empty, and version the system prompt so auditors know which instructions produced each report.
