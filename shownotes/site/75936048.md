Many people assume a firewall is a firewall, but a web application firewall reads what traffic says rather than where it goes. This Simply Explained episode is for beginners and Azure admins who want to know what Azure Web Application Firewall catches, where it lives, how its scoring and modes work, what it costs and what it cannot protect.

## Key takeaways

- Azure Web Application Firewall reads what web requests say and blocks known attack patterns such as SQL injection and cross-site scripting, based on OWASP-derived managed rule sets.
- It runs as a policy on Application Gateway for regional apps or Front Door for global apps, and should be tuned in detection mode before switching production to prevention mode.
- It is not DDoS protection, cannot fix broken access control, needs a locked-down origin, and does not protect your Microsoft 365 tenant, only the apps you host yourself.

## FAQ

**Does Azure Web Application Firewall protect my Microsoft 365 tenant?**

No, Azure Web Application Firewall does not protect a Microsoft 365 tenant. SharePoint Online, Teams and Exchange Online are services Microsoft runs and secures, and Microsoft 365 is not on the list of services Azure WAF works with. It protects only the web apps you host and expose yourself, such as a public form or internal tool in Azure.

**What is the difference between detection mode and prevention mode in Azure WAF?**

Detection mode only logs what it would have blocked, while prevention mode actually blocks matching requests with a 403 page. Microsoft says production workloads should run in prevention mode, but the recommended path is to start in detection, read the logs, add exclusions for false positives and switch after roughly one to two weeks of clean logs.

**Should I use Azure Application Gateway or Azure Front Door for WAF?**

Use Application Gateway for an app that lives in one region and Front Door for an app that serves users worldwide. Application Gateway inspects traffic inside the Azure region, while Front Door stops bad requests at Microsoft's network edge. Note that managed rule sets and bot protection on Front Door require the premium tier, not standard.
