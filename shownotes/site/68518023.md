## FAQ

**How do you automate Excel RFI answers with Copilot Studio?**

Combine a Power Automate flow with an autonomous Copilot Studio agent. The flow catches the email in a shared mailbox, keeps only xlsx attachments, copies the file to SharePoint and prompts the agent with file and message IDs. The agent answers each row with generative AI, writes answers back, and Power Automate replies with the completed file.

**Why should a Copilot Studio agent answer one Excel question at a time?**

Answering one question per loop iteration prevents context bleed between questions. The agent reads the named table into a variable, loops through the rows with a for each loop and sends each question to the Create Generative Answers node. One large prompt with every question tends to produce inconsistent formatting and answers that mix context.

**Why does the reply flow wait before sending the completed Excel file?**

Excel cloud files can take a moment to register updates, so builders add a delay of around two minutes before retrieving the file. The episode notes Copilot Studio expects a called flow to respond within roughly 100 seconds, so the reply flow must stay lean, then get the file content from SharePoint and reply in the original email thread.
