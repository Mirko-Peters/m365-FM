## FAQ

**What is Azure Container Storage v2?**

Azure Container Storage v2 is a rewritten version of the AKS storage service that focuses only on local NVMe disks. It drops the LVM and etcd components of version one, removes managed disk support, works through the standard CSI interface with an open-sourced driver, and automatically stripes all local NVMe disks of a node.

**Which Azure VMs can use local NVMe with Azure Container Storage v2?**

Mainly the storage-optimized L series, such as Lsv3 and newer, plus GPU-based NC series machines, and some Dv6 and E class VMs with local NVMe temporary disks. The episode notes that using this NVMe adds no extra cost because it is already included in the VM price.

**Is it safe to store data on ephemeral NVMe volumes in AKS?**

Only for data you can regenerate, because the volume disappears when the node deallocates or fails. Use it for caches, Spark shuffles, staging and model weights, and keep durability in higher layers through database replication, availability zones, scheduled exports and backups to Azure Blob Storage.
