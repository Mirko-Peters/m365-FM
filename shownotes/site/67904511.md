## FAQ

**Why do Power BI alerts require a dashboard?**

Classic Power BI alerts only trigger on card-type visuals pinned to dashboards, so you cannot set a threshold directly in a report. Each alert therefore means another pinned card and dashboard object, which adds permissions, naming and lifecycle overhead and leaves workspaces full of dashboards that exist only to hold one alert.

**What is the difference between Power BI alerts and Fabric Data Activator?**

Power BI alerts only send a notification when a single card value crosses a threshold, while Data Activator watches the data itself and can trigger workflows. When a rule fires, it can start a Power Automate flow that posts in Teams, creates a ticket or emails leadership, without fake card visuals or extra dashboards.

**Should I replace Power BI alert scripts written in PowerShell?**

Yes, for enterprise monitoring the episode argues PowerShell scripts are a poor foundation because they break on schema changes and depend on one maintainer. If you must keep them, treat them as production code: write a runbook, move credentials to a managed service account and schedule a quarterly dry run to confirm they still work.
