## FAQ

**What do I need to set up computer use in Copilot Studio?**

You need a Windows 10 or 11 Pro machine or better with the Power Automate Desktop machine runtime, version 2.59 or newer. Sign in with your work account, register the machine to an environment, confirm it appears under Monitor, Machines in the Power Automate portal, and turn on the enable for computer use toggle.

**How is computer use different from a Power Automate flow or an API call?**

Computer use operates the user interface itself instead of going through defined connectors. The agent interprets screenshots, decides its next move by reasoning rather than a script, and can misclick, pause and recover. Because it reads the screen fresh each time, every run differs, but it can reach legacy desktop apps that have no API.

**What are the security risks of letting a Copilot Studio agent use a computer?**

The agent borrows your authority: every click uses your credentials, license and network access, so it can open whatever you can. Reduce the risk with a dedicated least-privilege Entra agent identity, sandbox testing, human-in-the-loop approvals in Power Automate, Purview labels and DLP, Defender monitoring, and deactivating agent credentials when they are no longer needed.
