## FAQ

**Does the on-premises data gateway copy my SQL Server database to the cloud?**

No, the gateway does not upload, clone or replicate your database. It executes queries on your behalf and returns only the results over encrypted TLS connections. It initiates every connection outbound, so no inbound firewall port needs to be opened, and calls can be tracked through Power Platform monitoring tools.

**How do I add on-prem SQL Server as a knowledge source in Copilot Studio?**

Install and register the on-premises data gateway, then add knowledge in Copilot Studio, choose the SQL source and select your gateway connection. Authenticate and pick the tables or views the agent may use. Well-named, read-optimized views work best, because the agent infers relationships from the schema you expose.

**Can a Copilot Studio agent write data back to on-prem SQL Server?**

Yes, through SQL actions such as insert row, update or execute stored procedure, which run over the same gateway connection. Copilot Studio turns table columns into input parameters, and clear labels help the agent ask for missing values. Many organizations use separate read and write credentials and add confirmation steps before committing.
