## FAQ

**Can Microsoft 365 Copilot show users files they are not allowed to access?**

No. Copilot is grounded through Microsoft Graph and security trimmed at query time, so it only returns content the user's existing permissions already allow. What surprises people is oversharing they created themselves, such as Everyone except external users grants or broken inheritance left behind after a migration, which Copilot merely makes visible.

**What is the difference between Restricted SharePoint Search and Restricted Content Discovery?**

Restricted SharePoint Search limits tenant-wide discovery to an allow list of 100 sites, a broad brace for when the map is untrusted. Restricted Content Discovery is a site-level flag that hides sensitive hubs such as HR, legal or finance from tenant-wide surfacing. Neither changes permissions or fixes oversharing.

**How do you stop employees pasting Copilot answers into external AI tools?**

Layer controls where the behavior happens. Browser DLP in managed Edge profiles blocks pasting sensitive content into unmanaged AI sites, network DLP refuses uploads to known AI endpoints, and prompt DLP declines risky requests. Adaptive protection narrows sessions for high-risk users, while DSPM for AI shows which AI sites and departments create risk.
