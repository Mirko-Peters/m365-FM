## FAQ

**Why don't sensitivity labels stop oversharing in SharePoint?**

Labels classify content and can add protection, but they do not decide who can reach a file today. They don't repair broken inheritance, recall old links or remove stale users. That is why label coverage can rise while risk rises: metadata improves while access boundaries stay porous through links and ad hoc grants.

**Does Microsoft 365 Copilot create new security risks in a tenant?**

Mostly no: Copilot reveals existing risk rather than creating it. It can summarize anything a user can already reach, so forgotten sites, broad links and stale guests become one prompt away. The episode recommends baselining overshared, ownerless and stale content before a broad rollout, instead of cleaning up afterwards.

**What should happen when a Team or SharePoint site loses its owner?**

It should trigger an automatic remediation loop rather than a cleanup project. With two owners as the baseline, a resource that drops below minimum owners gets a time-bound grace period, then escalation from owners to manager to governance team. If accountability can't be restored, access degrades: no new guests, links disabled, read-only, or deletion.
