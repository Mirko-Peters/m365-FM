## FAQ

**How many sensitivity labels should an organization start with?**

Four, with five as the absolute ceiling. The suggested starter set is Public, General, Confidential and Highly Confidential, each describing a handling rule rather than a department. Sublabels only earn a place when enforcement truly differs, such as restricting board papers to named recipients, and the taxonomy should be tested against a few hundred real documents first.

**Should every sensitivity label apply encryption?**

No. The episode recommends encrypting only the top tier and using visible markings without encryption for middle tiers like Confidential. Encrypting everything above Public tends to break older Office clients, third-party scanners, backups and partner access, and such programs often get rolled back within a quarter. Build a client compatibility matrix before encrypting anything.

**Do container labels on Teams and SharePoint sites label the files inside?**

No. A container label sets the rules of the workspace, such as privacy, guest access, external sharing and access from unmanaged devices, but the files inside do not inherit it. To cover content as well, pair the site label with a default label on the library, after enabling labels for Microsoft 365 groups and sites.
