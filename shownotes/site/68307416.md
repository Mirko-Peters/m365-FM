## FAQ

**What are Power Apps code apps?**

Power Apps code apps are full React web applications that run inside Power Platform. Developers write them in Visual Studio Code with Node.js, TypeScript and Git, initialize and push them with the Power Platform CLI, and still inherit environment governance policies, connectors and automatic Microsoft Entra authentication alongside regular canvas apps.

**When should I use a canvas app instead of a code app?**

Use a canvas app for fast, self-contained, low-risk tools built by business analysts, such as an HR onboarding app driven by a SharePoint list. Choose code apps when a system needs SQL and API integrations, custom dashboards, source control, automated pipelines and long-term maintenance by professional developers.

**Can GitHub Copilot write Power Apps code apps for me?**

GitHub Copilot can generate much of the code, including React components, JSX, Dataverse service interfaces and fixes for build errors. It speeds up syntax but not design decisions, so it can produce error-free code that is conceptually wrong. Developers still need to define the architecture and rely on reviews, testing and source control.
