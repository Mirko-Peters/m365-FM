## FAQ

**What is the difference between syncing a SharePoint library and adding a OneDrive shortcut?**

Syncing pulls an entire SharePoint library into File Explorer, so your device tracks every item, while a shortcut is a lightweight pointer to only the folders you choose. Shortcuts appear in File Explorer, Finder and OneDrive on the web, roam across your devices, and keep the sync client focused on a much smaller set of items.

**How do I add a SharePoint folder as a shortcut in OneDrive?**

Open the SharePoint document library, navigate to the specific folder you work in and click Add shortcut to OneDrive in the command bar. The shortcut then appears under My files with a chain link icon. If the button is missing, drill into a subfolder or check that you have permission to that path.

**Do OneDrive shortcuts keep sensitivity labels and retention policies?**

Yes. Shortcuts point to the single governed source instead of copying files, so sensitivity labels, retention policies, permissions and version history all stay intact. Removing a shortcut deletes only the doorway, not the content. Governance problems start when users drag files out of synced folders to the desktop or email copies around.
