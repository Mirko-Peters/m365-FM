## FAQ

**What is the difference between cloud flows and agent flows in Power Automate and Copilot Studio?**

Cloud flows are licensed per user or per flow in Power Automate, while agent flows run inside Copilot Studio and are billed by message consumption. Mirko describes cloud flows as automating labor and agent flows as automating decisions, triggered by conversations, AI events or service signals rather than schedules and shared human triggers.

**How much does an agent flow cost to run?**

At the time of recording, the episode cites roughly 13 cents per 100 actions or API calls. A run that loops through 100 records with three actions each makes 300 calls, about 39 cents per execution, or around 12 dollars if run daily for a month. Cost scales linearly, with premium connectors and AI Builder included.

**Can I convert an existing cloud flow into an agent flow and switch it back later?**

You can convert it, but the change is irreversible. First make the flow solution-aware by moving it into a managed solution in Dataverse, then change its plan from Power Automate to Copilot Studio. Licensing switches to consumption immediately, and returning to a cloud flow means rebuilding it from scratch.
