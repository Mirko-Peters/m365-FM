## FAQ

**Why shouldn't Copilot output be treated as an answer?**

Because Copilot is a probabilistic synthesis engine, not a truth engine, so its output is a hypothesis that a human must accept or reject. It can be wrong without hallucinating, simply through missing context. If an output can move money, change access, set policy or become a record, someone must explicitly say they accept it.

**Do prompt libraries count as AI governance?**

No, a prompt library is not a control plane because it enforces nothing. The episode argues that prompt volume usually signals unclear intent or missing authority. Prompting cannot replace explicit constraints, decision ownership and enforced convergence, meaning a workflow point where a human must stop generating options and choose one.

**What should a decision log for AI-influenced decisions contain?**

A one-page decision log owned by a named human should answer five questions: what the decision is, who owns it, which options were considered, which trade-off was chosen and what would cause a reversal. It also states whether AI was used for summarization, drafting or option generation, so the reasoning can be reconstructed later.
