## FAQ

**What does the SharePoint Knowledge Agent actually do?**

It suggests metadata columns, creates simple automated rules, builds filtered views and answers questions across sites. The agent lives inside SharePoint Premium, is powered by Copilot and needs a paid Microsoft 365 Copilot license plus an admin opt-in. Every suggested change still has to be reviewed and approved by a human before it is applied.

**Why do Knowledge Agent metadata suggestions look random at first?**

The agent first needs background indexing and content analysis, which can take hours, so early suggestions are mostly guesses. Waiting before creating columns gives far better results. Filling metadata also runs asynchronously, so columns can stay blank for a while, and users who rerun the task in the meantime cause colliding, partially overwritten updates.

**How can admins stop the SharePoint Knowledge Agent from causing metadata drift?**

Contain it. Keep the agent in pilot libraries, watch column and rule creation through the SharePoint admin portal or API, record which library created each field, and prefix AI-generated columns so their origin is clear. Users should learn that saving a change is a schema decision, because unreviewed columns spread and confuse Copilot answers.
