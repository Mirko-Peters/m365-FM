## FAQ

**Why do Microsoft 365 Copilot rollouts fail?**

Most Copilot rollouts fail because teams treat them as a technical deployment instead of a behaviour change project. Licenses get switched on with a memo and generic training, but nobody gets role-specific tasks, visible leadership examples or a steady comms cadence, so people try a vague prompt once and quietly return to old habits.

**Does Microsoft 365 Copilot train on my company data?**

No, the episode stresses that retrieval is not training. Copilot retrieves content the user already has permission to see and uses it as context for an answer. If someone cannot open a file in SharePoint, Copilot will not use it for them, which is why fixing permissions, sensitivity labels and stale sharing links matters.

**How do you measure Copilot adoption?**

Track monthly active users, time to draft and ticket volume trends, plus artifact submissions to a shared prompt library. Flat MAU points to vague use cases or hidden leaders, unchanged time to draft points to weak templates, and ticket spikes deserve pattern analysis. Registrations for webinars are vanity metrics, not evidence of behaviour change.
