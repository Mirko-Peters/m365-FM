## FAQ

**What is the difference between Azure Logic Apps and Power Automate?**

Power Automate is built for business user convenience, such as approvals, notifications and light data work in Microsoft 365. Azure Logic Apps targets IT-managed integration with network boundaries and SLAs. Both share connectors, but Logic Apps adds stateful and stateless workflows, Consumption and Standard hosting, VNet integration, managed identities and Azure Policy governance.

**Why does Power Automate throttle high-volume workflows?**

Power Automate enforces aggregate action limits across a tenant window, so heavy workloads hit a ceiling you cannot tune. Runs then back off, retry and slow down, pushing P95 and P99 latency past SLAs. Logic Apps Standard runs on dedicated compute with per-action concurrency, while Consumption offers a high-throughput mode for bursts.

**How should AI agents use Azure Functions with Logic Apps?**

Keep orchestration declarative in Logic Apps and move complex code into Azure Functions. Functions handle intent classification, deduplication, custom transforms or model calls and return typed results the workflow branches on. Managed identities, private endpoints and a correlation ID traced in Application Insights keep every hop secure and auditable, and functions can be versioned and rolled back.
