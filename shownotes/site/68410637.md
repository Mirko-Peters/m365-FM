## FAQ

**What is hub-and-spoke architecture in Power BI?**

It is a model where a central hub holds certified semantic models, shared datasets and standardized measures, while departmental spoke workspaces build reports on top of them. Spokes consume the hub's data but never redefine it, so finance and sales can work quickly while still using the same revenue definition and avoiding duplicate models.

**Who should own a shared Power BI dataset?**

Every shared dataset should have both a business owner and a technical owner. The business owner decides what a measure means, such as what counts as an active customer. The technical owner handles refresh schedules, DAX performance and gateway reliability. Both names belong in the dataset description so nobody has to search for who is responsible.

**How should Power BI workspace permissions be assigned?**

Assign workspace roles through security groups in Microsoft Entra ID, never to individual users. Create groups that match the Viewer, Contributor, Member and Admin roles, keep admins to a handful per workspace, and avoid giving everyone Member or Admin access. When an employee leaves, removing them from Entra ID strips their Power BI permissions automatically.
