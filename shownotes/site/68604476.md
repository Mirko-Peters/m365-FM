## FAQ

**How do you build a Copilot learning center in SharePoint?**

Build it as a SharePoint hub site with three areas: learn, do and govern. SPFx web parts power agent directory cards, role-based prompt galleries and context panels, PnP Modern Search handles findability through taxonomy and scopes, and Viva Connections pins the hub into Teams so guidance sits one click away from where people work.

**Why does traditional Copilot training not reduce help desk tickets?**

Static decks and webinars cannot keep up with a product that changes weekly and is not learned along a linear skill path. Users forget, unofficial guides multiply and search returns contradictions. Tickets then cluster around four questions: where to start, which Copilot to use, whether it is safe and why it answered that way.

**Which KPIs show that a Copilot learning center is working?**

Track ticket deflection rate, unique hub visitors, prompt library reuse and rogue-doc decay as north-star metrics. Leading indicators include search success rate and whether users resolve 70 percent of Copilot questions in three clicks or fewer. SharePoint usage analytics, search logs and a Power BI dashboard supply the data, alongside a falling stale content rate.
