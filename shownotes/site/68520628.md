## FAQ

**Why does exporting a Power BI dashboard to PDF look broken?**

Because Power BI dashboards are designed for screens, not paper, and exporting to PDF is not true pagination. You lose repeating headers, reliable page numbers and clean grouped totals. Paginated reports based on RDL define paper size, margins, headers, footers and page breaks, so the output stays the same every time.

**When should I use Power BI Report Builder instead of the web paginated builder?**

Switch to Power BI Report Builder when you need real page control, charts, parameters or advanced expressions. The web builder in the Power BI service is fine for simple tables, matrices and quick prototypes, but it has sparse charts, no maps, shallow expressions and minimal layout control over page breaks.

**Why do paginated reports produce extra blank pages?**

Usually the report body is wider than the printable width, which is the page width minus the margins. Exceeding it, even slightly, creates phantom blank pages. Set paper size, margins and orientation before designing, keep columns within that width and test pagination early with realistic parameters and exports to PDF and Word.
