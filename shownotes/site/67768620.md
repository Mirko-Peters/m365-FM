## FAQ

**What do I need to install to start writing Q# code?**

You need a current .NET SDK, the Quantum Development Kit and the Q# extension in Visual Studio Code. To run jobs on real hardware, add an Azure subscription with a Quantum workspace, authenticate with the Azure CLI, set your subscription and point the project at that workspace.

**How do you debug a Q# program if you cannot inspect qubits?**

You debug statistically on the simulator instead of inspecting state. Run the program hundreds or thousands of times, check whether the distribution matches theory, and add assertions or diagnostics to confirm qubits are prepared as intended. Measuring a qubit mid-execution collapses it, so print-style debugging does not work.

**Why do Azure Quantum hardware results differ from the simulator?**

Real quantum devices add physical noise that the simulator does not have. A balanced Hadamard test may lean slightly toward zero or one on hardware. Mirko recommends confirming correctness on the simulator first, then reading hardware deviations as measured physical data rather than chasing them as logic bugs.
