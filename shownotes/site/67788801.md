## FAQ

**Does .NET 10 add AI to ASP.NET Core apps automatically?**

No, AI in .NET 10 is opt-in. The framework provides hooks that let you connect services, models or APIs using the same middleware and dependency registration patterns you already know. Nothing ships with intelligence by default, but once you configure models or telemetry, the framework handles the connection points that previously required hand-built pipelines and glue code.

**How can passkey and WebAuthn events improve security monitoring in .NET 10?**

They become security signals when you route them into the same telemetry pipeline as performance data. A valid passkey login from an unfamiliar device or at an unusual time may not mean trouble alone, but correlated with other telemetry it can reveal a pattern. AI analysis then surfaces suspicious combinations earlier than manual log reviews would.

**How do minimal API validation and OpenAPI work together with Blazor?**

Together they turn your API into a contract that stays in sync with your code. Minimal API validation checks inputs before they reach business logic, OpenAPI generation produces a live specification of endpoints, and Blazor's strongly typed components consume those shared definitions. Both features must be enabled and configured in your project to work.
