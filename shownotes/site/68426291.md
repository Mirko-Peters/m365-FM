## FAQ

**Why does Copilot in Microsoft Fabric give wrong answers?**

Copilot gives wrong answers because it reflects your data model rather than validating facts. Wrong join keys, inconsistent measures, missing descriptions and messy medallion layers become its context, so it pattern-matches similar column names and fills gaps with plausible guesses. The result sounds confident and looks professional, but the underlying numbers can be fiction.

**What is the difference between data source instructions and agent instructions in Fabric?**

Data source instructions define the facts, while agent instructions define the voice. Data source instructions specify joins, measure references, synonyms and bucketing logic for the schema. Agent instructions control presentation and scope, for example returning only the top five rows or adding a summary first. The data agent combines both into one prompt for each answer.

**How do you keep Copilot accurate in Fabric over time?**

Keep it accurate by treating the data model like software and auditing it regularly. Enforce schema contracts, version semantic changes, certify datasets in Microsoft Purview, and keep one central semantic model instead of shadow copies. Run periodic truth audits that rerun representative queries against a source of truth, and recalibrate instructions when results diverge.
