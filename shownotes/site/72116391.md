## FAQ

**Why does prompt injection work against AI applications?**

Prompt injection works because a language model cannot tell developer instructions apart from user input, since both arrive as typed text. Martin Dimovski compares it to a waiter who follows a customer's note instead of the chef. The model treats every piece of text as a potential authority, so whoever writes the most convincing instructions wins.

**How can teams keep security from becoming a bottleneck for AI innovation?**

Teams avoid the bottleneck by involving security early and working together continuously. Martin suggests a short 15-minute check-in whenever a new application starts, a threat model on the design pattern, the four-eyes principle and senior approval before production. Starting early is a shift left: skipping it means paying double later in the project.

**How does GitHub Advanced Security help protect AI pipelines?**

GitHub Advanced Security catches mistakes developers make under time pressure, such as secrets left in code that would otherwise be cloned into production. According to Martin, it warns the developer directly and continuously scans packages for compromise. That matters because forgotten credentials in pipelines and logs are one of the most common causes of data leaks.
