## FAQ

**Why does Microsoft 365 Copilot give confident but wrong answers?**

Because it can only reason over what is indexed and permissioned in Microsoft Graph. When approvals, support tickets or exceptions live in external procurement, ticketing or compliance systems, Copilot never sees them. It then answers from documents such as an outdated PowerPoint deck, producing professional-sounding recommendations that miss the current state of the business.

**What is the difference between an integrated and an indexed system for Copilot?**

An integration displays data inside a Microsoft 365 app; indexing lets the AI reason across it. Seeing a CRM record in Outlook does not put it in the semantic index. Only when ticketing, CRM and delivery data are indexed through connectors can Copilot notice an open critical ticket before drafting a sales follow-up.

**What does a custom Copilot connector need to be secure and useful?**

It needs mapped identities, a rich schema, faithful access control lists and defined latency targets. External user IDs must be normalized to Microsoft Entra ID, the schema tells the index which fields matter, ACLs replicate source permissions, and critical status changes such as pending approvals are streamed rather than batch-synced overnight.
