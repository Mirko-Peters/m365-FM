## FAQ

**What is the difference between assistive and agentic Copilot?**

Assistive Copilot drafts, summarizes and proposes text, while agentic Copilot calls tools and changes state in systems. The episode explains that wrong text is usually reversible, but an agent action is either authorized or unauthorized, so governance must shift from checking answers to controlling identity, tool paths, data boundaries and containment.

**Why are Teams approvals for agent actions often governance theatre?**

They are theatre when the approval is bound to a conversation instead of an identity and tool contract. In the episode's pattern case, an approved access request ran through a different tool path under a shared service account, so nobody could prove which approval authorized which action. Tools should refuse to act without a matching approval token.

**What is a minimal viable agent control plane?**

It is the smallest set of enforced constraints that makes an agent safe to scale: one identity, one curated toolpath, one bounded data domain and one containment playbook per agent. The episode adds a provenance standard and an intake gate, and says a fleet should only grow once one agent can be disabled without collateral damage.
