## FAQ

**What is the difference between search, action and link unfurling message extensions in Teams?**

Search extensions find a record and share it to chat, action extensions open a form that collects input and triggers a back-end process, and link unfurling turns a pasted URL into a rich preview. Use search for fast lookups, action for workflows and updates, and link unfurling when context matters more than workflow.

**How do you build an action-based message extension for Microsoft Teams?**

You register a Teams app, write a manifest and define action handlers, then run a web service on the Bot Framework. When a user triggers the action, Teams sends the input to your bot, which queries the back-end system and returns an Adaptive Card that Teams inserts into the conversation, ready for further interaction.

**What should you check before rolling out a Teams message extension across the organization?**

Check that the manifest is precise and request only the permissions you actually need. Keep the manifest under source control, document every change, test updates with a small pilot group first, and monitor usage and errors. Also review authentication and data residency rules such as GDPR, because security reviews can stall an imprecise app.
