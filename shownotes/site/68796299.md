## FAQ

**What is the difference between MCP and Semantic Kernel when building AI agents?**

MCP is the wiring and Semantic Kernel is the control panel. MCP advertises tools such as Microsoft Graph endpoints in a standard shape the model can discover dynamically. Semantic Kernel turns those tools into kernel functions, plans multi-step work and builds the JSON schemas the model needs for function calling.

**How do you stop an AI agent from taking dangerous actions in production?**

Enforce safety at the tool boundary, not in the prompt. Tool schemas carry required parameters, range clamps and preconditions, and high-risk tools need a signed, time-bound approval token. Split managed identities by read, write and high-risk actions so a tool without permission fails closed, and log every call in an immutable audit envelope.

**Why should Azure OpenAI tool calls run under a managed identity?**

Managed identity lets the model choose tools while identity decides what is allowed. The executor obtains a token for each call based on the identity's assigned roles, so no secrets are stored and unpermitted tools fail closed. Because these scopes are independent of the model, you can swap model versions without changing your security posture.
