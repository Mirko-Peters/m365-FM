## FAQ

**Why does Microsoft 365 BizChat give vague answers about CRM or ERP data?**

BizChat gives vague answers because, out of the box, it only sees content Microsoft 365 already holds, such as Outlook messages, Teams chats, OneDrive files and SharePoint libraries. Without access to the CRM, ERP or project tool, it pieces together mentions from emails and documents, so pipeline forecasts and invoice totals come back incomplete.

**What is a Copilot connector?**

A Copilot connector is a controlled integration that lets BizChat query a system of record and return scoped answers. It does not change the model; it feeds it context. When you ask a question, the connector routes it to the right system, such as a CRM or ERP, respects permissions and returns only the information you need.

**How do you build a secure first Copilot connector?**

Start with one narrowly scoped use case and build security in from the start. The episode outlines six steps: define the business question, map the minimal data, design which fields are exposed, implement identity-based authentication and scoping, test with IT and business owners using real queries, and deploy with monitoring and governance in place.
