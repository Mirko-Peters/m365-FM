## FAQ

**How do I build an AI approval stage in Copilot Studio agent flows?**

Create an agent flow, add an AI stage and write a precise instruction prompt with exact rules, such as an amount limit and a 30-day purchase window. Define typed inputs like amount, description and purchase date, test with sample data, then replace the samples with Dataverse tokens from the triggering claim record.

**How can a Copilot Studio approval route a request to the submitter's manager automatically?**

Use the Office 365 Users connector to look up the manager dynamically. First get the claim creator's user record from Dataverse with a get row by ID action, then call get manager with that user's primary email, and pass the returned email into the manual stage's assigned to field.

**How do I make the AI check a receipt against the expense claim?**

Add an image or document input to the AI stage and extend the prompt so the receipt must match the declared item, amount and date. Download the file from the Dataverse file column, map its content (not the metadata) into the input, and trigger the flow when the receipt column changes.
