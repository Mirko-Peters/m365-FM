## FAQ

**How long do Microsoft Entra risky sign-ins and risk detections stay available?**

Risky sign-ins sit in a rolling 30-day window, while risk detections such as anomalous token or attacker in the middle persist for 90 days. The episode recommends exporting risky sign-ins weekly and keeping risk detections for at least 180 days in a store you control, so the earliest signals of an investigation are not lost.

**Which audit log signals indicate data staging in Microsoft 365?**

The strongest signal is a new sync client registration paired with widened sharing links in the same session window, especially alongside reads of files the user never touched before. Raw download counts are weak because people sync libraries, so the episode recommends detecting change from a user's baseline plus new capabilities such as external forwarding rules.

**Are Microsoft 365 Copilot interactions captured in the audit log?**

Yes, since an improvement after August 2024, Copilot interaction events reference the hosting service and the files used to build an answer, while earlier interactions may have left little trace. The episode suggests joining these events to unified audit log file reads within a short session window and watching for sharing links or external email afterwards.
