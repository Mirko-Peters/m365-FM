## FAQ

**What is the difference between Fabric Data Activator and Power BI dashboards?**

Power BI shows what is happening, while Fabric Data Activator acts on it. Dashboards may refresh only every fifteen to sixty minutes and still need a person to notice and respond. Data Activator reads event streams in near real time and, when a defined condition is met, triggers actions such as pausing a pipeline or updating records.

**Can Fabric Data Activator call systems outside Microsoft Fabric?**

Yes, it can call external APIs when a condition is met. The episode describes sending orders to a supplier's system when inventory drops below a threshold, posting to webhooks, triggering multi-step workflows in SaaS CRM or legacy ERP systems, and creating a Dynamics 365 work order when machine sensor readings reach a failure warning range.

**What limits should I plan for before scaling Fabric Data Activator?**

Plan for capacity and latency. Every trigger evaluation and action consumes the same Fabric capacity used by BI refreshes, dataflows and warehouse queries, so too many triggers can slow other workloads. Reactions are also only as fast as source and target systems, such as an ERP batch-processing every fifteen minutes. Start with high-value, low-frequency conditions.
