## Key takeaways

## FAQ

**What is the difference between Copilot and an autonomous agent?**

Copilot makes one person faster, while an autonomous agent completes the work without that person. With Copilot, a human still approves the final action, so the risk is wrong words. An autonomous agent keeps state, calls tools as its actual work and verifies outcomes, so the risk shifts to wrong actions in production systems.

**What should an execution contract for an AI agent contain?**

An execution contract defines at least five things: the allowed tools and specific actions, the scope or containment unit, the evidence the agent must cite before acting, the confidence, anomaly and volume thresholds, and escalation and kill behavior. It lives in the control plane, not in the prompt, so convenience cannot quietly widen it.

**How should a 30-day autonomous agent pilot be run?**

Pick one domain, such as IT remediation or security triage, and write three policies on day one: allowed actions, evidence requirements with confidence thresholds, and escalation paths with named owners. Build replayable run records before enabling autonomy, then track time to close, human-in-the-loop rate, rollbacks and policy violations, and stop if they do not move.
