## FAQ

**How do I add a SharePoint list as knowledge in Copilot Studio?**

Open your agent in Copilot Studio, choose add knowledge, select SharePoint and pick a list or paste its URL. The picker shows My lists and Recent lists, mirroring SharePoint itself. Copilot then queries the live list on every question without copying or indexing the data, so updates such as a new company holiday appear immediately.

**Does Copilot Studio respect SharePoint list permissions?**

Yes, Copilot Studio queries SharePoint lists in the calling user's own security context, so it only returns rows that user can already open. It uses the same authentication session, including multi factor authentication, and no elevated service accounts. Reads show up in normal audit trails, such as Microsoft Purview, as the user's own activity.

**When should I migrate a SharePoint list to Dataverse or Fabric instead of connecting it to Copilot?**

Migrate when the list changes faster than people can read it, needs relational integrity beyond lookup columns, or has grown into a makeshift ERP. Heavy analytics, cascading updates and transaction reconciliation also belong in Dataverse or Fabric. For holiday calendars, asset trackers and knowledge registers, an indexed list connected live is enough.
