## FAQ

**What does GitHub Copilot for Azure generate from a prompt?**

It generates infrastructure-as-code scaffolding, often Bicep or ARM templates, that matches common Azure deployment patterns. In the episode's example, a prompt for a Python web app on Azure Functions with a SQL backend produces files for the function app, hosting plan, database, firewall rules and connection strings, which you then review and adjust.

**How does the Azure Developer CLI (azd) simplify deploying an Azure app?**

azd replaces a chain of manual commands with one repeatable workflow for creating an environment, provisioning resources and deploying code. It reads configuration files in your repo or prompts for missing details, so you can see what gets provisioned. New developers can clone the repo, run azd and start coding.

**Can GitHub Copilot help debug errors in a deployed Azure app?**

Yes, it can interpret error messages and log snippets and suggest likely causes and fixes. In the demo, a database connection failure leads Copilot to point at firewall rules and the authentication type in the connection string. Pasting telemetry from Application Insights or Azure Monitor gives better suggestions, but fixes should be tested in staging first.
