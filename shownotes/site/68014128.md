## FAQ

**Is Power BI Pro included in Microsoft 365?**

Only in some bundles. The episode notes that Microsoft 365 E5 includes Power BI Pro, but many organizations still need separate Power BI licenses or premium capacity for full access. It is worth checking licensing before planning a rollout of embedded reports across Teams, Excel, Outlook, PowerPoint and SharePoint.

**How do you add a Power BI report to Microsoft Teams?**

You can embed Power BI reports and dashboards in chat threads or as channel tabs, where everyone can view and filter them live. A suggested first step is to embed one report in a Teams channel, test inline filtering, then show the live report in a meeting with a team leader.

**Does Microsoft Fabric require extra setup before Power BI teams can use OneLake?**

Yes. Fabric and OneLake are not a switch you simply flip. They require tenant settings, capacity planning and real governance decisions, and enabling Fabric may involve premium capacity or configuration changes. The payoff is one shared data pool and semantic model that finance, HR and sales all report from.
