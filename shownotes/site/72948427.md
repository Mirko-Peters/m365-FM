## FAQ

**Can the Key Vault Contributor role read secrets in Azure Key Vault?**

Yes, indirectly, if the vault still uses legacy access policies. A Key Vault Contributor can edit those policies and grant itself read access to every secret, key and certificate. The episode recommends switching to Azure RBAC, auditing contributor assignments and replacing them with narrower roles such as Key Vault Secrets User or Key Vault Secrets Officer.

**How does managed identity help an app access Azure Key Vault without credentials?**

Managed identity lets Azure create and manage an identity for a resource in Microsoft Entra ID, so the app stores no client secret. You enable it on, for example, a web app, then grant that identity the Key Vault Secrets User role. The app authenticates with its identity and Azure handles the credentials behind the scenes.

**How much does Azure Key Vault cost?**

At the time of recording, the standard tier charges per operation, about three cents per 10,000 operations, with no per-secret storage fee. For a typical web app with a handful of secrets that adds up to less than a dollar a month. The premium tier adds HSM-backed keys at higher per-operation cost plus a monthly fee per key.
