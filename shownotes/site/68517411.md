## FAQ

**When should I use the Copilot Studio code interpreter instead of Azure Functions?**

Use the code interpreter when a task is immediate, local and disposable, such as converting a CSV to an Excel report or running a one-off analysis. Choose Azure Functions when the work is recurring, business critical or needs versioning, monitoring and an owner. The interpreter is a sandbox for experimentation, not a production platform.

**What are the limits of the code interpreter in Power Platform?**

The code interpreter runs in a sealed, read-only sandbox with a 512 megabyte file cap and timeouts on longer executions. It cannot call external APIs, make web requests or install packages with pip. Admins must enable it per environment in the Power Platform admin center, because it is disabled by default.

**How do I move a Python prototype from the code interpreter to Azure Functions?**

Prototype in the code interpreter until the logic produces consistent results, then take the generated Python, refine it and deploy it as an Azure Function. Add proper error handling, environment variables and CI/CD. The function then gains versioning, managed identities, Application Insights logging and automatic scaling that the sandbox cannot offer.
