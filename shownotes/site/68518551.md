## FAQ

**Why do GPUs sit idle during AI training?**

GPUs sit idle because the data fabric cannot move data fast enough between storage, CPU and GPU memory. The episode argues the bottleneck is data movement, not the model math. Small interconnect delays repeat across every GPU, epoch and gradient update, so a training run planned for hours can stretch into days and raise cloud costs.

**What is the NVIDIA Grace Blackwell GB200 superchip?**

The GB200 combines an Arm-based Grace CPU and a Blackwell GPU that share coherent memory, so data no longer needs redundant copies between CPU and GPU memory. In a GB200 NVL72 rack, 72 GPUs connect through a fifth-generation NVLink switch fabric with 130 terabytes per second of all-to-all bandwidth, behaving like one large GPU.

**What does Microsoft Fabric have to do with Blackwell on Azure?**

Once Blackwell and Azure orchestration remove hardware bottlenecks, the data layer becomes the new limit, and Microsoft Fabric is that layer. The episode explains that slow ingestion pipelines, legacy connectors and loose governance leave fast GPUs waiting or spread corrupted data quickly, so pipelines and governance in Fabric need refactoring to keep the clusters fed.
