## FAQ

**How do I create Planner tasks from a chat with Copilot Studio?**

Build an agent in Copilot Studio, give it clear instructions, and add the Planner connector actions create a task, list tasks and update a task. Set group and plan IDs as custom values, keep titles dynamic, and write rich tool descriptions so the model can infer several task titles from one natural-language request.

**Why does my Copilot Studio agent pick the wrong tool or keep asking questions?**

Usually the tool descriptions are too generic. The orchestration model reads each tool's description to decide which one to call, so describe intent precisely, for example telling it to infer titles without asking or to accept natural-language dates. Mirko calls poor descriptions the main reason agents misfire.

**When should I use Power Automate instead of a Copilot Studio agent for Planner?**

Use Power Automate for deterministic, trigger-based work, such as creating a task whenever a form response arrives. Use a Copilot Studio agent for interpretive requests like adding whatever tasks came up in today's meeting. Both can be combined, with the agent gathering context and a flow creating individual tasks per attendee.
