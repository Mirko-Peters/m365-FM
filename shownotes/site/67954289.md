## FAQ

**How do I add my own Copilot capability in Business Central?**

You extend the Copilot Capability enum in AL and call the register capability method from an install or upgrade codeunit. Without that registration Copilot does not know the feature exists. Use unique names and enum values, version the extension, test in a sandbox, and confirm the capability appears on the Copilot and Agent Capabilities page.

**What is a meta prompt in Business Central Copilot development?**

A meta prompt is the primary system message that defines the model's role, output format and guardrails for every response. Developers set it with the AOAI Chat Messages codeunit's set primary system message call. Unlike a one-off user prompt, it persists across the chat, so a finance assistant consistently returns structured output instead of guessing its style.

**Where should I store Azure OpenAI API keys for a Business Central extension?**

Store them in isolated storage during development and testing, and in Azure Key Vault for production. Never hard-code keys in AL or commit them to a repository. Wrapping the key as SecretText keeps it hidden in the debugger, and running the Azure OpenAI set authorization chain end to end confirms endpoint, deployment and key line up.
