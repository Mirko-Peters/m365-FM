## FAQ

**Does enabling Microsoft Fabric break existing Power BI reports?**

No, turning on Fabric in the Power BI admin portal does not rewrite reports or move datasets. Existing workspaces stay the same and new items like lakehouses and pipelines simply become available. The episode recommends enabling it for a pilot group first, with a trial capacity and a sandbox workspace for experiments.

**Should a Dataflow Gen2 table use replace or append?**

Use append when you need history and replace only when a current snapshot is enough. With replace, every load wipes the previous data, so a fact table such as FactOnlineSales would keep only the latest values. Append lets the table grow over time and preserves the trail analysts need for year-over-year comparisons.

**How do I get an email alert when a Fabric pipeline fails?**

Chain the dataflow in a pipeline and add an on-fail path to an Office 365 Outlook email activity. Give the email a clear subject such as pipeline failure and use the expression builder to include the pipeline ID, workspace ID and a UTC timestamp. Grant the requested OAuth consent the first time, or alerts never send.
