## FAQ

**What is an enterprise control plane?**

An enterprise control plane is the system that governs who accesses what, when, and under which conditions. The episode defines it through three parts: identity as the origin where accounts are created and revoked, policy that travels with that identity and evaluates context in real time, and governance with one audit trail across every environment.

**How does Microsoft Entra ID differ from AWS IAM?**

AWS IAM is resource-centric and originates identity only for AWS accounts, while Entra ID is identity-centric and originates in the workforce. When Entra ID federates AWS, it evaluates identity, device health and risk, then issues the SAML assertion that grants temporary AWS credentials, so Microsoft controls the gate even though AWS hosts the resource.

**Can Microsoft tools govern workloads running on AWS?**

Yes, the episode argues Microsoft extends its governance layer across AWS. Defender for Cloud monitors AWS workloads, Azure Arc projects Azure Policy onto EC2 instances and on-premises servers, Sentinel logs access, and Purview classifies data. AWS keeps running the infrastructure, while incidents and policy enforcement flow through Microsoft's single governance engine.
