## FAQ

**What is the difference between ARM templates and Bicep?**

Bicep is a cleaner language that compiles down to ARM templates behind the scenes. ARM templates are written in verbose JSON, where one missing comma breaks the deployment. Bicep is built by Microsoft for Azure, gets full Microsoft support, and you can still fall back to raw ARM templates later, so nothing locks you in.

**Should I use Bicep or Terraform for Azure?**

If you only work in Azure, start with Bicep because it integrates natively and has fewer moving parts. Terraform makes more sense when you manage infrastructure across AWS, Google Cloud and Azure together. Its portability comes at a cost, though: you must learn its own language, HCL, on top of Azure itself.

**How can a beginner start with infrastructure as code without breaking production?**

Start in a separate test subscription, never in production. Export an existing resource group as an ARM template from the Azure portal to see real code, then write a small Bicep file in VS Code with the Bicep extension. Run what-if before every deployment and rebuild your dev environment several times.
