## FAQ

**What KPIs should a 30-day Copilot Studio pilot target?**

For IT service, the episode suggests 20 to 40 percent ticket deflection, a 15 to 30 percent SLA reduction for tickets the agent touches and 10 to 25 percent fewer escalations. It adds greater than 85 percent grounded answer accuracy on an evaluation set, zero access violations and audit logging from day one, while ignoring prompt and token counts.

**How do you stop a Copilot Studio agent from giving confident wrong answers?**

Enforce a no source, no answer rule: the agent must cite an approved runbook, policy or known issue, or it escalates. Ground it on a curated Azure AI Search index chunked by atomic procedure, tagged with metadata and security trimmed, then score grounded accuracy weekly against a fixed evaluation set and red team prompts early.

**Why does every agent need a Microsoft Entra Agent ID?**

Agent ID gives each agent a non-human identity, so its actions are attributable in audit logs and constrained by least privilege. It lets you apply Conditional Access, separate read from write permissions and tie the agent to an owner and lifecycle, so retired or forgotten agents lose their permissions instead of becoming ghost agents.
