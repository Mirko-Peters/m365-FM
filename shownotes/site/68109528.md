## FAQ

**When are SharePoint 2013 workflows retired in SharePoint Online?**

SharePoint 2013 workflows are scheduled for full retirement in SharePoint Online in April 2026, and SharePoint 2010 workflows are already retired. Microsoft also disabled 2013 workflows for new tenants in 2024. The episode recommends running an inventory of classic workflows and InfoPath forms now, because those are the processes you need to replace first.

**Can I build a Power Apps app from an existing SharePoint list without moving data?**

Yes, Power Apps can generate a canvas app directly from a SharePoint list, and the app uses the list as its data source. You don't port data or write back-end code. From the list's Power Apps menu you choose create an app, then adjust labels, buttons and columns, and Power Fx is only needed for advanced logic.

**How does AI Builder process documents in a SharePoint library?**

AI Builder applies a document processing model to a library through the classify and extract menu, and every new file is scanned automatically. Extracted values appear as new library columns. Structured models handle fixed layouts like invoices or purchase orders, while freeform models handle varying formats like contracts and letters. Training data is stored in Microsoft Dataverse.
