## FAQ

**Should I use Copilot Studio or Teams Toolkit to build a Copilot agent?**

Use Copilot Studio when power users need fast, low-code agents inside Microsoft's guardrails, and the Teams Toolkit, also called the Microsoft 365 Agents Toolkit, when developers need custom orchestration, external models or deep integration in VS Code. End users see the same interface either way, so the choice is about grounding, scale and control.

**Why do Copilot agents need grounding in enterprise data?**

Without grounding, an agent answers from general model knowledge and confidently guesses. Grounding through Microsoft Graph connectors, Power Platform connectors or APIs lets it pull current facts from SharePoint, Dataverse or line-of-business systems and cite the source. Pair it with sensitivity labels and Purview classification so agents only retrieve content their permissions allow.

**How is Copilot Studio billed compared with agents built in Teams Toolkit?**

Copilot Studio consumes tenant-wide Copilot Credits, bought in packs of 25,000 for about 200 dollars per month at the time of recording or through pay-as-you-go, and tests drain the same pool as production. Teams Toolkit agents run under users' Microsoft 365 Copilot licenses, but custom engines, external APIs and connectors add their own costs.
