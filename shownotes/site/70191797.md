## FAQ

**What is the difference between a metric and a KPI?**

A metric describes what happened, while a KPI is a decision rule that says what must happen next. A real KPI carries an obligation: a precise trigger with threshold, duration and scope, one accountable owner, a pre-committed action, a time window and a feedback loop that measures whether the intervention worked.

**Which Microsoft tools make up a KPI decision stack?**

The stack has five layers: Fabric and OneLake for data convergence, the Power BI semantic model for governed meaning, Dataverse as the decision ledger, Power Automate for enforcing actions and Copilot Studio as the interface. Each layer removes a class of ambiguity, and skipping one pushes the system back into reporting.

**Where should AI be used in KPI and decision systems?**

AI belongs at the edges, in explanation, summarization and option generation, not in the rule engine. It should not trigger escalations, freeze spend, change forecast baselines, assign severity, override ownership or mark actions complete. Those state changes need deterministic criteria recorded in the ledger, and low-confidence or out-of-policy requests must stop and escalate.
