## FAQ

**Why do duplicate files make SharePoint search and Copilot worse?**

Duplicates split the relevance signals search relies on, such as title, body, click history and links, across many variants. A stale draft with attractive metadata can then outrank the real final. Copilot uses the same index, so a messy corpus produces plausible but wrong summaries rather than true hallucinations.

**How can you move old SharePoint files to Azure Blob Storage without losing them?**

Use an SPFx command that sends a file reference to an Azure Function, which copies the file server to server, verifies the hash, logs the move in Table Storage and only then deletes the source. A one-click restore fetches the blob, validates the hash and recreates the file with its original metadata.

**Which permissions should a SharePoint archiving solution request so security approves it?**

Request delegated permissions with the on-behalf-of flow instead of tenant-wide application permissions like Sites.ReadWrite.All. The function then acts as the user who clicked, so it can only move files that user can already access. Admins approve one scoped API request in SharePoint admin and can revoke it later.
