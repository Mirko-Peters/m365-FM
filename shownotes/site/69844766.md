## FAQ

**What is agent sprawl in Microsoft 365?**

Agent sprawl is uncontrolled growth across six things: identities, tools, prompts, permissions, owners and versions. The episode says it enters through maker-built agents, vendor-provided agents and marketplace integrations, and an early warning sign is users asking which agent they should use, which signals duplication, failing discoverability and fragmenting trust.

**Why does every Copilot agent need its own Entra Agent ID?**

A dedicated Entra Agent ID lets you prove which agent acted, under which permissions and with whose approval. Without it, actions trace back to shared service accounts or maker connections, so security cannot disable one misbehaving agent without breaking others and often pauses the whole program instead of containing a single actor.

**Which metrics should executives use to fund an AI agent program?**

Fund agent programs on four metrics: MTTR reduction, request-to-decision time, auditability and cost per completed task. The episode argues against counting chats or agents, because a chat that ends in escalation or duplicate tickets is not a completed task, and it recommends a measurement contract for every agent product before it ships.
