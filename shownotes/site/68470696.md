## FAQ

**Why can't I style Power Apps charts the way I want?**

Because the native chart control seals rendering, colors, scaling and fonts inside predefined templates. The episode argues this is an architectural limit, not a bug: you get one data source, type and style, and changing gradients, axis labels or behaving dynamically requires brittle workarounds that often end with exporting data to Power BI.

**How do you display an AI-generated chart in Power Apps?**

Send a trimmed JSON version of your data to an AI prompt with code interpreter enabled, ask it to return only a Base64-encoded image, and store the result in a variable. Bind that variable to an HTML text control. The app never draws the chart; it only displays the image the AI generated.

**What data should I send to an AI prompt for charts in Power Apps?**

Send only filtered, flattened data. Filter records in Power Apps first rather than asking the AI to do it, keep only relevant columns, and convert choice, lookup, date or boolean fields into simple text values. Clean JSON keeps payloads small, avoids timeouts and produces predictable charts. Null fields can make records disappear.
