## FAQ

**Why does Copilot in Dynamics 365 give generic recommendations?**

Copilot starts from a broad, general-purpose knowledge base, so without your own data it fills gaps with what is normal across many companies. The episode cites pipeline forecasts with odd close probabilities and an ordering suggestion that ignored a supplier's penalty on small orders, because that detail lived only in an internal system.

**How does external CRM or ERP data get into Copilot in Dynamics 365?**

External data reaches Copilot through Dataverse, via APIs, Dataverse connectors or Azure Data Lake for staging larger datasets. A secure connector acts as gatekeeper, ingestion filters strip sensitive fields or reject invalid entries, and relevant data is then pulled into Copilot's prompt context. You also choose between real-time integration and simpler scheduled syncs.

**How do you keep Copilot data integrations in Dynamics 365 compliant?**

Limit what travels and who can see it. Map only needed fields, use role-based access so Copilot answers within each user's scope, add Conditional Access for device and network rules, encrypt data in transit and at rest, and log every data movement. Avoid shortcuts like pulling whole tables or giving test environments production permissions.
