## FAQ

**What does email-to-case ingestion do with attachments in Dynamics 365 Customer Service?**

It analyzes them before a human opens the email. In the episode, the case scanner reads the subject, body, footer and attachments, using OCR to spot a damaged product in a photo or a policy number in a PDF. It then creates the case and fills fields such as customer, product and priority.

**How does unified routing decide which agent receives a case?**

Unified routing assigns cases based on rules, skills and capacity rather than who grabs them first. It knows which agent handles returns, speaks a given language and has room for another case. A diagnostic trail shows which rule sent a case where, so teams fix the rule instead of blaming the person.

**In what order should a support team roll out these automations?**

Start with the case scanner, then routing, then AI drafting. Scanning first gives visibility and turns email into structured data. With clean data, unified routing ends routing by mood. Only then add Copilot Studio drafting, where agents review, edit and send every reply, so human judgment stays in control.
