## FAQ

**What is a Dataverse prompt column?**

A Dataverse prompt column is a table field that runs a natural-language instruction instead of formula logic. It uses the same large language model behind Copilot, references other fields of the record, and regenerates output such as welcome messages or validation flags when the record updates. Keep each prompt narrow and include the needed field context.

**Can generative pages in Power Apps be used directly in production?**

Not without review. Generative pages produce React-based pages inside model-driven apps from a natural-language description, but the episode advises treating the output like unreviewed pull requests. The AI may optimize for readability, not compliance exceptions or data masking, so preview in development environments first and test before anything reaches production.

**How do agents calling agents work in Copilot Studio?**

A parent agent handles the conversation and delegates specific tasks to smaller child agents, such as authentication, troubleshooting or escalation. Each child receives inputs, runs its procedure and returns structured output to the parent. This makes agents easier to debug and version independently, but parents must pass clear parameters to avoid context gaps.
