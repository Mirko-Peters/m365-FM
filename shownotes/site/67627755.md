## FAQ

**Where are files shared in Microsoft Teams actually stored?**

Files shared in Microsoft Teams are stored in SharePoint. When you create a team, Microsoft 365 creates a SharePoint site in the background that holds the document library, permissions and version history. Dragging a file into a channel places it in that SharePoint library, with Teams acting as a window into it.

**How have SharePoint permissions changed compared to older versions?**

Modern SharePoint ties access to Microsoft 365 groups instead of broken inheritance and layered exceptions. Adding a user to a team or group grants the right access across SharePoint, Teams and Outlook automatically. Sensitivity labels, data loss prevention policies and Conditional Access then apply tenant-wide rules, so admins set policies once rather than site by site.

**What do organizations use modern SharePoint for besides file storage?**

Organizations use modern SharePoint for intranets, portals and automated workflows. The episode describes HR onboarding portals with policies, training and checklists, an executive reporting hub with embedded Power BI dashboards showing live data, and controlled external sharing in compliance-heavy industries. Power Automate can also route uploaded contracts to approvers and archive signed copies.
