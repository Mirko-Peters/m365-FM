## FAQ

**Why do task lists make you feel busy but not productive?**

Task lists put every item on the same level, so a two-minute errand sits next to work that matters for months. People then grab quick wins, cross off many small items and feel productive while the critical project stalls. The episode calls this a system flaw of lists, not a lack of personal discipline.

**How can Copilot apply the Eisenhower Matrix to my tasks?**

Copilot can sort tasks into Eisenhower quadrants if you ask for it explicitly. Instead of a vague request to summarize, ask it to list all tasks from a meeting and place them into urgent and important categories using the Eisenhower Matrix. Without that framing, it falls back to a plain list of action items.

**How do Microsoft To Do, Planner, Lists and Teams work together?**

They work best as one connected system rather than separate apps. Flagged Outlook emails appear in To Do, Planner tasks surface inside Teams, and Lists can hold structured details such as owners and deadlines. Using these connections avoids copying the same task into three or four places and keeping every copy updated.
