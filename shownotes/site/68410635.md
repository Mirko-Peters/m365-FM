## FAQ

**Why do Azure Maps visuals not render in Power BI after upgrading from Bing Maps?**

Usually because a Power BI admin has not enabled them yet. Azure Maps visuals are disabled by default for privacy and data residency reasons. An admin must allow the Azure Maps visual and data processing outside the tenant's region in the admin portal; otherwise converted maps simply fail to render without any error message.

**Is the automatic Bing Maps to Azure Maps upgrade in Power BI reliable?**

Only for simple maps. Basic visuals with one category, one measure and latitude and longitude fields usually convert intact. Layered logic, shape overlays, drill-through and conditional formatting often break, bubble sizes shrink, default zoom changes and color gradients shift, so every converted map should be checked or rebuilt manually before publishing.

**What is the Power BI shape map visual and when should you use it?**

Shape map colors predefined areas such as countries, states or custom sales territories based on a measure. It is enabled under preview features in Power BI options and accepts custom boundary files. Because it renders entirely client side without cloud geography calls, it suits highly secure or air-gapped environments where data must not leave the region.
