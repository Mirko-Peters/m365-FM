## FAQ

**How does Copilot Studio query data in Microsoft Fabric?**

Copilot Studio connects to a published Fabric data agent. It parses the natural-language question, maps terms like sales or last quarter to the Fabric data model, and the agent runs a scoped query and returns the result. Conversational context lets follow-up questions refine earlier answers without restating the whole request.

**Can users see data they are not allowed to see through Copilot Studio?**

No, not when authentication passes through the end user's identity at runtime. Fabric then applies its role-based access, row-level security and data loss prevention to every query, so a user only sees their permitted data. Questions outside those permissions get a polite refusal that explains the governance policy instead.

**How do you stop a Copilot Studio Fabric agent from hallucinating answers?**

Set a clear system prompt telling the copilot to use Fabric data only. The episode also recommends disabling external web sources for critical data sets and creating fallback topics that decline out-of-scope questions. The tracer view shows which data agent was called and how the answer was formed, which helps debugging.
