## FAQ

**When should you use Azure instead of Copilot Studio for an AI agent?**

Start in Copilot Studio and switch to Azure only when the case cannot be solved there. Nilüfer Doğan says the main trigger is a large amount of data that must first be cleaned, structured and indexed elsewhere. She then uses Azure AI Search and connects the result to Copilot Studio as a knowledge source.

**How can a Copilot Studio agent respect document permissions?**

By indexing permission data together with the content. In her Confluence agent, Nilüfer retrieved the permission levels and groups from the on-premises system, stored them as a variable in the Azure AI Search index, and used that index as the agent's knowledge source. Users without access to a page in Confluence could not get answers from it.

**How do you measure the business value of Copilot Studio agents?**

Track usage against the time and cost of the manual process. Nilüfer used Power Automate to collect conversation history and compare it with how long tasks take without the agent. She recommends the Copilot Studio Kit for metrics, KPIs and return on investment, and notes it also helps with governance, alongside built-in analytics in Copilot Studio.
