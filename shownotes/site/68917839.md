## FAQ

**Why does Microsoft 365 Copilot give outdated or wrong answers from SharePoint?**

Copilot grounds on whatever content the user can reach, so stale PDFs, drafts in deep folders and broken permissions shape its answers. If the current policy sits behind a door the user cannot open, the answer blends old and partial sources. It sounds confident but is wrong because the underlying structure is wrong.

**What are the five binds of Microsoft 365 governance for Copilot?**

The five binds are information architecture, lifecycle, sensitivity labels, DLP and retention, run as connected controls rather than slogans. Lean hubs give every concept one home, lifecycle forces owners to attest or archive, labels map to risk, DLP stops exfiltration at the exits, and retention turns someday into dates.

**How can I measure whether SharePoint cleanup improved Copilot answers?**

Run the same Copilot prompts before and after cleanup with the same user persona and compare three measures. Citation precision shows how many references point to current authoritative pages, answer variance shows how much responses change across runs, and access mismatch shows how often citations point to content the user cannot open.
