## FAQ

**Can an AI agent upgrade a Java 8 application to Java 21?**

Yes, in the case described an agent runs an apply, build, test, patch loop until everything is green. It uses OpenRewrite recipes for API changes, aligns dependencies with official bills of materials, regenerates the SBOM, reruns vulnerability scanners and produces small commits with rationale that humans review and approve in Git.

**Why upgrade legacy Java to Java 21 instead of staying on Java 8?**

Upgrading to Java 21 brings measurable performance and maintainability gains, not cosmetic ones. Virtual threads make concurrency cheap, so more requests run on the same CPU budget, and G1 and ZGC refinements reduce garbage collection pauses and tail latency. The foreign function and memory API is also stable for native code and off-heap work.

**How is an AI-driven migration from AWS to Azure kept auditable?**

Every action lands in Git as a small commit with a reason and a link to an advisory, recipe or migration note. GitHub Actions deploys through environments that require approvals, secrets move to Azure Key Vault with managed identity, and rollback is a Git revert. Power BI dashboards report CVE trend, cost and deployment health.
