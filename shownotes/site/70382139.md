## FAQ

**What is an autonomous tenant in Microsoft 365?**

An autonomous tenant is a Microsoft 365 environment run as one control plane instead of separate tools. Entra ID enforces identity policy, Dataverse holds the authoritative business state, Power Automate orchestrates processes, Copilot Studio translates intent into actions, and Microsoft Graph propagates changes, so processes like onboarding run without people reconciling data between systems.

**How does automated new hire onboarding work with Entra ID and Power Automate?**

A signed offer triggers a Power Automate flow that creates the employee record in Dataverse. Entra ID lifecycle workflows then create the identity, assign role-based groups and apply Conditional Access. Parallel flows ship an Autopilot-enrolled laptop, grant Dynamics 365, Teams and SharePoint access, and push salary and cost-center data into payroll.

**Should Copilot make financial or access control decisions?**

No, the episode recommends keeping Copilot to generative tasks such as summarizing, drafting and flagging unusual items. Deterministic decisions like invoice amounts, access grants and expense approvals belong to policy engines such as Entra ID and Dataverse rules, or to a human approver, because language models can produce plausible but wrong answers.
