## FAQ

**How do you authenticate to the Dynamics 365 Finance and Operations API?**

Every call needs an OAuth 2.0 token from Azure AD, now Microsoft Entra ID. Register an app, assign only the API permissions it needs, get admin consent, then request a token with the client credentials flow for app-only access. Send it as a bearer token in the authorization header of each request.

**When should I use a custom service instead of OData in Finance and Operations?**

Use OData for standard create, read, update and delete operations on entities such as customers, vendors and invoices. Switch to an X++ custom service when you need server-side business rules, multi-table transactions or conditional workflows, for example currency conversions that must calculate atomically or production orders updating several tables together.

**How should integrations handle HTTP 429 errors from the Finance and Operations API?**

Build retry logic with exponential backoff from day one. Microsoft enforces API limits, and pushing past them returns HTTP 429 Too Many Requests. Without retries, integrations fail exactly when volume spikes, such as at month-end. Combine this with monitoring through Azure Monitor, Application Insights and Lifecycle Services diagnostics.
