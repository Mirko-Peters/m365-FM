## FAQ

**Why can't Microsoft 365 Copilot see data in Salesforce or ServiceNow?**

Copilot only sees what it is grounded on, and by default that is the Microsoft 365 work graph of mail, chats and files. Without a connector, token and governed access path to Salesforce, ServiceNow or an internal API, it has no way to fetch that data, so it guesses or answers vaguely.

**When should I use Copilot Studio instead of Teams Toolkit to build an agent?**

Choose Copilot Studio when you need speed, governance and citations for read-only enterprise answers that makers can maintain. Choose Teams Toolkit when you need strict input validation, custom schemas, conditional access aware policy in code or low latency. The episode recommends a hybrid where Studio orchestrates and Toolkit plugins execute.

**Why does DLP block my Copilot Studio agent connectors?**

DLP blocks connectors when the agent is built in the wrong environment or its connectors sit in different data groups. Many organizations block external connectors in default environments, so place the agent in an environment classified as business and keep its connectors in the same DLP data group to avoid blocked actions at runtime.
