## FAQ

**What is the difference between generative pages and canvas apps in Power Apps?**

Generative pages are built from a natural-language description, while canvas apps are assembled control by control. Generative pages run on React inside the model-driven environment and infer layout, filters, forms and lookups from Dataverse tables. Canvas apps rely on manually positioned containers and Power Fx formulas, which the episode says become fragile and hard to maintain.

**Can I undo changes the app agent makes to a generative page?**

Yes, every change the app agent makes is stored as a reversible diff that you can review, undo or extend. The agent keeps context and history, so you can trace exactly what the AI altered and roll back the last modification. The episode compares this to version control and contrasts it with canvas apps, which never offered that safety net.

**Are canvas apps still worth using now that generative pages exist?**

Canvas apps still make sense for prototypes and quick proofs of concept, according to the episode. For production apps that need compliance and long-term governance, it recommends generative pages, because they inherit consistent styling, accessibility and Dataverse logic. Developers then spend their time on data modeling, security and performance instead of layout maintenance.
