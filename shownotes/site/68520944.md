## FAQ

**What is column autofill in SharePoint document libraries?**

Column autofill reads each file and fills metadata columns based on prompts you write, such as word count, reading time, a one-sentence abstract or a single category. The episode stresses that it follows your instructions rather than guessing, so precise, format-locked prompts and a small calibration batch of about ten files come before scaling it to a whole library.

**How should I design a Microsoft Forms intake form for a document library?**

Ask users only for decisions a human must make, such as owner, status or sensitivity, and let autofill infer the rest. Add your logo and a matching theme, use branching so each category sees only relevant fields, and turn on notifications. Submissions land in a responses folder that someone triages daily before files move to the published library.

**What can Copilot do inside a SharePoint document library?**

Copilot can compare several files and flag whether one is newer, a duplicate or divergent, generate summaries and abstracts, create audio overviews of long documents and answer questions with cited passages. It respects permissions and depends on metadata quality, so the episode advises verifying high-impact answers and pasting useful output back into library columns.
