## FAQ

**When should SharePoint automation use Power Automate, Logic Apps or Azure Functions?**

Use Power Automate for human-centric team workflows with bounded volume and clear ownership, such as notifications and approvals. Use Microsoft Graph webhooks for high-volume eventing, Logic Apps for durable, long-running orchestration across systems, and Azure Functions for custom compute. Agents sit on top as the intake layer. The rule is one standard path per class of work.

**How should SharePoint site provisioning work at enterprise scale?**

Treat provisioning as a factory line rather than a request form. A structured request is validated against policy, approved by the risk owner, then executed through Microsoft Graph by a versioned provisioning service using queue-based orchestration and idempotency keys. Every site gets a template, Entra owner groups, registration in an inventory and an enforced lifecycle through archive and retirement.

**How should external sharing be governed in SharePoint?**

Govern it as a controlled zone instead of a per-site preference. External collaboration happens in dedicated sites with hardened defaults: no anonymous links, required authentication, expiring links and labels for allowed data. Guests need sponsors and lifecycle reviews in Entra B2B, conditional access applies stricter rules, DLP guards egress and audit signals stream into Sentinel.
