## FAQ

**Can Power Automate run Python scripts directly?**

No, Power Automate does not run arbitrary Python. Office Scripts, which are TypeScript-flavoured, are the native script surface for Microsoft 365 automation. To use Python you have to bolt on Azure Functions, Logic Apps or custom connectors, which adds external compute, deployment pipelines, authentication, credentials to rotate and ongoing costs.

**Where should Python still be used in Microsoft Fabric and Power BI?**

Python belongs in Fabric notebooks and dataflows as the compute core for analytics, modeling, machine learning and heavy transforms such as outlier detection or seasonal decomposition. The episode warns against using notebooks as orchestration glue; agents should handle scheduling, validation, I/O and policy, calling notebooks through a clean job API with typed inputs and outputs.

**How do you move Python glue to Office Scripts and agents in 30 days?**

Use week one to audit workflows as glue or analytics and baseline metrics, week two to replace trivial Python endpoints with Office Scripts and native connectors, week three to move dataflow transforms to Copilot-assisted generation, and week four to add an agent with a constrained toolbox and typed contracts. Review gates and versioned prompts run throughout.
