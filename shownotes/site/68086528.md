## FAQ

**Why does my Copilot Studio agent work in the test pane but fail in Teams?**

The test pane is a simulation with tidy inputs, while real users rephrase, abbreviate and make typos. Published channels such as Teams, SharePoint or the demo website can also handle input text and render responses differently. The episode recommends broadening trigger phrases with casual wording, then repeating the same test queries in every channel.

**How do I stop a Copilot Studio agent from making up answers?**

Ground it in a trusted knowledge source. In the agent, choose Knowledge, add knowledge and upload a file such as a policy document, or connect a website or SharePoint location. Wait for indexing, which can take ten minutes or more, and limit critical topics to your added sources so conversational boosting cannot fall back on generic answers.

**What should I check before rolling out a Copilot Studio agent to everyone?**

Confirm knowledge files are fully indexed, set authentication, publish and check the confirmation status, then update the welcome message and conversation starters. Run a closed pilot with a small group who try casual phrasing and typos. Afterwards, watch the Power Platform admin center and built-in analytics for errors and conversations that failed to trigger a topic.
