## FAQ

**Why does vector search alone give wrong answers in Copilot and RAG?**

Vector search returns the most mathematically similar content, not the most relevant or current. It struggles with exact terms such as product codes, legal wording and internal project names, and it ignores metadata like versions, so an older but more descriptive travel policy can outrank the one approved yesterday and produce a confident wrong answer.

**What is hybrid search with BM25 and why does it matter?**

Hybrid search runs BM25 keyword matching alongside vector search. The vector path captures intent while the keyword path catches exact strings such as document numbers, acronyms and internal jargon that a general embedding model treats as noise. When both paths agree, you get a high-confidence candidate; it improves recall but does not fix ranking.

**How can you keep the cost of semantic ranking in Azure AI Search under control?**

Use semantic caching so repeated questions with the same intent are answered from a cache instead of a full retrieval and model call, and apply the semantic re-ranker only to ambiguous, high-value queries. You can also partition indexes so critical content, such as compliance documents, gets deeper ranking than routine content.
