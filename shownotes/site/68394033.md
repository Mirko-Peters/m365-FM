## FAQ

**Is Dataverse included in a Microsoft 365 E3 or E5 license?**

No. Dataverse is a premium service licensed separately from Microsoft 365. Standard E3 or E5 users can build Power Apps on SharePoint lists, but as soon as an app connects to Dataverse, every user who interacts with that data needs premium licensing through a per app or per user plan, even for occasional use.

**Why does Dataverse storage get expensive so quickly?**

Because storage is split into database, file and log capacity, each billed separately per gigabyte. Attachments fill file storage, auditing fills log storage, and every additional environment for development, testing or production adds overhead. The episode suggests forecasting capacity from environments, apps, users and storage categories before building, rather than discovering costs at go-live.

**When should a Power Apps project use Dataverse instead of SharePoint lists?**

Use Dataverse when concurrency, security or compliance genuinely demand it. The episode names three cases: several apps and flows sharing tables with consistent security, fine-grained role based access at table or column level, and deeply relational data with transactional consistency. Otherwise start with SharePoint lists or SQL Server and migrate when requirements outgrow them.
