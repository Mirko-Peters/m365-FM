## FAQ

**What is indirect prompt injection in Microsoft 365 Copilot?**

It is an attack where instructions are hidden in content Copilot later retrieves, such as an email, a SharePoint file or a form field. Copilot blends that content with trusted material, and the model may treat the payload as an instruction rather than data, shaping answers or pushing information toward exfiltration.

**Why isn't a strong system prompt enough to stop prompt injection?**

A system prompt only persuades the model; it does not enforce a security boundary. The model reads instructions and data in one shared channel, so a malicious retrieved document can still compete for its attention. Delimiters and employee guidelines help with structure and honest mistakes, but not with poisoned content.

**How can Azure Logic Apps protect Copilot workflows from malicious payloads?**

Logic Apps can sit in the path as a policy layer that triggers on incoming content, normalizes it, runs fast regex checks, calls Azure AI Content Safety Prompt Shields and threat intelligence, then builds a composite score. Based on that score, the workflow allows, sanitizes, quarantines, requires approval or blocks before Copilot runs.
