## FAQ

**What does the With() function do in Power Apps?**

With() keeps logic local to a single formula. You name intermediate values such as input, source, transformed and payload, compute them once and reuse them without Set or Collect creating global state. The episode uses it to remove duplicated formulas, cache expensive calls like the user profile and build predictable patch payloads.

**Why should Power Apps use connection references instead of personal connections?**

Personal connections tie flows and connectors to the maker's identity, so the app breaks when that token expires or the person leaves. Connection references live in the solution and are bound per environment, typically to service principals with least privilege. The episode recommends rejecting any pull request that contains a personal connection.

**How should Power Apps be promoted from development to production?**

Build everything in a solution, unmanaged in dev and managed in test and prod. Use separate dev, test and prod environments, feature branches with pull requests, solution checker and lint gates, and pipelines that bind environment variables and connection references, run smoke tests and roll back automatically when a step fails.
