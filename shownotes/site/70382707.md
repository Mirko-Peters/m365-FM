## FAQ

**Does Microsoft 365 Copilot give users access to data they could not see before?**

No, Copilot does not create new access, but it exposes existing access at machine speed. It respects permissions as they currently exist in the tenant, not as your policy intends, so a user with drifted read access to thousands of files can summarize all of them with one prompt. Permission audits must come first.

**Why does Copilot give contradictory answers about the same business numbers?**

Copilot gives contradictory answers because the underlying data contradicts itself. When duplicate records, archived versions and differently defined metrics live in separate systems, Copilot synthesizes them all and presents each version as equally valid. The episode describes a board seeing conflicting revenue forecasts and argues that only data consolidation and clear ownership fix this.

**What should an AI governance framework for Copilot cover?**

An AI governance framework for Copilot should cover three domains: prompt governance, output governance and data governance. Prompt governance defines which questions are allowed, output governance sets how responses are validated and when a human must check them, and data governance controls what the AI touches and how its summaries are retained.
