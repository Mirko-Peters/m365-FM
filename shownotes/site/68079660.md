## FAQ

**Why does SharePoint intranet search fail to find documents even with the exact title?**

Usually because the information architecture underneath is weak, not because search itself is broken. The episode names six elements that must work together: global, hub and local navigation, metadata, search and personalization. Overbuilding one, such as huge menus, while files carry names like "final v2" and no tags leaves search with nothing reliable to match.

**Should I use folders or metadata in SharePoint document libraries?**

Use metadata; deep folders are brittle and break when content moves or teams reorganize. The episode recommends topic-specific libraries with site columns and content types, plus a small set of mandatory fields such as content type, owner, status and region, defined centrally in the term store and built into library templates so creators tag at upload.

**Will Microsoft 365 Copilot fix a poorly organized intranet?**

No. Copilot and semantic search cannot invent metadata that does not exist or create navigation where no hub structure was set. Copilot works best with flat sites that have clear topic scopes, consistent tags and aligned navigation, so it can retrieve current, role-appropriate content instead of guessing between outdated versions of the same file.
