## FAQ

**Why do IT automation backlogs keep growing?**

Backlogs grow because every department's automation request funnels into a small central coding team. Each solved request spawns new ones, so the queue lengthens while business needs shift. The episode argues this is a tooling and governance problem, not a people problem, since employees who understand the work are kept away from automation tools.

**What is a citizen developer in Microsoft Power Platform?**

A citizen developer is an everyday employee who builds simple automations with low-code tools inside IT guardrails. Examples from the episode include a finance analyst whose flow refreshes reports automatically and a support rep routing routine inquiries with a rule. They extend IT's reach but do not replace IT, override security or set strategy.

**How do you govern citizen development without creating chaos?**

You govern it with a Center of Excellence, admin controls and environment-level data loss policies. These give IT visibility and built-in safety rails while employees build, which the episode calls supervised freedom. A lean dedicated team handles platform governance, so access widens without turning into unsupervised side builds or security gaps across the organization.
