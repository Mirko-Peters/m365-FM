## Key takeaways

- Permanent exclusions for VIPs, partner domains or trusted locations become invisible bypasses; replace them with inclusive policies and a time-bound, approved authentication context for emergencies.
- Treat device states as distinct tiers, use filters for devices with authentication strengths as a fallback, and shorten token exposure with sign-in frequency, continuous access evaluation and phishing-resistant [MFA](https://www.m365.fm/entity/mfa/?utm_source=podcast&utm_medium=shownotes&utm_campaign=conditional-access-has-trust-issues) for sensitive apps.
- Roll changes out in report-only waves with a rollback plan, then monitor coverage and strength KPIs plus alerts for coverage drops, exclusion changes and high-risk sign-ins without a Conditional Access decision.

## FAQ

**Why are Conditional Access exclusions risky?**

Permanent exclusions become invisible bypasses, because logs only show not applied. VIP groups, partner domains and named locations tend to grow over time. Instead, include all users and cloud apps and handle exceptions through a time-bound emergency bypass authentication context that still requires MFA, needs approval, caps sessions at one hour and is reviewed weekly.

**What is the difference between a registered and a compliant device?**

A registered device has only introduced itself, while a compliant device has met your Intune health rules and brought proof today. Hybrid joined and cloud-joined corporate devices form separate tiers again. Conditional Access policies should treat each tier as a distinct promise, using filters for devices and authentication strengths as a fallback for weaker device states.

**How does Conditional Access protect against token theft?**

It shortens how long a stolen session stays useful. Set sign-in frequency in hours for sensitive apps, enable continuous access evaluation so sessions react to risk changes, password resets and revocation, and require a high sensitivity authentication context with phishing-resistant MFA plus a compliant or hybrid joined device for admin portals and data exports.
