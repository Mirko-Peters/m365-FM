## FAQ

**Why is AI not just another Azure workload?**

AI is a probabilistic decision engine running on deterministic infrastructure. The same prompt can produce different outputs and the same workflow can take different paths, while autoscale, retries and monitoring keep treating activity as demand. The episode argues that a workload is something you host, but a decision engine is something you must constrain at its boundaries.

**How do you stop AI costs from spiraling on Azure?**

Put hard limits in the execution path instead of relying on budgets and alerts. The episode proposes cost classes such as gold, silver and bronze that fix model family, context size, token caps, tool permissions and whether agentic loops are allowed, plus pre-call estimators, intentional model routing and a hard stop on retry attempts.

**How should non-human identities for AI agents be governed?**

Separate identities for execution from identities for decision, and map each non-human identity to a named owner, an owned blast radius, a defined set of actions and a clear revocation path. Scope permissions by action class, such as read, write, notify or transact, so revoking an identity does not break unrelated business processes.
