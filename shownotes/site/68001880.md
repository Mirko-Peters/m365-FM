## FAQ

**What is the difference between a lakehouse and a warehouse in Microsoft Fabric?**

A warehouse is the SQL-first option for structured, curated reporting, while a lakehouse is a flexible workbench for semi-structured data, Spark notebooks and machine learning. Both store tables in Delta Parquet on the same OneLake storage, so the difference is the experience and workload they are optimized for, not where the data lives.

**What is OneLake in Microsoft Fabric?**

OneLake is the single logical data lake that Fabric creates once per tenant, and every workspace, lakehouse and warehouse uses it by default. It runs on Azure Data Lake Storage Gen2, exposes one file system namespace across the tenant and stores tables as Delta Parquet, while compute capacity stays regional and is billed by assignment.

**Do OneLake shortcuts respect the permissions of the person querying the data?**

Not always. When data is accessed through Spark, the shortcut checks the user's own permissions on the target. When it is queried through SQL, access can run under the shortcut creator's identity, so everyone querying gets through with the creator's rights. That is why shortcut creators should be treated as gatekeepers and audited.
