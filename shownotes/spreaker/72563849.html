SOC analysts drown in alerts while MTTR dashboards look great and attackers stay hidden. This episode is for security leaders and architects who want to move from human middleware to a governed security agent fabric, with phishing triage, conditional access and multi-agent validation as concrete examples.

In this episode

  • 00:00 – The human middleware problem
  • 03:45 – The metrics trap: MTTR vs. outcomes
  • 09:58 – Phishing and alert triage agents
  • 21:27 – Conditional access optimization agent
  • 24:49 – Multi-agent debate and validation
  • 31:33 – Governing agents and the autonomy spectrum
  • 46:13 – SOC roles, costs and trust
  • 63:11 – Phased implementation and the agent fabric

Key takeaways

  • Alert fatigue is a system design problem: agents should become the orchestration layer so humans supervise decisions instead of clicking through every alert.
  • Dwell time and true positives are better SOC metrics than MTTR, and multi-agent validation cuts false positives more than bigger models do.
  • Agents need their own identities, least privilege, guardrails, audit trails and a phased rollout from assistive to semi-autonomous before they gain more autonomy.

Worth quoting

“When a machine handles the triage, enrichment, and correlation, speed becomes cheap. What becomes expensive is accuracy. What becomes precious is the human time spent on the stuff that actually matters.” – Mirko Peters (06:26)

“If an agent can disable user accounts, it's a system administrator. If an agent can isolate endpoints from your network, it's a security operator.” – Mirko Peters (31:39)
