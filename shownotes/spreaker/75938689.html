Power BI reports that show last week's numbers usually point to one small, overlooked component: the data gateway. This episode explains for report builders and Microsoft 365 admins what a gateway does, which of the three gateway types fits, and which limits and mistakes to avoid so refreshes keep running.

  • 10:48 – Common gateway mistakes
  • 12:27 – Growing with gateways

Key takeaways

  • A Power BI gateway only connects outward through Azure Relay, so no inbound firewall ports have to be opened.
  • Use personal mode only for solo work; as soon as more than one person depends on a refresh, move to a standard gateway or a cluster, or to the VNet data gateway for data inside Azure.
  • Most gateway trouble comes from operations: sleeping laptops, undersized machines, outdated versions, mixed cluster members and lost recovery keys.
