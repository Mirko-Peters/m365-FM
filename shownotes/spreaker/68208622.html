Compliance analysts still copy Purview audit logs into Excel to build reports that are outdated on arrival. This episode shows GRC, security and Power Platform teams how to combine Purview, Power Automate and Copilot Studio into an agent that classifies risky activity and writes consistent daily compliance reports.

In this episode

  • 00:00 – Why manual GRC reporting fails
  • 02:32 – What the GRC agent actually is
  • 05:54 – Building the Purview data pipeline
  • 11:27 – Giving the agent a brain with Power Automate logic
  • 15:43 – Teaching it to write with Copilot Studio
  • 20:49 – From documentation to orchestration

Key takeaways

  • Most GRC reporting is pattern recognition, so an agent built from Microsoft Purview audit logs, Power Automate and Copilot Studio can produce compliance reports on a schedule.
  • Power Automate extracts, filters and parses Purview audit data, applies risk thresholds you define and logs every run with a run ID and flow version for auditors.
  • Copilot Studio turns the structured results into consistent narrative reports when prompts specify headings, tone and metrics, and the reports are posted to Teams and archived in SharePoint.

Worth quoting
