Running Active Directory and Microsoft Entra ID side by side means double policies, sync drift and broken logins. This episode is for identity admins planning a move to cloud-managed identities. It shows how to shift the source of authority for groups and users step by step without breaking authentication.

In this episode

  • 00:00 – Why two identity systems hurt
  • 01:20 – Understanding the source of authority
  • 04:04 – Preparing the environment
  • 07:55 – Migrating groups to cloud management
  • 11:53 – Migrating user accounts
  • 15:25 – Troubleshooting sync issues
  • 18:47 – Optimization and long-term strategy

Key takeaways

  • The source of authority decides which directory owns an object's attributes, and dual control between Active Directory and Entra ID causes sync drift, lockouts and inconsistent policies.
  • Clean up duplicates and sync scope, enforce modern MFA and document Entra Connect configuration before flipping isCloudManaged on any object.
  • Migrate groups first, then pilot users, verify every change via Graph and sign-in logs, and then use access reviews, Conditional Access and lifecycle workflows to govern from the cloud.
