Exchange Web Services is being retired in Exchange Online, and many line-of-business apps still depend on it without anyone knowing. Microsoft MVP Glen Scales explains to developers and admins how to find EWS usage, what migrates easily to Microsoft Graph and where the hard gaps are. You get a practical migration roadmap from someone who has built on every Exchange API since 2004.

Key takeaways

  • EWS in Exchange Online is switched off in stages, so check the EWS usage report in the admin portal now to find every application ID that still depends on it.
  • Email operations migrate to Microsoft Graph easily, while calendaring, tasks, streaming notifications and high-volume synchronization need redesign around webhooks, delta queries and throttling limits.
  • Moving to Graph is also a security upgrade: replace broad EWS impersonation with granular, least-privilege Graph permissions and use the Graph SDKs that handle retries and throttling.
