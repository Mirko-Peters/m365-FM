Still clicking through admin portals for the same tasks every week? Microsoft MVP Harm Veenstra shows why PowerShell is fun and how automation brings consistency across Entra ID, Exchange, Teams, Azure and Microsoft Graph. IT admins and consultants get practical tips on what to automate first, how to learn PowerShell and how to keep scripts secure.

Key takeaways

  • Automate repetitive tasks such as user onboarding first, because scripted processes deliver consistent results every time.
  • Learn PowerShell with a real business case and understand objects, properties and methods before writing complex scripts.
  • Never store credentials in scripts; use a key vault or certificates, version scripts in GitHub and document them so colleagues can run them.

Worth quoting
