Many Power Apps projects discover just before go-live that Dataverse is not included in Microsoft 365 and that licensing and storage costs multiply. This episode is for makers, architects and IT leaders who want to understand the real cost drivers, the common licensing myths and when cheaper options like SharePoint lists, SQL Server or hybrid designs are the better choice.

  • 04:52 – Three licensing myths that drain budgets
  • 09:31 – Performance, scale and when Dataverse makes sense
  • 14:26 – Cheaper alternatives: Lists, SQL and hybrid
  • 19:14 – Questions to ask before you build
  • 22:05 – The Dataverse reality check

Key takeaways

  • Dataverse is a premium service outside standard Microsoft 365 licenses, so every user who touches its data needs premium licensing.
  • Dataverse costs grow with environments, apps, users and separately billed database, file and log storage, so forecast capacity before you build.
  • Start with SharePoint lists or SQL and graduate to Dataverse only when concurrency, security or compliance requirements truly demand it.
