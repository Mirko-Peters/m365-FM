Planner users waste time dragging, updating and re-dating tasks by hand. This episode shows Microsoft 365 and Power Platform makers how to build a Copilot Studio agent with Planner tools and publish it to Microsoft 365 Copilot and Teams, so plain-language requests turn into structured tasks.

In this episode

  • 00:00 – Why dragging Planner tasks is busy work
  • 00:40 – How Copilot Studio and Planner work together
  • 03:57 – Building the Task Planner agent
  • 08:34 – Adding create, list and update task tools
  • 14:16 – Deploying the agent to Microsoft 365 Copilot and Teams
  • 18:28 – Strategy, governance and limitations
  • 21:46 – From task juggler to task commander

Key takeaways

  • A Copilot Studio agent with Planner connector tools can create, list and update tasks from natural-language requests, so users stop dragging cards by hand.
  • Fix group and plan IDs as custom values and write rich tool descriptions, because the orchestration model reads those descriptions to decide which tool to call.
  • Use Power Automate for deterministic, trigger-based workflows and Copilot Studio for interpretive requests, and govern connections, monitor analytics and respect licensing limits.
