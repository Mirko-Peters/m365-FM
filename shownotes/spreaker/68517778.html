Clicking Add tool and filtering by Model Context Protocol in Copilot Studio does not mean your own MCP server is connected. This episode is for makers and Power Platform admins who want an external MCP server to really talk to their agents. Learn how to build, align and test a streamable custom connector so Copilot answers with governed, cited context instead of polite silence.

Key takeaways

  • The Model Context Protocol option in Copilot Studio only lists Microsoft's built-in servers; an external MCP server needs a custom connector built in Power Apps that acts as a real protocol bridge.
  • Most failures come from small details: the host field must hold only the bare domain, the base URL must not duplicate the API prefix, schemas must match the MCP spec exactly and streaming must be enabled with chunked transfer encoding.
  • Verify the integration with a controlled question against Microsoft Learn and look for incremental, cited answers, because a correct MCP setup gives you governed, auditable and least-privilege context exchange.
