Fabric, Power BI and Spark workloads often crawl because data travels to remote managed storage. This episode shows data platform engineers how Azure Container Storage v2 uses the local NVMe disks already inside AKS nodes for much faster analytics, and how to handle the durability trade-off.

In this episode

  • 00:00 – Storage is the hidden bottleneck

  • 03:07 – Azure Container Storage v2
  • 06:46 – How local NVMe outruns managed storage
  • 11:43 – The durability dilemma
  • 15:42 – Fabric use cases reimagined
  • 20:11 – The local secret you already own

Key takeaways

  • Slow Fabric and Power Platform workloads are often caused by the distance between compute and remote managed storage, not by compute power.
  • Azure Container Storage v2 stripes the local NVMe disks of AKS nodes into fast ephemeral volumes at no extra cost on suitable VM series.
  • Local NVMe is ephemeral, so use it for caches, shuffles, staging and model weights while keeping durability through replication and backups in higher layers.

Worth quoting
