Clicking through the Azure portal for every environment invites mistakes and drift between dev, test and production. This episode explains infrastructure as code for Azure admins and beginners, compares ARM templates, Bicep and Terraform, and shows a safe way to get started.

In this episode

  • 01:16 – What manual provisioning costs you
  • 03:05 – The one-sentence definition
  • 05:04 – ARM, Bicep and Terraform
  • 07:49 – Version control for Azure
  • 10:00 – Security by design
  • 11:39 – How to start safely
  • 13:53 – Three beginner mistakes

Key takeaways

  • Infrastructure as code describes the desired end state of an Azure environment in a file, so every deployment produces the same result without configuration drift.
  • For Azure-only teams, Bicep is the easiest starting point because it compiles to ARM templates and is natively supported by Microsoft.
  • Store templates in version control, keep secrets in Azure Key Vault, run what-if before deploying and never bypass the pipeline for quick portal fixes.
