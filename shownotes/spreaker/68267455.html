Synchronized Active Directory groups show up in Entra ID as read-only, which blocks automation, self-service and access reviews. This episode is for identity and Microsoft 365 admins running hybrid environments and shows how to clean up groups, flip the source of authority to the cloud and use group writeback so legacy systems keep working.

In this episode

  • 00:00 – Why AD groups are fossils
  • 01:19 – The myth of Active Directory sovereignty
  • 04:05 – Entra ID and group writeback
  • 07:14 – Why source of authority matters
  • 10:52 – Cleansing, categorizing and converting groups
  • 14:47 – Living in a dual authority world
  • 18:21 – Why admins resist the switch

Key takeaways

  • Source of authority is set per object, and flipping a group to cloud managed lets Entra ID govern it with dynamic membership, self-service and access reviews.
  • Before converting, inventory and clean up groups, delete unused ones and make sure candidates are universal, security-only and not mail-enabled.
  • Group writeback via Entra Cloud Sync keeps legacy on-premises systems working while Entra becomes the governing authority.

Worth quoting

“Here's the key correction most admins miss. Source of authority isn't a global toggle, it's per object each group. Each user carries its own little flag defining who commands it.” – Mirko Peters (02:24)

“Why does source of authority define maturity? Because governance scales only when it's unified. The moment ENTRA owns the group, every automation, API and access review engine in the Microsoft ecosystem suddenly obeys a single set of modern rules.” – Mirko Peters (09:17)
