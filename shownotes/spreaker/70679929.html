Many Azure administrators keep collecting certifications yet still end up clicking in the portal when something breaks. This episode is for Azure admins and cloud architects who want to move from operator to architect across seven levels, from scripts and Bicep to Azure Policy, landing zones, Entra ID and AI agent governance. Learn how to design systems where the wrong thing is architecturally impossible and what to do first on Monday morning.

In this episode

  • 00:00 – Azure administration as managing entropy
  • 03:22 – Portal clicking and scripting traps
  • 08:26 – Infrastructure as code and its limits
  • 12:05 – Azure Policy and landing zones
  • 20:07 – Identity as the perimeter and zero trust
  • 31:30 – AI agents, bounded autonomy and observability
  • 63:36 – The 2026 MFA deadlines and career levels
  • 70:27 – Monday morning actions

Key takeaways

  • Azure cannot be managed by clicks and scripts; it has to be governed through declarative infrastructure as code backed by enforced Azure Policy.
  • Entra ID, conditional access and zero trust make identity the real control plane, and every policy exception becomes a vulnerability.
  • AI agents must be governed as identities with bounded autonomy, observability and a continuous governance loop, starting with a measured assessment of the current state.

Worth quoting
