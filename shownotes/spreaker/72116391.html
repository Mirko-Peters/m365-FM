Generative AI ideas now reach production in days, often without a security review. Martin Dimovski explains how developers, data scientists and security teams can protect MLOps pipelines in the Microsoft cloud, from prompt injection and secret leaks to Defender, GitHub Advanced Security and just-in-time access. Ideal for teams that want to ship AI fast without becoming the next data leak headline.

  • 05:56 – MLOps, DevSecOps and secure by design explained
  • 07:41 – Biggest AI security mistakes
  • 12:22 – Prompt injection and data leakage
  • 19:57 – Threat modeling and governance
  • 25:41 – Defender, GitHub Advanced Security and Entra
  • 45:49 – AI security for small companies and careers
  • 53:36 – Rapid fire and final advice

Key takeaways

  • Prompt injection works because language models cannot distinguish developer instructions from user input, so exposed AI applications need extra protection.
  • Threat modeling and secure-by-design reviews at the start of a project are cheaper than fixing security gaps after release.
  • Tools like Microsoft Defender, GitHub Advanced Security and Entra Privileged Identity Management only help when people configure them and security teams work closely with developers.
