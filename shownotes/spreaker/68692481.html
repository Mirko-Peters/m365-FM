Hand-upgrading legacy Java apps is slow, error-prone and leaves CVEs and idle cloud spend in place. This episode is for developers, platform engineers and IT leaders facing Java modernization. It walks through a case where an AI agent assesses, upgrades to Java 21 and migrates to Azure with a full audit trail.

In this episode

  • 00:00 – Why manual Java modernization fails
  • 00:31 – The legacy stack and the modernization mandate
  • 04:14 – Assessment: technical debt with receipts
  • 08:36 – Automated upgrade from Java 8 to Java 21
  • 12:38 – Cloud migration from AWS to Azure
  • 17:09 – Results: time, CVEs, cost and hours
  • 19:33 – Governance, audit trail and transparency

Key takeaways

  • An AI agent can assess a legacy Java app end to end, building a dependency graph with CVE, upgrade-readiness, cloud-readiness and cost findings before touching code.
  • The upgrade to Java 21 runs as an apply-build-test-patch loop with OpenRewrite recipes, BOM alignment, regenerated SBOMs and scanners, producing small reviewable commits.
  • Migration to Azure App Service with Key Vault, managed identity and GitHub Actions approvals cut cost and CVEs together while every change stays traceable in Git.
