Still wiring up Power Fx formulas and manual flows while Power Platform quietly turns AI into a building block? This episode is for makers and architects who want to know what Dataverse prompt columns, form filler, generative pages and Copilot Studio agents actually change. You will learn where each tool fits, where it falls short, and how to start practicing in a sandbox today.

In this episode

  • 00:00 – The AI revolution in Microsoft Power Platform
  • 00:50 – Dataverse prompt columns: data that reasons
  • 05:27 – Form filler: AI-driven data entry
  • 11:23 – Generative pages: AI-generated React UI
  • 17:56 – Copilot Studio agents calling agents
  • 23:38 – Future-proofing your Power Platform skills

Key takeaways

  • Dataverse prompt columns let a table field run a natural-language instruction, replacing brittle formula logic and many supporting flows.
  • Form fill assistance in model-driven apps turns pasted emails, text or screenshots into suggested Dataverse field values that users confirm before saving.
  • Copilot Studio's agents-calling-agents model splits one monolithic bot into a parent agent and focused child agents that are easier to test, debug and version.

Worth quoting

“Instead of building one giant agent that knows everything, you now orchestrate multiple smaller ones that each know a focused slice” – Mirko Peters (18:43)

“Over delegation creates context dead zones where child agents lack the information needed to answer correctly. Solve that by defining clear parameters and passing relevant outputs.” – Mirko Peters (22:41)
