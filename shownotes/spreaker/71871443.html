Attackers don't need to beat your Copilot prompt; they only need to poison the context it retrieves. This episode shows security architects and Microsoft 365 leaders how to put Azure Logic Apps in the path to inspect, score and block malicious payloads before Copilot ever runs.

In this episode

  • 00:00 – Context poisoning is the real Copilot risk
  • 03:04 – Why basic defenses fail in production
  • 05:58 – The Logic App firewall model
  • 09:58 – What the workflow does at runtime
  • 13:18 – Tuning for low noise and business use
  • 16:24 – What changes for leaders and architects

Key takeaways

  • Indirect prompt injection hides instructions in emails, files and form fields that Copilot later retrieves, so the control point cannot sit only at the prompt layer.
  • Azure Logic Apps can act as a policy layer that normalizes, inspects, scores and routes context with regex, Prompt Shields and threat intelligence before the model runs.
  • Tune for low false positives, start with one high-risk workflow and preserve an audit trail so the control earns trust and stays in place.

Worth quoting
