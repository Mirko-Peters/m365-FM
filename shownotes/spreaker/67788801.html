ASP.NET Core developers hear a lot about AI in .NET 10 but rarely what is real and what is opt-in. This episode explains how AI hooks, passkeys, predictive diagnostics, orchestration and self-documenting APIs fit together, and which features are safe to adopt now.

In this episode

  • 00:00 – Introduction: an AI engine inside .NET 10
  • 00:43 – The AI engine hiding in plain sight
  • 04:04 – Security that talks to the AI: WebAuthn and passkeys
  • 08:00 – Diagnostics that predict breakdowns
  • 12:12 – Orchestration: productivity without the guesswork
  • 16:26 – Blazor, APIs and the self-documenting web
  • 19:58 – Takeaway and project audit

Key takeaways

  • .NET 10 lowers the barrier to adding AI by letting AI services plug in through familiar middleware and dependency patterns, but only when you opt in.
  • WebAuthn and passkey events become valuable security signals when routed into the same telemetry pipeline as performance data.
  • Minimal API validation, automatic OpenAPI generation and Blazor's typed components turn APIs into self-documenting contracts that reduce front-end/back-end drift.

Worth quoting
