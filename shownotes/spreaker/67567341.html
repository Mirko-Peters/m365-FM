Empty offices one day, no free desks the next: hybrid work often runs on guesswork. This episode shows IT admins, facilities and HR leaders how Microsoft Places turns scattered on-site decisions into coordinated, data-driven planning inside the Microsoft 365 tools people already use.

In this episode

  • 00:00 – The empty office problem
  • 00:26 – Why hybrid work feels broken
  • 04:11 – The hidden price tag of hybrid chaos
  • 08:27 – Microsoft Places as the missing layer
  • 12:28 – Admin view: deployment without breaking workflows
  • 16:33 – Turning workflows into data insights
  • 21:10 – Hybrid work as a coordination problem

Key takeaways

  • Hybrid work chaos is a coordination problem that wastes real estate budgets, time and employee goodwill, not a flaw of flexibility itself.
  • Microsoft Places adds an orchestration layer inside Outlook and Teams that shows presence trends, events and space availability so people can decide when coming in is worthwhile.
  • Because Places reuses existing Microsoft 365 identity, permissions and MFA and reports only aggregated data, it can be deployed without new infrastructure or surveillance concerns.

Worth quoting

“Hybrid work without coordination is a lot like trying to run an orchestra when every player brought a different sheet of music. Everyone's technically working, but nobody is in rhythm.” – Mirko Peters (02:34)

“The real breakdown is in the absence of intelligent systems that manage those choices in a structured way. Left completely manual, hybrid work becomes chaos by default, not by design.” – Mirko Peters (03:31)
