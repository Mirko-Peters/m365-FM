Prompt-only AI agents hallucinate tools, skip preconditions and declare victory on partial failures. This episode is for architects and builders of agents on Microsoft 365, Microsoft Graph, Azure OpenAI and Copilot Studio. Learn how executors, validated workflow graphs and a pre-execution contract check make agents reliable, secure and auditable.

In this episode

  • 00:00 – The pre-execution contract check
  • 04:33 – Why prompts fail at operations
  • 08:45 – Graph workflows: nodes, edges and state
  • 13:03 – Secure by design with graph validation
  • 17:39 – Microsoft Graph, Azure OpenAI and Copilot Studio
  • 22:46 – Before and after metrics
  • 25:01 – A measurement rig you can run

Key takeaways

  • Let the model propose plans, but let a policy-bound executor run tools with preconditions, idempotency keys and verified post-conditions.
  • Encode workflows as validated graphs with explicit contracts, allow lists, compensations and human checkpoints so agents fail safely.
  • A pre-execution check of capability, permission and feasibility, plus tracing tied to metrics, improves accuracy, latency, cost and auditability.

Worth quoting

“LLM's handle cognition. Executors handle operations. Mixing those is how you get chaos. The model can propose a plan. It cannot guarantee that the email was sent, the file was saved or the permission existed.” – Mirko Peters (05:15)

“If an action can be retried, it needs a key that makes the second attempt a no-op or a consistent override. Timeouts prevent zombie calls.” – Mirko Peters (06:46)
