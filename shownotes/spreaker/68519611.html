Most copilots answer from a single retrieval pass and sound confident while missing data that lives in other systems. This episode shows architects and Microsoft 365 admins how agentic RAG combines planning, specialist agents and verification across SharePoint and Microsoft Fabric. You learn how to build copilots that reason over enterprise data while respecting permissions and audit requirements.

Key takeaways

  • Classic RAG runs one query against one index and cannot plan, verify or reconcile data spread across many systems.
  • Agentic RAG uses a planner, specialist retriever agents and a verifier in an adaptive loop, orchestrated by the Azure AI Agent Service.
  • On-behalf-of authentication, row-level security and Purview labels keep agent retrieval within each user's permissions and fully auditable.

Worth quoting

“Retrieval alone provides information. Agency converts that information into process by introducing planning, specialization and verification as your agent service transforms random data pulls into accountable reasoning chains.” – Mirko Peters (09:30)
