You have dozens of PowerShell scripts that work, but nobody could rebuild the platform behind them in three hours. This episode is for Microsoft 365 and Azure automation engineers who have hit the scripting ceiling. Learn how Bicep turns infrastructure and identity into versioned, auditable code and how to start the transition next Monday.

Key takeaways

  • Script sprawl fails not because PowerShell is bad but because imperative scripts never declare the infrastructure, identities and permissions they depend on.
  • Bicep, now including Microsoft Graph resources, lets you declare Azure infrastructure and Entra ID identity in Git, with modules, what-if previews and pipelines enforcing governance by default.
  • Use Bicep for infrastructure, PowerShell for operations and Graph for data, and choose Terraform only when you genuinely operate across multiple clouds.
