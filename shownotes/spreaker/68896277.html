A single Copilot agent can invent evidence, leak restricted content and drift on stale indexes without anyone noticing. This episode gives architects and security teams a multi-agent reference architecture for Microsoft 365 and Azure OpenAI with a threat model and build steps that make every answer verifiable and auditable.

Key takeaways

  • Single all-purpose agents hallucinate under token pressure and weak retrieval, so split retrieval, reranking, generation and verification into separate roles.
  • Permission-aware retrieval with the user's token, Purview labels as filters and red team and policy agents prevent context leakage through prompts and over-broad indexes.
  • Route every call through Azure API Management with correlation IDs and persisted retrieval sets so a compliance agent can re-enact any answer for audits.

Worth quoting
