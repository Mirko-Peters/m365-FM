Copilot Studio agents inherit your permissions and can quietly pull confidential data through connectors if DLP is not scoped correctly. This episode is for Power Platform and Microsoft 365 admins who want to classify connectors, restrict agent permissions in Entra ID and test and monitor their environments so AI agents stop leaking internal data.

In this episode

  • 00:00 – Copilot Studio agents are leaking data
  • 01:25 – Agents that know too much
  • 04:48 – How data flows through Copilot Studio
  • 08:43 – Building the DLP fortress
  • 13:02 – Entra permissions and the myth of safety
  • 16:50 – Testing and monitoring
  • 20:20 – Agents reflect your governance

Key takeaways

  • Copilot Studio agents run with the delegated permissions of the user, so anything the user can see the agent can retrieve and summarize.
  • Power Platform DLP policies are environment scoped, so every environment hosting agents needs deliberate business, non-business and blocked connector classifications.
  • Red-team agents with forbidden prompts, monitor connector analytics and audit logs, and reclassify connectors regularly to prove the setup holds.

Worth quoting
