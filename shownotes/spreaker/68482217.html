Copilot Studio can now click, type and open apps on a real Windows desktop. This episode is for Power Platform makers and IT security teams who want to automate legacy apps without APIs. See how computer use is set up, how the agent reasons through a Power App, and which governance guardrails keep it from becoming a teenager with root access.

  • 15:08 – Building a responsible agentic workflow
  • 19:49 – Wrap-up: autonomy requires discipline

Key takeaways

  • Computer use in Copilot Studio lets an agent operate a real Windows machine through vision and synthetic mouse and keyboard input, reaching apps that have no API or connector.
  • Setup requires Windows Pro or better, the Power Automate Desktop machine runtime, registration in the Power Automate portal and enabling the machine for computer use.
  • Treat each agent like a new employee: give it a scoped Entra Agent ID with least privilege, test in a sandbox, add human-in-the-loop approvals and monitor it with Purview and Defender.

Worth quoting
