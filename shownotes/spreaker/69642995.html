Every team building AI integrations with custom glue code is quietly creating permissions sprawl, drift and incidents waiting to happen. This episode is for Microsoft architects and developers who want agents that act safely, and explains how the Model Context Protocol, combined with Entra, managed identity and Azure API Management, becomes a governable control plane for tool use.

  • 61:48 – Building a SharePoint and Graph MCP server

Key takeaways

  • MCP is not a plugin system but a host-mediated protocol boundary where identity, scope, audit and failure behavior can be enforced without trusting the model.
  • In Microsoft environments, Entra on-behalf-of keeps tool calls attributable to users, managed identity suits operational workloads, and Azure API Management governs exposure at the edge.
  • Deterministic tool contracts with non-overlapping names, strict schemas, stable outputs, versioning and fail-closed behavior reduce hallucinated integrations and retry storms.
