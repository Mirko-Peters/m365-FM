Picking the wrong Azure managed disk can cost you performance, money or both. This episode walks Azure beginners and VM admins through the five disk types, IOPS and throughput, LRS versus ZRS, encryption, backups and cost tips so they can choose the right disk for each workload.

In this episode

  • 00:46 – What a managed disk is
  • 02:35 – The five disk types
  • 05:53 – IOPS, throughput and latency
  • 07:29 – LRS vs ZRS redundancy
  • 09:06 – OS, data and temporary disks
  • 10:35 – Security and encryption
  • 12:07 – Backups, snapshots and cost

Key takeaways

  • Managed disks remove the need to create and balance storage accounts yourself, because Azure handles placement, replication and limits behind the scenes.
  • Premium SSD v2 and Ultra Disk let you set IOPS and throughput independently of capacity, while Premium SSD and Standard disks scale performance with disk size.
  • Azure bills for provisioned disk size, so right-sizing, deleting unattached disks and choosing LRS for non-critical data are the biggest cost levers.

Worth quoting

“Managed disks abstract all of that away. You don't create a storage account, a container, or a page blob. You just create a disk, pick a size, and a type, and Azure handles the rest.” – Mirko Peters (01:30)

“With older disk types, if you needed more performance, you had to buy a bigger disk. Even if you didn't need the extra space. Premium SSD V2 fixes that, and it's generally less expensive than the original premium SSD for the same performance.” – Mirko Peters (03:37)
