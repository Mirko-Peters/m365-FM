Copilot settings change constantly, and some of the most important ones are barely documented. This episode walks Microsoft 365 admins through web access controls, licensing pitfalls, Edge and Loop gaps and agent governance, with concrete tests to run in your own tenant.

In this episode

  • 00:00 – Copilot is a moving target
  • 00:36 – The hidden web access switch
  • 04:24 – Licensing land mines
  • 08:33 – Copilot in Edge
  • 12:41 – The Loop and DLP puzzle
  • 16:30 – Preparing for Copilot agents
  • 20:26 – Three habits to wrap up

Key takeaways

  • Verify the Copilot web access setting in your own tenant and test what it returns instead of trusting the default.
  • Treat Copilot licenses as a flexible pool that is reviewed regularly and reassigned to users with measurable adoption.
  • Run recurring tests of DLP, sensitivity labels and agent behavior in Edge, Loop and new agent features, and assign a clear owner for Copilot governance.

Worth quoting

“Whether you choose to allow, block or selectively enable web access, make it a conscious choice instead of living with the default.” – Mirko Peters (03:49)
