Many users fear that Copilot is quietly recording everything they do, and they often confuse Copilot Memory with Windows Recall and Copilot Vision. This episode is for end users, admins and compliance teams who need to explain the difference. It walks through what each feature keeps, how consent works and which controls you can use today.

In this episode

  • 00:00 – The spying myth
  • 00:41 – What Copilot Memory is and isn't
  • 03:51 – Windows Recall: automatic screenshots
  • 07:16 – Copilot Vision: real-time and session-only
  • 11:29 – Privacy controls for users and admins
  • 14:33 – Why memory matters for productivity
  • 18:29 – Three tools, three consent models

Key takeaways

  • Copilot Memory only stores what users explicitly ask it to remember, shows a memory updated badge and can be reviewed, edited or switched off.
  • Windows Recall on Copilot+ PCs captures encrypted local screenshots automatically, so enterprises need to assess it separately for compliance.
  • Admins can disable memory for a tenant or groups and audit memory actions through Microsoft Purview eDiscovery.
