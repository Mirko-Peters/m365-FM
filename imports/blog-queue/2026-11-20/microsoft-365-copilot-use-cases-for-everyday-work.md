The most reliable Copilot scenarios are the ones Microsoft documents step by step: drafting and rewriting text in Word, summarizing long email threads in Outlook, building presentations from a prompt or a Word file, analyzing data in Excel and catching up on Teams meetings. This article walks through each with the exact starting point, then covers how to choose scenarios for a team.

A note on sources: Microsoft's published scenario collections by job role were not readable when this article was written. The scenarios below come from the product pages for each app and from one Microsoft Inside Track article, so the list is narrower than a full scenario library.

## Before you start: which Copilot do you have?

The Microsoft Learn overview describes a baseline Copilot Chat experience included with eligible Microsoft 365 licenses, which primarily uses web data. In that baseline, organizational content has to be pasted, uploaded or selected, unless you use content open in Teams or Outlook. The add-on license grounds Copilot in organizational data through Microsoft Graph so files do not need manual uploads. The support pages for Word, Excel and PowerPoint add that Copilot might not be available because of your subscription or your organization's settings. If a button is missing, check the license first.

## Writing and editing in Word

Microsoft Support says Copilot in Word can create a first draft from a simple request, a detailed prompt, an outline, notes or reference files. It can also add a section, paragraph, checklist or table to an existing document, and generate content with citations to referenced sources.

1. Open a blank document or put the cursor where new content should go.
2. Open Copilot in the bottom-right corner and describe topic, audience, tone, format and length.
3. To use a specific source, type **/** and choose the file, if it is available.
4. Select **Generate**.
5. Review the draft, then keep, discard, regenerate or refine it with a follow-up prompt.

Microsoft also states that output may contain errors. Check facts, numbers, citations and names before sharing.

## Email overload in Outlook

For a long thread, open the conversation and select **Summary by Copilot** at the top. The button might say **Summarize** instead. Copilot scans the thread for key points and actions and shows the summary at the top of the email. Numbered citations take you to the matching email, which is the quickest way to verify a point. In new Outlook, if the email has a PDF, PowerPoint or Word attachment, **Summarize a file** is also available. On Mac, iOS and Android the summary defaults to the language of the email. You can switch it to match Outlook's menus, but the change does not persist after a restart.

## Presentations in PowerPoint

Microsoft Support describes creating a presentation from a prompt or from a file. For the prompt route, start a new presentation, open Copilot Chat from the icon at the bottom-right, describe the presentation and answer the clarifying questions about audience, length, template and imagery, or skip them. If your organization uses a Brand Kit, select it under **Select brand**.

For a Word source, Microsoft recommends three habits:

- Use Word Styles so Copilot can split the document into slides.
- Include relevant images, since Copilot tries to use them.
- Start from your organization's template.

Copilot works best with Word documents smaller than 24 MB. Microsoft frames that as a recommendation, not a hard limit.

## Data questions in Excel

The Excel support page lists these actions: generate data from prompts, apply formulas across sheets, summarize data, create charts and PivotTables, highlight, sort and filter, and fetch web information with citations. To use it, select the Copilot icon in the lower-right corner and pick a mode: edit (the default), plan or chat only. Chat only analyzes data and gives insights without changing the workbook, which is the safer choice on a file you do not want touched. Mode support varies by platform. Windows, Mac and web support all three, while Android supports chat only.

## Meetings in Teams

Select **Copilot** in the meeting controls to open a private chat. Microsoft says Copilot summarizes key discussion points, suggests action items and answers questions during or after the meeting. Select **View prompts** for suggestions. Samples from Microsoft include "Where do we disagree on this topic?" and "Create a table with the ideas discussed and their pros and cons." Copilot can be turned on without transcription, but you need live transcription on to prompt Copilot about the meeting or to see its conversation history after the meeting ends. The meeting setup is covered in the separate Copilot in Teams meetings article on this site.

## How to choose scenarios for a team

Microsoft's Inside Track team described its own rollout. It identified priority roles, then built three hero scenarios per role. Each scenario has six steps, and each step has a Copilot prompt. The criteria for choosing roles were enthusiasm for adoption, readiness, the number of people in the role and the fit for repetitive, context-rich or communication-intensive tasks. Focus groups had 10 to 20 participants who were already using Copilot, and the playbook process is designed for implementation across three weeks. The article says adoption and usage increased but reports no metrics, so treat any productivity figure you read elsewhere with care.

A practical way to apply this: pick one role, list the tasks that repeat weekly, and test each task with a short prompt before you write guidance for others.

## Common mistakes

- **Pasting nothing.** With baseline Copilot Chat, organizational content has to be supplied. A prompt about "last week's budget file" will not work without it.
- **Trusting output unchecked.** Microsoft states outputs can contain errors.
- **Starting from a messy Word file.** Without Word Styles, slide structure suffers.
- **Using edit mode on a file you want unchanged.** Use chat only in Excel.
