A good AI-901 plan follows the weights of the skills measured outline. More than half of the exam, 55 to 60 percent, is about building solutions with Microsoft Foundry, so hands-on practice matters more than memorizing definitions. The plan below spreads the outline over four weeks. It is a suggested schedule, not an official one. The outline and exam facts come from Microsoft Learn, and exam questions are not covered here.

## What the exam covers

Microsoft Learn dates the current skills measured as of April 15, 2026, and lists a passing score of 700. The audience profile describes someone at the beginning of a career in AI solution development, with conceptual knowledge of AI solutions in Azure, foundational technical skills, Python syntax and familiarity with Azure resources.

| Domain | Weight |
|---|---|
| Identify AI concepts and capabilities | 40-45% |
| Implement AI solutions by using Microsoft Foundry | 55-60% |

Learn says most questions cover generally available features, and the exam may include preview features if they are commonly used. Familiarity with REST APIs, SDKs and CLIs is expected.

## Domain 1: Identify AI concepts and capabilities

Three areas, according to the outline:

- **Responsible AI principles:** fairness, reliability and safety, privacy and security, inclusiveness, transparency and accountability.
- **AI model components and configurations:** how generative AI models work, choosing a model by capability, and model deployment options and configuration parameters.
- **AI workloads:** scenarios for generative and agentic AI, text analysis, speech, computer vision and information extraction. The outline names techniques such as keyword extraction, entity detection, sentiment analysis and summarization.

## Domain 2: Implement AI solutions by using Foundry

Four areas:

- **Generative AI apps and agents:** write effective system and user prompts, deploy a model and interact with it in the Foundry portal, build a lightweight chat client with the Foundry SDK, and create and test a single-agent solution and a client for it.
- **Text and speech:** build a lightweight text analysis app, respond to spoken prompts with a deployed multimodal model, and use Azure Speech in Foundry Tools.
- **Computer vision and image generation:** interpret visual input with a multimodal model, create visual outputs with generative models and build a lightweight vision app.
- **Information extraction:** extract information from documents, forms, images, audio and video with Azure Content Understanding in Foundry Tools, and build a lightweight app with it.

## A four-week plan

**Week 1: responsible AI and model basics.** Read the six responsible AI principles and write one sentence on each in your own words. Study how generative models work and what deployment options and configuration parameters exist. This covers the first two Domain 1 areas.

**Week 2: workloads and the Foundry portal.** Cover the AI workloads list. Then deploy a model in the Foundry portal and practice system and user prompts. Notice how changing parameters changes answers.

**Week 3: code and agents.** Build a small chat client with the Foundry SDK. Create a single agent in the portal, test it and write a client for it. Keep your Python practice light but regular, since the exam expects Python syntax knowledge.

**Week 4: speech, vision and extraction, then review.** Build one small app each for text analysis, speech, vision and information extraction. Then take the free practice assessment, list weak areas and revisit them.

## A self-check list from the outline

Before you book the exam, check that you can do each of these without notes:

- Name the six responsible AI principles and give one consideration for each.
- Explain what a deployment option or configuration parameter changes in a model.
- Deploy a model in the Foundry portal and compare two prompts.
- Write a short script that sends a prompt through the Foundry SDK and prints the answer.
- Say which Foundry tool you would use for speech, for vision and for extracting data from forms.
- Describe how a single agent differs from a plain model call.

This list restates the outline in practical form. It is not an official checklist.

## Official resources

- The instructor-led course **Introduction to AI in Azure (AI-901T00)**. The study guide also mentions self-paced learning paths and modules, and the exam page links two Learn items (AI technical concepts, and get started with AI apps and agents) that I did not read.
- The free **practice assessment** on AI Skills Navigator. You must sign in to launch it.
- The skills measured page itself. Learn says two versions of the objectives may exist depending on test date, and that localized versions follow English by about eight weeks.

## Exam logistics to check yourself

The exam details page lists the languages: English, Arabic (Saudi Arabia), Chinese (Simplified and Traditional), French, German, Indonesian, Italian, Japanese, Korean, Portuguese (Brazil), Russian and Spanish. If your language is missing, the study guide says you can request an additional 30 minutes. It does not state the price, duration, number of questions or question format. The page does not say how AI-901 relates to AI-900 either, so treat it as its own exam with a Foundry focus. It is listed as part of the Microsoft Certified: Azure AI Fundamentals certification.

## Typical mistakes

- Spending most of the time on definitions, when more than half of the exam is implementation with Foundry.
- Practicing on old portal screens. Use the current Foundry portal.
- Ignoring Python and SDK basics because the exam is called fundamentals.
- Studying from an outline version that does not match your test date.
