Several useful Copilot features sit one click away from the chat box and still go unused. This article covers five that Microsoft documents: Notebooks, Pages, scheduled tasks, memory with custom instructions, and temporary chats. For each one, you get the steps, the limits and the license note from the source pages. Microsoft says the new Copilot Home experience is still rolling out, so menus on your screen may differ.

## 1. Copilot Notebooks: a workspace that uses only your sources

Microsoft Support describes a notebook as an AI-powered workspace where you gather your content so Copilot gives more relevant, context-aware responses. Copilot uses only the content you add.

**What you can add:** Word, PowerPoint, Excel and PDF files, Copilot pages, Loop files, OneNote pages and notebooks, and specific web URLs.

**Workflow in the article:** create a notebook, add files, pages and references, ask questions, and review answers based only on those references.

**Limits worth knowing:**

- Copilot uses up to 300 files for grounding. From a shared location such as a SharePoint folder, it selects the 300 most relevant files you can access. To guarantee a file is included, add it directly.
- Notebooks do not generate images or data visualizations.
- Deleting a notebook is permanent. A recycle bin is described as in development.
- Audio overviews work in English, Spanish, Japanese, French, German, Portuguese, Italian and Chinese.

**License:** available to users with a Microsoft Copilot or Copilot Chat license. Accounts need a SharePoint or OneDrive service plan to create notebooks.

## 2. Copilot Pages: turn an answer into a working document

Pages is a workspace for content that changes over time, such as briefs, vendor comparisons and meeting notes. Chat and the page open side by side, so you can ask Copilot to update the page or answer questions from its content.

**From a response:**

1. Select the ellipses below a Copilot Chat response.
2. Select **Edit in Pages**.
3. Add the response to an existing page or a new one.

**From a new chat:** select the plus button left of the prompt box, hover over **More**, select **Draft page or code**, describe the content and send.

**License:** with a work or school account, Pages needs SharePoint or OneDrive storage and works without a Microsoft 365 Copilot license. Your admin may control which AI tools and data sources you can use in Pages. Pages stay until you delete them, and deletion of a page is permanent according to the Notebooks article.

## 3. Scheduled tasks: run a prompt on a timer

A prompt you use often can run automatically at a set time and frequency. Microsoft Support says scheduled prompts are now called **Scheduled tasks** and are managed in Task Hub.

**Create one:** in Copilot Chat, hover over a prompt, select **Schedule this**, choose when and how often it runs, and select **Save**. You can also create tasks from Task Hub.

**Where results go:** the response appears in the **Chats** section on the left. Scheduled tasks are bold and have an icon.

**Manage:** select the Task icon in the left sidebar header, open the **Scheduled** tab, and use **Run now**, **Edit Schedule**, **Pause** or **Delete**.

**Requirements:** a Microsoft Copilot license. The initial release works in Copilot Chat, Microsoft Copilot on the web and the desktop app. Teams, Outlook and mobile are not included. The page states no limit on the number of tasks, and it does not describe admin controls.

## 4. Memory and custom instructions: make answers fit you

Microsoft Support explains that Copilot can remember details from Copilot Chat conversations, such as communication style or recurring tasks. Personalization can draw on four things: saved memories, chat history, work insights from your Microsoft 365 content, and custom instructions that you write in Copilot settings.

**Control it:**

- Ask Copilot "What do you know about me" to see what it knows.
- Ask it to forget a detail to stop it using a work insight.
- Delete a saved memory in **Chat settings**. The page adds that to fully remove what Copilot learned, you also need to turn off the **Chat history** toggle.
- Turn off the **Chat history** toggle in **Chat settings** to delete inferences from chat history. If you turn it back on within 30 days, the deleted memories return.

Work insights need a work or school account, and availability depends on your organization's Copilot plan. The page gives no path for switching memory itself on or off and does not describe editing single memories.

## 5. Temporary chats: nothing saved

Select **Start a new temporary chat** at the top right of the Copilot Chat page. These chats do not use or store personal information and do not appear in your history. Retention policies of your organization may still keep temporary chat data, and admins may be able to access it during the retention period.

## Which one to try first (my own suggestion)

| If you want to | Try |
|---|---|
| Ask questions across a fixed set of files | Notebooks |
| Keep refining a draft with Copilot | Pages |
| Get the same summary every morning | Scheduled tasks |
| Stop repeating your preferences | Memory and custom instructions |
| Ask something without leaving a trace in your history | Temporary chat |

## Typical mistakes (own checklist based on the limits above)

- Adding too many files to a notebook and assuming all are used. The limit is 300.
- Expecting scheduled tasks to arrive in Outlook or Teams. The initial release does not include them.
- Deleting a notebook or page without a copy. Deletion is permanent.
- Treating a temporary chat as invisible to IT. Retention policies can apply.
