The Microsoft 365 Administrator exam MS-102 retires on November 30, 2026, at 11:59 PM Central Standard Time, according to a warning at the top of the Microsoft Learn study guide, Study guide for Exam MS-102: Microsoft 365 Administrator. By the date of this article that day has passed, so check the certification page for the current status of the exam. The page names no replacement exam. This guide reproduces the skills measured outline from the study guide, as of April 28, 2026, and contains no exam questions.

## Retirement

The warning says: this exam will retire on November 30, 2026, at 11:59 PM Central Standard Time. Its Learn more link points to a Tech Community blog post, the Microsoft Credentials roundup of June 2026, which I did not read. The study guide does not say what happens to the Microsoft 365 Certified Administrator Expert certification after the retirement, and it does not name a replacement. Check the blog post and the certification page before you plan.

## Audience and background

The page says the exam is for administrators who deploy and manage Microsoft 365 and perform tenant-level implementation and administration of cloud and hybrid environments. A Microsoft 365 administrator is the integrating hub for all workloads and works with architects and other administrators.

Candidates should have functional experience with all Microsoft 365 workloads and Microsoft Entra ID, and should have administered at least one of them. They should have working knowledge of networking, Active Directory Domain Services, DNS and PowerShell.

For the Microsoft 365 Certified: Administrator Expert certification, the page says you must earn at least one of these: Microsoft 365 Certified: Endpoint Administrator Associate, Microsoft 365 Certified: Teams Administrator Associate, or Microsoft Certified: Identity and Access Administrator Associate.

## Domain weights

| Domain | Weight |
|---|---|
| Deploy and manage a Microsoft 365 tenant | 25 to 30% |
| Implement and manage Microsoft Entra identity and access | 25 to 30% |
| Manage security and threats by using Microsoft Defender XDR | 30 to 35% |
| Manage compliance by using Microsoft Purview | 10 to 15% |

## Deploy and manage a Microsoft 365 tenant

- **Tenant:** create a tenant, manage domains, configure org settings (Security and privacy, Organization profile), monitor Service Health with notifications, configure and review Network connectivity insights, configure and monitor software updates in the admin center, monitor adoption and usage, and configure and manage Microsoft 365 Backup.
- **Users and groups:** manage users in Microsoft Entra ID including external users, manage contacts, manage groups including Microsoft 365 Groups and shared mailboxes, manage licenses including group-based licensing, and perform bulk user management with Microsoft Graph PowerShell and Microsoft Entra PowerShell.
- **Roles and role groups:** manage roles in Microsoft 365 and Microsoft Entra ID, manage permissions for Defender XDR, Purview and other workloads, manage delegation with administrative units, and manage Entra roles in Privileged Identity Management.

## Implement and manage Microsoft Entra identity and access

- **Identity synchronization:** prepare for synchronization including IdFix, implement Microsoft Entra Connect Sync or Cloud Sync, monitor with Connect Health, and troubleshoot synchronization.
- **Authentication:** manage authentication methods, self-service password reset and Microsoft Entra Password Protection, and investigate authentication issues.
- **Secure access:** plan for identity protection and manage Microsoft Entra Identity Protection, plan and manage Conditional Access policies, and manage multifactor authentication by using Conditional Access.

## Manage security and threats by using Microsoft Defender XDR

- **Reports and alerts:** respond to threats by using Security Exposure Management including Microsoft Secure Score, handle incidents and alerts including advanced hunting, review Defender XDR reports, and respond to threats identified by Defender Threat Intelligence.
- **Defender for Office 365:** implement threat policies and rules, configure alert policies, investigate and respond to email and collaboration threats, manage attack simulations, and manage restricted entities.
- **Defender for Endpoint:** onboard devices, configure endpoint settings, and respond to vulnerabilities in the Defender Vulnerability Management dashboard.
- **Defender for Cloud Apps:** configure the app connector for Microsoft 365 and policies including alerts, interpret the activity log, and configure and review Cloud App Discovery.

## Manage compliance by using Microsoft Purview

- **Information protection and data lifecycle:** manage sensitive information types with keywords or regular expressions, retention labels and policies, sensitivity labels and policies, and monitor label usage with Content explorer, Activity explorer and label reports.
- **Data loss prevention:** configure DLP policies for Exchange Online, SharePoint Online, OneDrive, Teams, Power BI and Microsoft 365 Copilot, configure Endpoint DLP, and respond to DLP alerts, events and reports.

## Passing score, renewal and changes

A score of 700 or greater is required to pass. Associate, expert and specialty certifications expire annually, and you can renew by passing a free online assessment on Microsoft Learn. The change log from the prior version marks several areas as Minor changes, among them users and groups, roles and role groups, secure access and DLP. The English exam is updated first and localized versions follow about eight weeks later, and Learn says you can request an extra 30 minutes if your language is not available. Most questions cover generally available features, and preview features may appear if they are commonly used.

## Suggestion: how to use the study guide

This section is a practical suggestion and not a Microsoft statement.

1. Check the certification page first for whether MS-102 can still be scheduled, since the retirement date has passed.
2. Weight your study by the domain percentages. Defender XDR is the largest domain.
3. Practice the administration tasks in a test tenant, because most bullets start with implement, manage or configure.
4. Use the free practice assessment that the page links.

## Not covered

The page I read does not describe the following:

- A replacement exam.
- What happens to the Administrator Expert certification after retirement.
- Exam fee, number of questions and duration.
- The list of available exam languages.
- The objectives of the previous version.
