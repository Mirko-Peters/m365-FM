OneDrive is Microsoft's cloud storage. You save files to it once, and you can open them from a browser, a PC or a phone. This guide covers the basics in the order most people need them: signing in, syncing, saving space, sharing, restoring files and watching your storage. Menu names follow Microsoft's documentation and can differ slightly by app version.

## What OneDrive is

Microsoft Support describes OneDrive as a service to store, protect and share files and reach them from multiple devices. Files are private until you share them.

You will meet two kinds of account:

- A **personal Microsoft account**, managed by you. Microsoft lists 5 GB of free storage for an account with no subscription.
- A **work or school account**, managed by your organization. Microsoft Support says Microsoft 365 users get at least 1 TB depending on the plan, and administrators control what is allowed.

The two cannot be linked. Which one you use decides the storage, the rules and the recovery period, so check which account is signed in before you troubleshoot.

## Sign in

- **Web:** go to onedrive.com and sign in.
- **Windows:** OneDrive is preinstalled on Windows 11. Select the OneDrive cloud icon in the taskbar and sign in. On other versions, download it from Microsoft first.
- **Mac:** download OneDrive, select the cloud icon in the menu bar and sign in.
- **Phone or tablet:** install the OneDrive app and sign in.

When both account types are signed in on a PC, File Explorer shows the personal files under **OneDrive - Personal** and the work or school files under **OneDrive - [Company name]**.

## Set up sync on Windows

Microsoft's setup steps for Windows are:

1. Open OneDrive and sign in with your personal or your work or school account.
2. On the **This is your OneDrive folder** screen, keep the default location or choose another. Microsoft says this is the best moment to change it.
3. On the **All your files, ready and on-demand** screen, review the file status markers and select **Next**.
4. After the first sync, choose which OneDrive folders sync to the PC, turn on backup for Desktop, Documents, Music, Pictures and Videos, or add another account.

Your files then appear in the OneDrive folder in File Explorer. Microsoft says changes made in either place appear in the other.

## Upload on the web

On onedrive.com use **Create or upload** to make new files and folders, or to upload or drag in existing ones. This works on any computer without installing anything.

## Files On-Demand: save disk space

Files On-Demand lets File Explorer list all your OneDrive files without storing them all on the PC. Microsoft describes three markers:

| Marker | Meaning |
|---|---|
| Blue cloud | Online-only. Uses no disk space and downloads when you open it. It cannot be opened offline. |
| Green check | Locally available. It was downloaded when you opened it and works offline. |
| Solid green circle with a white check | Always available. It is downloaded and stays offline-ready. |

Right-click a file or folder and choose **Always keep on this device** to keep it offline, or **Free up space** to make it online-only again.

If the feature is off, select the OneDrive cloud icon, then the Help and Settings icon, then **Settings**. Open the **Sync and back up** tab, expand **Advanced settings** and turn on **Files On-Demand**. Microsoft lists Windows 10 version 1709 or later, or Windows Server 2019, as the requirement. OneDrive build 23.066 or later enables it by default.

## Share a file or folder

1. Select a file or folder and select **Share**.
2. Under **Add people**, enter names, groups or email addresses.
3. Choose a permission, such as **Can edit** or **Can view**.
4. Add a message if you like and select **Share**.

For a broader audience, open **Share**, then the link settings, choose who the link works for and the permission, then select **Copy link**. The option **Anyone** appears only if your organization allows it. Share with named people when the content is sensitive.

## Restore deleted files and earlier versions

1. Go to onedrive.com and select **Recycle bin**.
2. Select the file and then **Restore**.

Microsoft Support says personal accounts can restore items deleted in the last 30 days. Work or school accounts can restore items deleted in the last 93 days, unless the administrator changed the retention setting. Items deleted from the Recycle bin cannot be restored, and you can only restore items from your own OneDrive.

To go back to an earlier edit, open **Version history** on the file. Microsoft 365 subscribers can also restore a whole OneDrive to a point within the last 30 days.

## Know your storage limit

Microsoft lists these personal storage amounts: 5 GB free, 100 GB with Microsoft 365 Basic and 1 TB with Microsoft 365 Personal. Family, Premium and Pro plans have their own amounts. The quota page says that starting October 8, 2026, new Family and Premium subscriptions include 2 TB of shared storage and new Pro subscriptions include 5 TB, so read the quota page for your plan.

Going over the limit has consequences. You cannot upload, edit or sync new files, and existing files become read-only. After three months the account is frozen, and after six months Microsoft might delete the OneDrive and its files permanently.

## Personal Vault in one paragraph

Personal Vault is a protected area for sensitive files in a personal account. Microsoft says it needs two-step verification each time you open it. The web vault locks after 20 minutes of inactivity. Without a Microsoft 365 Family or Personal plan you can add only three files. The page does not mention work or school accounts.

## Common beginner mistakes

- **Deleting a synced file.** Microsoft's quick start says deleting a synced file also deletes it from OneDrive and your other devices. Use the Recycle bin if this happens.
- **Mixing up accounts.** A file saved under the personal account is not in your work OneDrive.
- **Ignoring sync problems.** Microsoft Support has separate articles for sync states such as Processing changes and Paused. Check them before you assume a file is missing.
- **Sharing with Anyone links by default.** Choose specific people when you can.
