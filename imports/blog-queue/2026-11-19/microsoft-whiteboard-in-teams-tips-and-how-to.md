To use Microsoft Whiteboard in a Teams meeting, select **Share** in the meeting's share tray, choose **Microsoft Whiteboard** and pick an existing board or start a new one. Everyone in the meeting can view and edit the board at the same time. No screen share is needed. This article covers the steps, what happens after the meeting, and the tips Microsoft lists for better collaboration.

## Share a whiteboard in a meeting

Microsoft Support gives these steps:

1. In the meeting's share tray, select the **Share** icon.
2. In the Whiteboard section, select **Microsoft Whiteboard**.
3. In the board picker, select an existing board from the list or start a new one.

If a board is already linked to the meeting, Teams shares that board by default. To share a different board, select the **Home** icon in the top left, return to the board picker and choose another one. On Surface Hub and Microsoft Teams Rooms devices, which mainly use resource accounts, the default is a new board or the board already linked to the meeting.

The Whiteboard features in a Teams meeting are the same as in the Windows and web versions, according to Microsoft. The page links to guides for text, notes and note grids, draw and ink, Ruler and Enhance Shapes, shapes and reactions, pictures and documents, and templates.

## Prepare a board before the meeting

You can choose an existing whiteboard when you share, so a board can be prepared ahead of time or reused across meetings. That is useful for a recurring workshop or a project review. Microsoft's summary describes three benefits: create or open a board without switching apps, real-time collaboration from any device, and reuse across meetings.

## What happens after the meeting

Microsoft Support says the whiteboard is available to participants from your organization after the meeting ends. Open the meeting chat and look for the tab labeled **Whiteboard**. Two limits apply:

- Participants from outside your organization can't access the whiteboard after the meeting ends.
- A whiteboard shared in a recorded meeting is not part of the recording. If you need the content, save it or export it before you close the board. The pages I read don't describe the export steps.

The pages also don't state where the board file is stored or who owns it, so ask your admin if retention matters for your team.

## External participants

Microsoft Support says collaboration with people outside your organization works during a Teams meeting, as long as the administrator has enabled the correct settings. It refers admins to the article on managing sharing for Microsoft Whiteboard, which I did not read, so I can't name the exact settings. If a guest can't see the board, the admin settings are the first thing to check.

## Tips Microsoft lists

### Start from a template

When you don't know how to begin, open a ready-made, editable layout. Microsoft names brainstorming, lesson plans, compare and contrast, and two truths and a lie as examples.

### Lock the board when you present

In a Teams meeting or channel, turn off **Other participants can edit** in the **Settings** menu to make the board read-only. The setting stays on that board after the meeting. It works only if you started the whiteboard in the Teams meeting or channel.

### Use reactions to vote

Reactions let people respond to others and vote on ideas, which is quicker than typing comments.

### Use the ink tools

- Ink shape recognition cleans up shapes you draw.
- The arrow pen draws arrows in colors you choose.
- Holding Shift while inking produces straight lines.

### Use keyboard shortcuts

| Action | Shortcut |
|---|---|
| Draw mode | Alt + W (or Alt + W + 1) |
| Pen 2 | Alt + W + 2 |
| Pen 3 | Alt + W + 3 |
| Highlighter | Alt + H |
| Erase | Alt + X |
| Arrow mode | Alt + A |
| Double arrow | Alt + Shift + A |
| Beautify | Alt + B |

### Use right-click

Right-click the board to add a sticky note or text box and move it. Object snapping and alignment guides line content up. Right-click an object to bring it to the front or send it to the back.

## A simple workshop flow

1. Before the meeting, create the board from a template and add the agenda items.
2. Start the meeting and share the board from the Whiteboard section.
3. Ask people to add sticky notes, then use reactions to vote.
4. Lock the board with **Other participants can edit** off when you move to the decision.
5. After the meeting, send the follow-ups from the meeting chat, where the board stays for your organization.

This flow is a suggestion built from the documented features. Microsoft doesn't publish a standard workshop recipe.

## Common mistakes

- Expecting external guests to open the board after the meeting.
- Assuming the board is in the meeting recording.
- Turning off editing for a board that was not started in the meeting or channel, where the setting doesn't apply.
- Starting a new board by accident when a prepared one exists. Use the board picker.
