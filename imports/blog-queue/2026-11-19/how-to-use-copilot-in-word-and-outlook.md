Copilot works in Word and Outlook through a chat pane and a few buttons. In Word you describe what you want and get a draft, a rewrite or a summary. In Outlook you can summarize an email thread and draft a message from a prompt. All of it needs a license and an app version that supports it, and all of it needs your review. This article covers the buttons Microsoft documents and the limits stated on those pages.

## What you need

Microsoft Support says Copilot in Word needs an eligible Microsoft 365 subscription and/or a Copilot license. It is supported in Word for Microsoft 365, Word for Mac and Word for iPad. Availability depends on your subscription, license, organization settings and platform, and your organization may not include or enable Copilot features. If you can't access Copilot in Outlook, Microsoft says to check with your IT admin. The Outlook draft page covers Outlook for Microsoft 365 on Windows and Mac, new Outlook for Windows, and Outlook for Android and iOS.

If the button is missing, see Microsoft's note that Copilot sits in the Copilot Dynamic Action Button in a corner of the document.

## Write a draft in Word

1. Open a blank document or put the cursor where you want new content.
2. Select the **Copilot Dynamic Action Button**. The Copilot pane opens.
3. Describe what you want: the topic, audience, tone, format and length.
4. To use a source, type **/** and choose the file, email or meeting.
5. Select **Generate**.
6. Keep, discard, regenerate or refine the draft with a follow-up prompt.

## Rewrite text in Word

Microsoft Support lists rewriting selected text as a Copilot capability. A Microsoft Learn training module shows an older flow:

1. Select the text.
2. Select **Edit Copilot** in the context menu, then **Auto Rewrite**.
3. Use the arrows to browse alternative versions.
4. Select **Replace**, **Insert below** to keep both versions, or **Regenerate** for new suggestions.

To steer the result, type a prompt, for example: *Rewrite this paragraph to make it more formal and emphasize the importance of the project timeline.* The training module has no separate Tone or Concise buttons, so ask for tone or length in the prompt. Menu names may differ in your version of Word.

## Summarize a Word document

Open the Copilot pane and ask for a summary, key takeaways, open questions or action items. A sample prompt from Microsoft Learn is: *Summarize this document. Include key points and action items in a table.* The pages read for this article do not describe other summary buttons in Word.

## Summarize an email thread in Outlook

1. Open the conversation in classic or new Outlook.
2. Select **Summary by Copilot** at the top of the thread. It may read **Summarize**.
3. Read the summary at the top of the email. Select a numbered citation to jump to the matching message.
4. In new Outlook, for a PDF, PowerPoint or Word attachment, select **Summarize a file**.

On Mac, iOS and Android, summaries default to the language of the email. You can change the language, but the change doesn't persist after you restart Outlook. The page states no limits for thread length, file size or supported summary languages.

## Draft an email in Outlook

1. Select **Home** > **New mail**.
2. Select the Copilot icon in the toolbar and then **Draft**. If it isn't there, select **Draft with Copilot** in the message area.
3. Type a prompt or edit a suggested one.
4. Select **Generate**.
5. Change the length or tone from a dropdown, rerun the prompt, or enter a new one.
6. Select **Keep it**, edit and send.

In the message area you can also select **Help me write** or **Help me reply** to work in Chat. To change only part of a message, select the text, select the Copilot button and choose an option or type a request. In new Outlook and on the web, plain text messages aren't supported, so go to **Settings** > **Mail** > **Compose** and select **HTML**. Microsoft also notes that if the generated output has a higher sensitivity level than your draft, the draft's sensitivity level may change.

## Prompts that work

Microsoft's own advice for drafting is to give topic, audience, tone, format and length. These examples follow that pattern and are suggestions, not Microsoft templates:

- Word: *Draft a one-page project update for the steering group. Neutral tone. Three sections: progress, risks, next steps.*
- Word: *Make the selected paragraph shorter and keep the dates.*
- Outlook: *Reply to this thread, confirm Thursday and ask for the final numbers. Friendly and brief.*

## Limits and safe use

- Microsoft Support says Copilot in Word can also use web information when available.
- It supports fewer languages than Word itself.
- Model selection in Word depends on your subscription. Others can choose Auto, Instant or Think deeper.
- Copilot applies the proper sensitivity label to protect the document.
- Review the output. Microsoft says to check facts, numbers, citations, names and policy statements before sharing.

## Common mistakes

- Looking for the old Copilot button instead of the Dynamic Action Button.
- Using plain text in Outlook and getting no Draft with Copilot.
- Accepting a rewrite with **Replace** without comparing it to the original. **Insert below** keeps both.
- Sharing a summary without checking the citations.
