SC-900 is Microsoft's fundamentals exam for security, compliance and identity. This article summarizes the skills measured outline from the Microsoft Learn study guide, dated October 21, 2026, and turns the weightings into a study plan. It contains no exam questions.

## Exam facts from the study guide

- Title: Exam SC-900: Microsoft Security, Compliance, and Identity Fundamentals.
- Passing score: 700 or greater.
- Languages: not listed on the page. It refers to the Schedule Exam section of the exam details page. Localized versions are typically updated about eight weeks after the English version, and if the exam isn't available in your language you can request an additional 30 minutes.
- Retirement: the page does not say.

## Domain 1: security, compliance and identity concepts (10 to 15%)

- Security and compliance: shared responsibility model, defense-in-depth, Zero Trust, encryption and hashing, governance, risk and compliance concepts.
- Identity: identity as the primary security perimeter, authentication, authorization, identity providers, directory services and Active Directory, federation.

## Domain 2: Microsoft Entra capabilities (25 to 30%)

- Microsoft Entra ID and identity types, including workload identities and hybrid identity.
- Authentication: methods, multifactor authentication, password protection and management.
- Access management: Conditional Access, Entra roles and role-based access control.
- Identity protection and governance: ID Governance, access reviews, Privileged Identity Management, ID Protection.

## Domain 3: Microsoft security solutions (35 to 40%)

- Core Azure infrastructure security: DDoS Protection, Firewall, Web Application Firewall, network segmentation with virtual networks, network security groups, Bastion and Key Vault.
- Security management in Azure: Defender for Cloud, cloud security posture management, security policies, standards and recommendations, cloud workload protection.
- Microsoft Sentinel: SIEM and SOAR concepts, threat detection and mitigation.
- Microsoft Defender XDR: its services, Defender for Office 365, Defender for Endpoint, Defender for Cloud Apps, Defender for Identity, Defender Vulnerability Management, Microsoft Threat Intelligence and the Defender portal.

## Domain 4: Microsoft compliance solutions (20 to 25%)

- Service Trust Portal and Microsoft privacy principles.
- Compliance management: the Microsoft Purview portal, Compliance Manager and compliance score.
- Information protection and data lifecycle: data classification, content explorer and activity explorer, sensitivity labels and policies, data loss prevention, records management, retention policies, labels and label policies.
- Insider risk management, eDiscovery solutions and audit solutions.

## Study plan by weight

| Priority | Domain | Weight |
| --- | --- | --- |
| 1 | Microsoft security solutions | 35 to 40% |
| 2 | Microsoft Entra capabilities | 25 to 30% |
| 3 | Microsoft compliance solutions | 20 to 25% |
| 4 | Security, compliance and identity concepts | 10 to 15% |

The weightings are ranges, so the real share on any one exam varies. Use them to decide how much time to give each area, not as a promise of question counts.

### A four-week outline

1. **Week 1: concepts and Entra.** Start with the shared responsibility model and Zero Trust, then work through Entra ID, MFA and Conditional Access.
2. **Week 2: Entra governance, then security.** Cover PIM, access reviews and ID Protection, then the Azure infrastructure security services.
3. **Week 3: Defender and Sentinel.** Learn what each Defender product protects, and the SIEM and SOAR concepts.
4. **Week 4: Purview and review.** Cover labels, DLP, retention, insider risk, eDiscovery and audit, then revisit weak spots.

This outline is a suggestion based on the weights, not a Microsoft recommendation.

## How to read the outline

Each domain header in the study guide lists the area names and then the specific topics under them. A few observations from the wording:

- Domain 2 and domain 3 both name Microsoft Entra products and Azure security products, so keep the line clear between identity services and workload or network protection services.
- Domain 3 names Microsoft Defender XDR as a family. The outline lists seven items under it, from Defender for Office 365 to the Microsoft Defender portal, so know what each one protects.
- Domain 4 groups Purview capabilities in three clusters: compliance management, information protection with data lifecycle, and insider risk with eDiscovery and audit.
- Domain 1 is the smallest, but its terms, such as Zero Trust and defense-in-depth, show up as vocabulary throughout the other domains.

## Tips

- Learn names for products carefully. The outline uses current names such as Microsoft Entra ID and Microsoft Defender XDR.
- Compare similar services by purpose. For instance, ask what problem each Defender product solves.
- Check the study guide page for updates close to your exam date, because the skills measured document is revised.

## What the page does not tell you

The page does not publish the number of questions, exam duration or price in the part I read, and it does not list available languages. Use the exam details page for those.
