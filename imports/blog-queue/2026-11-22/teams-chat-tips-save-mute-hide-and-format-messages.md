Teams has small chat features that save a lot of scrolling. You can save a message and come back to it from a **Saved** list, mute a noisy chat, hide one you do not need, mark a chat as unread so it stays on your radar, and format text with the toolbar or Markdown. This guide lists the steps and menu labels from Microsoft Support, and says where the documentation stops.

## Save a message and find it again

1. Hover over the chat message or channel post.
2. Select **More options** (the ellipsis).
3. Select **Save this message**.

A **Saved** section now appears at the top of your chats and channels list. Under **Saved**, select **chats** or **channels** to filter. Selecting an item opens the conversation in a new pane, so you see the message in context.

To remove it, hover over the item in **Saved**, select **More options** and then **Unsave this message**. You can also unsave from the original chat or channel.

Things that surprise people:

- If you have nothing saved, the **Saved** section is not shown.
- If the author edits a saved message, your saved copy shows the edit.
- If the author deletes it, the title stays in **Saved** with a note that the author deleted it. You can still open the conversation.

The Microsoft Support article does not cover keyboard shortcuts or the mobile steps for saving. It links to a general mobile guide instead.

## Mute a chat

1. Open the chat and point to it to reveal **More options**.
2. Select **Mute**.
3. To undo it, select **More options** > **Unmute**.

What muting does, according to Microsoft Support:

- You stay in the conversation but get no notifications from it.
- You still get notifications for **@mentions**.
- Unread messages show in bold but do not add to the chat badge count.
- Muted chats move to a **Muted** section at the bottom of the chat list. Chats already in a custom section stay there.
- A mute symbol appears next to the participants' names.

To send muted chats back to your recent list, turn off the **Muted** section in **Settings** > **Chat and channels**. The article labels that setting "Show meeting chats in their own section", so read the label before you change it.

## Hide a chat

1. Open the chat and reveal **More options**.
2. Select **Hide**.

The chat and its history stay hidden until someone posts a new message. As a shortcut, type **/hide** in the compose box and press Enter.

To bring it back, type the person's name in the Teams **Search** box and select them. The hidden chat's name appears in italics. Select **More options** > **Unhide**. If it does not show, select **Filter**, find the chat and use **More options** > **Unhide**. **Show hidden chat history** displays the conversation.

## Follow up: mark as unread and use Favorites

Microsoft Support describes no dedicated follow-up or reminder feature for chats. Two documented options do the same job in practice.

**Mark as unread.** Open the chat, reveal **More options** and select **Mark as unread**. The chat appears unread the next time you open it, which keeps it visible in your list.

**Favorites.** Drag a chat into the **Favorites** list, or hover over it and select **More options** > **Move to** > **Favorites**. You choose the order. To remove it, select **More options** > **Remove from section**.

The article does not state a limit on how many chats you can add to Favorites.

## Format messages

Select **Show Formatting options** in the compose box to open the expanded view. Select text and choose **B** for bold, **I** for italic or **U** for underline. Highlighting, font size, lists and further options sit under **More options**. Teams underlines misspelled words in red, and you can right-click a word for suggestions. A separate spelling and grammar check is not available except in a Wiki tab.

You can also type Markdown-style syntax:

| Result | Type |
|---|---|
| Bold | `**bold text**` |
| Italic | `_italic text_` |
| Strikethrough | `~strikethrough~` |
| Numbered list | `1. Item one` |
| Bullet list | `- Item one` or `* Item one` |
| Link | `[Text](URL)` |
| Inline code | single backticks around the text |
| Code block | triple backticks |
| Headings | `#`, `##`, `###` |
| Quote | `>` at the start of the line |

Teams shows a live preview while you type, and Ctrl+Z undoes the formatting. Microsoft notes that some formatting may behave differently from standard Markdown. Tables are not in the list.

## Common mistakes

- **Expecting a Saved section too early.** It only appears after the first saved message.
- **Muting when you meant to hide.** Muted chats stay in your list, hidden chats disappear until someone writes again.
- **Missing @mentions.** Muting does not block them, so a muted chat can still notify you.
- **Typing Markdown for tables.** The documented syntax has no table support.
