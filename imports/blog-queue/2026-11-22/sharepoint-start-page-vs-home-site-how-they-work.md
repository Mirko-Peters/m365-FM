When people search for the SharePoint home page, they usually mean one of two things. The first is the **SharePoint start page**, a personal page at the top level of SharePoint. The second is the **SharePoint home site**, a designated communication site that acts as the organization's landing page. Microsoft documents both, and they are not the same thing.

## The start page

Microsoft Support says the SharePoint home page was renamed the SharePoint start page in SharePoint in Microsoft 365. It is where you find and open sites and portals in your organization. It also shows news from followed sites and suggested sites.

### How to open it

1. Sign in to Microsoft 365.
2. Select the app launcher icon in the top left corner.
3. Select **SharePoint**. If it is missing, select **More apps** and search for it.

### What the sections show

The article names these sections:

| Section | What it does |
|---|---|
| Search | Finds recently visited sites and files, plus other sites, files or people in your organization |
| Create a site | Available only if your administrator enables it |
| Create a new post | Creates a news post |
| Following | Lists the sites you follow, most recently followed first |
| Recent | Lists recently visited sites; See all shows the full list |
| Featured links | Sites and portals your organization features; admins can set these links |
| News from sites | News from followed and frequently visited sites and other suggestions; See all shows the 100 latest articles |
| Frequent sites | Sites you visit often; managed by Microsoft Graph, not editable by users or admins |
| Suggested sites | Sites generated by the Office Graph |
| Save for later | News posts you saved |
| New SharePoint Start | Create and track personal pages |

The article uses the names Following, Featured links and Suggested sites. Some third-party guides use different labels, so use these when you look for a setting.

### Why it looks different for everyone

Microsoft Learn says the content of the start page is driven and managed by Microsoft Graph and personalized to the individual user's recent activity, followed sites and content saved for later. That is why two colleagues see different lists.

## The home site

Learn describes a home site as a customized landing experience that reflects the organization's brand, voice and priorities and serves as a gateway to other portals in the intranet. It is a communication site with special capabilities and the base component for the SharePoint app in Teams (formerly Viva Connections).

What a home site adds, according to Learn:

- **Intranet-wide search.** Users search sites, news and files across the intranet instead of only within the site.
- **Organizational news source.** By default a home site is set as the organizational news source.
- **Global navigation.** The SharePoint app bar can show navigation nodes wherever users are in SharePoint. To use this fully you need a home site. Global navigation can be customized only from the home site's home page.

### Start page versus home site

| Question | Start page | Home site |
|---|---|---|
| Scope | Personal | Whole organization |
| Content source | Microsoft Graph, based on your activity | What the site owners publish |
| Who sets it up | Nobody; it exists by default | A SharePoint admin |
| Editable by users | Only through following, saving and similar actions | Edited as a communication site by its owners |

Learn also says integration between the home site and the start page isn't available at this time. To improve discovery, it recommends a featured link on the start page and a link in the Microsoft app launcher.

## Setting up a home site

Learn lists these requirements and steps:

1. Create a modern communication site first.
2. You need a SharePoint admin role to open the SharePoint admin center.
3. You need an Enterprise (E), Frontline (F) or Academic (A) license type to create the SharePoint app in Teams experience. Creating more than one experience, up to 50, requires a Microsoft Viva Suite or Viva Communications and Communities license for every user.
4. As a best practice, swap the communication site in place of the tenant root site before setting it as the home site. Learn warns that doing it in the other order might lose home site settings.
5. Learn says to set it as a home site in the SharePoint admin center. A FAQ entry states that starting in July 2026 the SharePoint admin center is the way to set a home site for the SharePoint app in Teams experience.

The home site plan page also lists planning steps: align objectives, organize priority content, design navigation, think about branding and use audience targeting. Its build steps include content approval flow, site health checks and testing on all devices.

Learn does not give an admin center menu path or a cmdlet name in the pages read, so confirm the exact click path in your tenant.

## Common mistakes

- **Treating the start page as editable.** Frequent sites and suggestions come from Microsoft Graph.
- **Expecting a home site to replace the start page.** The two are separate and are not integrated.
- **Setting the home site before the root swap.** Learn warns it can cost you settings.
- **Looking for Create a site and not finding it.** An admin controls that option.

## Limits of the sources

The Microsoft Support article does not compare the start page with a site home page and does not cover mobile. The Learn pages on the home site give no menu path or cmdlet and do not say how many home sites a tenant can have.
