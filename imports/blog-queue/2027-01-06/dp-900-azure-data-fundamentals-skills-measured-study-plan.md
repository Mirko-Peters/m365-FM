DP-900 weights core data concepts and the analytics workload at 25-30% each. Relational data on Azure follows at 20-25%, and non-relational data at 15-20%. This guide uses only the Microsoft Learn skills outline, valid as of 21 July 2026. It contains no exam questions.

## About the exam

The study guide gives a passing score of 700 or greater on a scale of 1 to 1000. The English version is updated first, and localized versions follow about eight weeks later. If the exam is not offered in your language, you can request an additional 30 minutes. Most questions cover generally available features, though preview features may appear if commonly used.

The audience is candidates who are beginning to work with data in the cloud. The expected knowledge is concepts of relational and non-relational data and the different data workload types, transactional and analytical. The exam can help you prepare for Azure Database Administrator Associate or Azure Data Engineer Associate, but it is not a prerequisite for either.

## Skill areas and weights

| Skill area | Weight |
| --- | --- |
| 1. Describe core data concepts | 25-30% |
| 2. Identify considerations for relational data on Azure | 20-25% |
| 3. Describe considerations for working with non-relational data on Azure | 15-20% |
| 4. Describe an analytics workload | 25-30% |

## Area 1: core data concepts (25-30%)

- **Ways to represent data:** features of structured, semi-structured and unstructured data.
- **Options for data storage:** common data file formats, features of data stores including databases, and Azure datastores for common use cases.
- **Common data workloads:** features of transactional and analytical workloads.
- **Roles and responsibilities:** database administrators, data engineers and data analysts.

## Area 2: relational data on Azure (20-25%)

- **Relational concepts:** features of relational data, normalization and its purpose, common SQL statements and common database objects.
- **Relational Azure data services:** the Azure SQL family, which is Azure SQL Database, Azure SQL Managed Instance and SQL Server on Azure Virtual Machines, and Azure database services for open-source databases.

## Area 3: non-relational data on Azure (15-20%)

- **Azure storage capabilities:** features of Azure Blob storage, Azure Files and Azure Table storage.
- **Azure Cosmos DB:** use cases and APIs.

## Area 4: analytics workload (25-30%)

- **Large-scale analytics:** data ingestion and processing, analytical data store options, and Microsoft cloud services for large-scale analytics, including Azure Databricks and Microsoft Fabric.
- **Real-time analytics:** batch versus streaming data, and Microsoft cloud services for real-time analytics.
- **Data visualization in Power BI:** Power BI capabilities, data model features and choosing appropriate visualizations.

## A study plan from the weights

The plan is advice derived from the weights, not an official plan.

1. Start with area 1. At 25-30% it is the base for the rest, and the vocabulary shows up everywhere: structured and semi-structured data, transactional and analytical workloads, and the three roles.
2. Do area 4 next, because it carries the same weight. Know the difference between batch and streaming, and know what Fabric, Databricks and Power BI each do at a concept level.
3. For area 2, practice reading basic SQL statements and learn what normalization is for. Compare the three Azure SQL options.
4. For area 3, compare Blob, Files and Table storage and learn what Cosmos DB is for, including its APIs.
5. Use the practice assessment named on the exam page, if one is offered.
6. Read the study guide again before your exam date.
