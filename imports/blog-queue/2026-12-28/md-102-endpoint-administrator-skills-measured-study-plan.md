MD-102 is the exam Managing and Securing Microsoft 365 Endpoints by using Intune. This article restates the Skills Measured outline from the Microsoft Learn study guide, which is dated October 27, 2026, and builds a study plan from it. It contains no exam questions.

## Exam facts from the page

- Passing score: 700 or greater.
- The English version is updated first, and localized versions follow about eight weeks later, although this schedule is not always met.
- If the exam is not offered in your language, you can request an extra 30 minutes.
- Most questions cover generally available features, and preview features may appear if commonly used.
- The page does not mention a retirement.

## Audience profile

Candidates have expertise in managing devices and client applications in a Microsoft 365 tenant by using Microsoft Intune and agentic tools and workflows. They should understand Microsoft Entra ID, Microsoft Security Copilot, Intune agents and Microsoft Defender XDR.

## Skills measured

| Domain | Weight |
| --- | --- |
| Prepare infrastructure for devices | 20 to 25% |
| Manage and maintain devices | 25 to 30% |
| Protect devices | 15 to 20% |
| Manage and secure applications | 15 to 20% |
| Optimize endpoint operations by using automation, monitoring and reporting | 10 to 15% |

**Prepare infrastructure for devices.** Add devices to Microsoft Entra ID (join type, join, register, dynamic groups). Enroll devices to Intune (automatic enrollment for Windows, personal enrollment for macOS, iOS and iPadOS, Android profiles, Apple Business Manager, Samsung Knox and Google zero-touch). Implement identity and compliance (roles, scope tags, multi-admin approval, compliance policies, Conditional Access, Windows Hello for Business, Windows LAPS, local groups).

**Manage and maintain devices.** Deploy and upgrade Windows clients (Autopilot profiles versus device preparation policies, deployment modes, device name templates, Enrollment Status Page, Windows 11 upgrades, Windows 365 Cloud PCs, Windows Backup). Device configuration profiles for Windows, Android, iOS, macOS and specialty devices, with assignment filters. Intune Suite add-on capabilities (Endpoint Privilege Management, Enterprise App Catalog, Remote Help, Cloud PKI, Microsoft Tunnel for MAM, Advanced Analytics). Remote actions, including device queries by using KQL and the Troubleshooting blade.

**Protect devices.** Endpoint security policies (antivirus, disk encryption, firewall, attack surface reduction, security baselines, Defender for Endpoint integration, App Control for Business). Device updates (update rings, feature and quality updates, Windows Autopatch and Hotpatch policies, Apple and Android updates, Delivery Optimization).

**Manage and secure applications.** Deploy and update apps (Win32, LOB, Store apps, Quiet Time policies, Microsoft 365 Apps, Apple Business Manager, Managed Google Play). App protection and app configuration policies.

**Optimize endpoint operations.** Automate with PowerShell and Microsoft Graph, investigate threats and analyze device performance with Security Copilot agents in Intune. Reporting, Endpoint Analytics, remediation scripts, tenant health, message center notifications and alert rules.

## What changed

The change log compares the prior version with October 27, 2026. Only minor changes are listed, mostly inside existing domains, and Intune Suite add-on capabilities was renamed Microsoft Intune Suite add-on capabilities.

## A study plan

This plan is a suggestion based on the weights, not Microsoft guidance.

1. Weeks 1 and 2: enrollment, join types and compliance, since the first domain carries up to 25 percent.
2. Weeks 3 and 4: Autopilot, configuration profiles and remote actions, the heaviest domain.
3. Week 5: endpoint security and updates.
4. Week 6: apps, app protection and the Intune Suite items.
5. Week 7: automation, reporting and Security Copilot agents, then the free practice assessment.

## Study resources named on the page

Learn lists self-paced learning paths and modules, instructor-led courses, product documentation for Windows, Windows Autopilot and Microsoft Intune, Microsoft Q&A and the Windows Tech Community for support, videos from the Exam Readiness Zone and a free practice assessment.

## How to use the weights

This is a suggestion, not Microsoft guidance. Treat the ranges as a guide to effort rather than a count of questions, and cover every bullet of the outline at least once, because the outline is the only list of skills the page gives. Give time to newer topics in the outline, such as Security Copilot agents in Intune, Quiet Time policies, Hotpatch policies and device queries by using KQL. The change log marks changes only as minor and does not say which bullets are new, so compare with your earlier study notes yourself.

## Not covered

The page does not give exam duration, price or number of questions.
